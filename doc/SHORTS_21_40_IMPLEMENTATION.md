# GB21〜GB40の実装

2026-10-23、設計モデルv1.2bで書かれた短編20作を本棚へ追加しました。全333節・81結末をプレイでき、本文の条件分岐、数値と印の更新、結末の収集、保存・再開、足あとの再読に対応します。短編はGB01〜GB40の40作です。

`index.html`を直接開いて遊べます。GB21〜GB32には表紙・挿絵・BGMを導入済みです。GB33〜GB40は文字と配色で表紙を表示し、音楽ボタンを隠します。[素材記録](SHORTS_21_40_ASSETS.md)に配置と残作業を記載しています。

## 本文と生成物

本文の正本は[gb21-40の目次](drafts/gb21-40/README.md)から開ける20個のMarkdownです。導入・遊び方・全節・全結末・作者メモを保持しています。作者メモは読書画面へ出しません。

- `data/short-adapters/gb21.json`〜`gb40.json`：記録の初期値と範囲、選択条件、更新、条件付き本文の対応定義。原稿の該当行・段落とSHA-256を照合します。
- [scripts/short-stories.cjs](../scripts/short-stories.cjs)：Markdownと対応定義を変換します。未処理の記法、古くなった対応、行先の欠落はエラーにします。
- `data/shorts/gb21.json`〜`gb40.json`：生成された実行データ。
- [js/shorts.js](../js/shorts.js)：ブラウザ用の通常スクリプト。`fetch()`やサーバーを使わず読み込めます。

GB01〜GB20の初版・第2版、既存の記録形式、作品IDは維持しています。新作はGB21〜GB40・revision 1として独立して保存します。設計モデルv1.2bはシナリオの設計基準であり、実行エンジンやセーブ形式の版とは別です。

## 条件と更新の扱い

原稿中の128段落を明示的に対応付け、180の条件付き本文断片を含む1,955断片を元の順番で表示します。共通部分も条件付き部分の前後の位置を保ちます。GB35の二段落では、条件の両側で共有されていた述語を各表示へ補っています。その他の本文を要約しません。

記録は選択確定時だけ更新します。到着節にある更新も、その節へ進む選択に割り当てています。ページ送り、再読み込み、ルール表示、足あとでの再読では再適用しません。

- **GB27の三手**：一手目は中央、二手目は直前に選んだ門、三手目は二手目の右隣（右の隣は左）を番人が守ります。条件ごとに同じ行動の定義を分け、表示時には一つだけ選べます。加点は進む瞬間に一度だけです。
- **GB30の物資**：食料・薪・給餌回数・準備・夕食を保持します。共同橇を頼む結末では、本文にある「食料が残れば一包を置く」「薪が残れば一束を使う」も反映します。到着前の残量で本文を選び、置くだけの食料では給餌回数を増やしません。
- **GB34の位置**：球の位置は節に含まれるため、別の座標を作りません。戻る経路やミナを呼ぶ経路でも、球の位置は原稿と一致します。
- **GB36・GB39の到着前の描写**：新しい印を付ける前の状態で読む部分を区別します。初めて印を付けたのに「以前にも経験した」と表示されることを防ぎます。GB36の目の前で試せる技を印で制限しません。
- **GB29の捕まり方**：名乗りに加え、帽子を囮にした履歴をゲームが自動記録します。わざと捕まった経路へ、帽子を投げた描写を出しません。紙で読む際に必要な記録は従来どおり名乗りだけです。

原稿の選択肢は475行です。GB27の加点とGB30の残量による条件別定義を含めると、実行データは484選択肢になります。同時に同じ行動のボタンが複数出ることはありません。

## 編集と再確認

本文や条件を変えたら、対応するMarkdownとadapterを合わせて編集します。adapterの`sourceSha256`は、`## 導入`の直後から`## 作者用`の直前までをtrimしたUTF-8文字列のSHA-256です。本文の変更を確認した後に更新します。作者メモや実装状況の表示だけの変更では更新不要です。

```sh
node scripts/build-data.cjs
node scripts/build-data.cjs --check
npm test
BROWSER_SUITE=new-short npm run test:browser
```

生成JSONや`js/shorts.js`だけを直接直しても、次の生成で元へ戻ります。原稿変更後のSHA不一致を、本文の条件を確認せず解除しないでください。
