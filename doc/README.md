# 制作・実装・引継ぎ資料

このフォルダには、実装済みGB01〜GB20のシナリオ全文、新規GB21〜GB40のドラフト20作、制作に用いたゲームシナリオモデルの全文、HTML版の実行仕様、導入した絵と音楽の一覧を収録します。ゲームの入口は、リポジトリ直下の `index.html` です。GB21〜GB40は文書段階で、ゲームにはまだ実装していません。 中編M01『潮待ちの劇場』とM02『灰冠迷宮と星火の剣』も、それぞれ全12章のドラフトとして追加しました。M03『空渡り便の二度目の人生』は、異世界転生をテーマにした全16章のドラフトです。

## シナリオを読む

[実装済みGB01〜GB20のシナリオ目次](scenarios/README.md)から、作品ごとのMarkdownを開けます。本文と条件付き本文、選択肢と分岐先、条件と記録の変化、すべての結末、作者資料を収録しています。節のリンクをたどって分岐を確認でき、GitHub上でもそのまま読めます。

## GB21〜GB40のドラフトを読む

[GB21〜GB40・20作のドラフト目次](drafts/gb21-40/README.md)から、新作の全文を読めます。各作に導入、遊び方と記録、番号付き本文、全選択肢と遷移先、全結末、作者用設計メモがあります。本文のリンクをたどって、GitHub上で分岐を読めます。

設計モデルv1.2bによる第1稿です。内容のレビューと検査範囲は[ドラフトのレビュー記録](drafts/gb21-40/REVIEW.md)にまとめています。

## 原稿と生成物の扱い

GB01の第2版は[../data/editions/gb01-v2.json](../data/editions/gb01-v2.json)に初版をそのままコピーしてあります。[第2版の閲覧用Markdown](scenarios/gb01-v2.md)も自動生成します。改稿は第2版JSONで行い、既存の`data/stories/gb01.json`を初版として保持します。ゲーム画面上部から両版を切り替え、進行と結末を別々に保存できます。

実装済みGB01〜GB20の正本は [../data/stories/](../data/stories/) の `gb01.json`〜`gb20.json` です。本文、選択肢、状態、結末、作者用の根拠が一つの作品データに入っています。取得元とバイト単位の識別情報は [../data/source-manifest.json](../data/source-manifest.json) にあります。

ブラウザ用の `js/stories.js` と `js/assets.js`、試聴用の `doc/audio-review-data.js`、シナリオ閲覧用の `doc/scenarios/README.md` と `doc/scenarios/gb01.md`〜`gb20.md` は、正本から `node scripts/build-data.cjs` で生成します。試聴用データには音源のSHA-256も記録し、音源の更新を確認結果へ反映します。生成物だけを直接編集すると、次の生成で変更が消えます。作品の条件・効果・本文を変えた場合は、作品の内容版と保存互換を見直してください。

`node scripts/build-data.cjs --check` で、シナリオMarkdownも含めた生成物が正本と一致するか確認できます。GitHub Actionsでも同じ検査を行います。

ゲームを遊ぶために、この生成コマンドやサーバーの起動は必要ありません。

GB21〜GB40の原稿は、[drafts/gb21-40/](drafts/gb21-40/README.md)のMarkdownをドラフトの正本とします。既存の生成器が作る`doc/scenarios/`とは別の文書です。今回、実行用JSON、JavaScript、画像、音源、保存形式、作品一覧への追加は行っていません。実装へ進むときに、採用する原稿版を決め、条件・効果・本文変種を実行データへ変換してください。
