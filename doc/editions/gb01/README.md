2026年10月22日。初版を保持しながら第2版を試作するための作業場所です。今回は初版の固定保存、改稿前原稿の複製、現状点検と改稿候補の整理までを行いました。第2版の本文執筆・実装はまだ行っていません。

- [第2版の準備資料](edition-2/PREPARATION.md)：初版の特徴、具体的な検討箇所、改稿と比較の手順です。
- [第2版の作業原稿](edition-2/DRAFT.md)：初版の全文を複製した改稿前の原稿です。第2版として完成した文章ではありません。

## 版の意味

ここでいう「初版」は、準備開始時の`main`、コミット`8d5a2308ff05d0605d837e00fed2a1028e44b242`にあるGB01です。過去の最初のコミットまで巻き戻す意味ではありません。

初版のJSONは`id: "GB01"`、`revision: 2`です。`revision`は既存セーブとの互換を管理する内容改訂番号です。本フォルダの「初版／第2版」という編集上の区分とは別であり、初版を保存するために`revision`を1へ戻すことはしません。制作モデルv1.2／v1.2bの版とも区別します。

初版のJSONは完全複製です。初版Markdownは元の全文を保持し、保存版の説明・見出し・案内リンクだけをこのフォルダに合わせています。元素材のファイル名、表示位置、音量、ループ設定とハッシュも保存記録へ収め、当時の画像・音楽は基準コミットで特定できます。

## 作業の進め方

`edition-1/`は比較基準として固定し、改稿は`edition-2/DRAFT.md`と`edition-2/PREPARATION.md`で進めます。初版の誤記や改善点が見つかった場合も、保存版を修正せず第2版の変更記録へ残します。

作業原稿は自動生成対象ではありません。`node scripts/build-data.cjs`を実行しても更新されません。実装済みの原稿は引き続き`data/stories/gb01.json`、その閲覧用生成物は`doc/scenarios/gb01.md`です。

第2版をゲームへ載せる際は、初版も遊べる形を確保し、版の選択とセーブ・結末履歴の分離を先に設計します。既存の`GB01`を第2版で上書きすることを、この準備作業の延長として行わないでください。具体的な実行ID、内容改訂番号、版選択UIは未決定です。
