## 原稿と生成物

`doc/drafts/medium01`〜`medium03`の章別Markdownを正本として保持しています。章ファイルの本文・分岐・作者用メモは今回変更していません。章冒頭に残る「ドラフト」「ゲーム未実装」は執筆時点の表記です。現在の実装状態は各作のREADMEと本書を参照してください。

`scripts/medium-stories.cjs`が番号付き本文、順序を保った条件付き段落、選択肢、条件、記録更新、結末を変換します。未知の構文、存在しない行先、未知の記録・値がある場合は生成を中止します。原稿の各章のSHA-256を実行データ内に記録しています。

`npm run build`で`data/medium/m01.json`〜`m03.json`と`js/medium.js`を生成します。JSONとJavaScriptを直接編集せず、原稿を修正して再生成してください。`npm run check`が生成物との一致を確認します。短編の初版・第2版の原稿と生成本文はそのままです。

本文のない条件分岐専用の1節では、節題を本文欄にも表示します。章・節の識別子は作品ごとに独立しており、画面には原稿の章番号・節番号を表示します。

## 記録と読み返し

各作の七つの記録を全章で引き継ぎます。原稿の「記録：」は、その場面へ進む選択の効果として一度だけ適用します。ページ送り、足あとの再読、再読み込みで二重に消費しません。保存形式は従来のまま、作品ID `M01`・`M02`・`M03`で進行・本文ページ・結末を分離します。

M02には、既存の傷の状態を先に描き、その後で新しい手傷を記録する場面が3か所あります。条件付き段落の`whenBefore`は直前の選択より前の状態で評価し、それ以外は到着後の状態で評価します。以前の状態は選択履歴から再生し、セーブへ余分な状態や信頼できないキャッシュは追加しません。
