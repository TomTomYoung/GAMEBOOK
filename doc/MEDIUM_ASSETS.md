# 中編3作の絵と音楽

**各作品に表紙1点・場面挿絵3点・専用BGM1曲を導入済みです。** 中編分は画像12点・BGM3曲の計15点。共通本棚と短編を含む全体は画像85点・BGM40曲の計125点です（2026-10-24）。

2026年10月23日、第10回で表紙3点・挿絵3点・BGM3曲、第11回で挿絵6点を追加しました。[PR #13](https://github.com/TomTomYoung/GAMEBOOK/pull/13)・[PR #14](https://github.com/TomTomYoung/GAMEBOOK/pull/14)でmainへ反映済みです。

## ゲームでの表示

表紙は本棚の作品カード、導入、挿絵の指定がない節で表示します。場面挿絵は以下の指定節だけで表示し、別の節へ進むとその節に対応する画像へ切り替わります。小さい横画面では本文を優先して画像を省略します。判断に必要な情報は本文にもあります。

BGMは初期OFFです。音楽ボタンで再生した後は各作の曲がループし、挿絵への切替では再生し直しません。素材追加による本文・選択肢・結末・セーブ形式の変更はありません。

## 原本と作り方

画像は[採用A](art-direction/a-selected.png)の少色ドット絵を基準に、組み込み画像生成で作成しました。大きな色面と階段状の輪郭へ整理し、固定8色への機械的な減色や拡大は行っていません。第10回の修正では初稿とAを参照し、M03の朝の挿絵はさらに直前の画像を修正しました。第11回も初稿をAに合わせて整理し、朝の卓の器を湯呑みに、余計な幕を船の木部へ直しています。守護竜の命令紋は読ませる文字にせず、鐘塔も正確な機構図としては使いません。

ファイルは同じ基底名で対応します。例はM01の第8章07節です。

- 配布画像：[assets/images/m01-scene-c08-s07.webp](../assets/images/m01-scene-c08-s07.webp)
- 採用PNG：[sources/images/m01-scene-c08-s07-a.png](../sources/images/m01-scene-c08-s07-a.png)
- 生成・修正指示：[sources/images/m01-scene-c08-s07.prompt.txt](../sources/images/m01-scene-c08-s07.prompt.txt)

表紙の基底名は `m01-cover`、挿絵は `m01-scene-c08-s07` の形です。各点の正確なパス・寸法・容量・SHA-256は[画像原本台帳](../sources/images/manifest.json)にあります。英語プロンプトはPass順に保存しています。

PNG原寸を保ち、ffmpegのlibwebp・quality 95でWebPに変換しました。第10回の6画像は1586×992px（M03表紙のみ1585×992px）、約112〜200KiB。第11回の6画像は1584×993pxまたは1585×992px、約114〜173KiBです。全点500KB以内です。

3曲とも28小節、A8・B8・A′8・折返し4小節のオリジナル曲です。外部録音サンプルを使わず、既存の加算合成レンダラーで制作しました。画像の画風に合わせてチップチューンへ変更せず、読書向けの柔らかい音色を維持しています。

音符・編成は `sources/audio/m01-theme.score.json`〜`m03-theme.score.json` に保存しています。再生成する場合は、リポジトリ直下で次を実行します。

```sh
python sources/audio/compose-medium.py
python scripts/render-music.py --only m01-theme m02-theme m03-theme
```

前者は対象3曲のスコアを、後者は配布音源を再生成します。44100Hz・ステレオの24-bit WAVを一時作成してOgg化します。3曲の統合音量は−17.95〜−17.94 LUFS-I、最大true peakは−7.26 dBTP。ループ境界の最大サンプル差はM01が0.000150、M02が0.000625、M03が0.001072で、通常の隣接サンプル差以下でした。各曲2MB以内、ゲームの再生音量は0.35です。[測定記録](../sources/audio/render-report.json)に値とSHA-256があります。
