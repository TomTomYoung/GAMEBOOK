# M01『潮待ちの劇場』

中編ゲームブック・第1稿｜2026年10月21日｜設計モデル v1.2b

この旅の九日目、灯港の水上祭で一本の芝居を上演する。

あなたはナギ、二十八歳の舞台装置職人。四年ぶりに戻った浮き劇場〈潮待ち〉には、主演のリツ、船長のタマキ、看板描きのユノがいる。岸の古い客席は取り壊されるが、船はまだ動く。師の芝居を載せた船で、自分の仕事を見せるための旅が始まる。

ところが稽古で、リツは最後の「ただいま」を言えなくなった。

扉を作り、声を合わせ、寄港先の人に見せながら、四人は何を演じたいのかを決めていく。あなたが選んだ舞台は、実際に客の前へ出る。その夜を終えてからも、次にどこで、誰と仕事を続けるかという選択が残っている。

## 読み方

各章の番号付き本文を読み、末尾の選択肢から一つを選んで、指定された節へ進みます。「台本が『原作』なら」など、現在の記録で行先が決まる箇所では、当てはまるリンクだけを使います。

条件付きの段落は引用枠に入っています。たとえば「舞台が『張出し』の場合」とあれば、手元の舞台の記録が「張出し」のときだけ、その枠内を読みます。枠が終わったら、通常の本文へ戻ります。同じ節にある別条件の枠を全部読む必要はありません。

本文に「記録：」とあれば、その場面を終えてから指定の値へ書き換えます。指定のない記録はそのままです。サイコロや点数計算は使いません。読む速さで作中の時間が進むこともありません。

中断するときは、現在の章・節と七つの記録を一緒に残してください。再開したら、その場所から続きを読みます。過去の節を読み返すだけで、記録をもう一度変える必要はありません。

## 最初の記録

次の欄を紙やメモへ写して始めてください。

```text
現在地：第一章01
手紙：未送
舞台：未定
合図：未定
ユノ：未定
台本：未定
布：乾いた
幕：未演
```

七つの記録は、それぞれ次の意味です。必要になる章で、選ぶ対象を実物や会話として確かめられます。

- **手紙**：サキへ自分から便りを出したか。「未送」「送った」。サキから返事を受け取っても、この送付履歴は変わりません。
- **舞台**：今回作る舞台の形。「未定」「張出し」「透かし」。張出しは岸へ近づく低い前舞台、透かしは奥で動く人の手も見える枠の舞台です。
- **合図**：四人が舞台を合わせる主な方法。「未定」「鐘」「灯」。止まる合図と続ける合図は、第三章で実際に練習します。
- **ユノ**：今回の本番で本人と決めた持場。「未定」「演者」「仕掛け」。その後の人生の職業を固定する記録ではありません。
- **台本**：今回上演する稿。「未定」「原作」「改作」「新作」。採用した一本を準備して、本番でもその稿を演じます。
- **布**：舞台布をどのように使える状態へ整えたか。「乾いた」「乾かした」「青い継ぎ」。後の描写へ残る、布の手入れの履歴です。
- **幕**：本番の途中で、予定外の間をどうつないだか。「未演」「通した」「結び直した」。この記録を更新した時点では、まだ上演の途中です。芝居は続きの本文で最後まで行います。
