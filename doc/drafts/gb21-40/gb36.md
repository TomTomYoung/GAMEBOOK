# GB36 雨の中で笑う鎧

ドラフト第1稿／設計モデルv1.2b／作成日2026-10-21／ゲーム未実装

[20作の目次](README.md)

## 導入

剣術教室の看板を作ったのは、三日前だった。まだ生徒の名前は一つもない。

雨の広場では、黒い鎧が挑戦者を次々と敷物へ転がしている。兜の内側で笑い声が鳴るたび、見物人も笑った。赤い旗には「黒鉄ジェロ、一度でも背をつけさせた者へ銀貨五枚」とある。

あなたは昔、この広場の大会で準優勝した。人は優勝者の名だけを覚えていた。今日は旗の下に自分の看板を立てられる。勝てば、少なくとも名前を読んでもらえる。

ジェロは人の入っていない鎧だ。独りで動き、賭け金を数え、負けた相手に手を貸す。若い頃のあなたなら、練習台と呼んだだろう。

ちょうど転ばされた男が、笑いながら泥を払っている。ジェロは男が立つまで、差し出した手を引かなかった。

## 遊び方と記録

開始は[01へ](#s01)。自分が選んだ先だけを読んでください。

記録する印は「間」一つで、初めはありません。指示のある節で付けます。印がなくても、目の前の動きを見て技を試せます。

勝負は刃を丸めた貸剣で行います。相手の背を敷物につければ一本、降参もできます。関節を壊す打撃は禁止されていませんが、破損すれば鎧の興行はその場で止まります。ジェロはその規則を聞かれた相手に、同じように説明しています。身体への強い打撃は審判のロクが止めます。

銀貨五枚は正式な一本の賞金です。何を選んでも自動的にもらえるものではありません。読む時間によって勝負は進みません。

## 本文

<a id="s01"></a>

### 01 看板を立てる場所

ロクはあなたの看板を裏返し、雨の当たらない樽へ立てた。

「出るなら表へ返しな。出ないなら、荷物番くらいはしてやる」

貸剣の柄には、前の人の手の温かさが残っていた。ジェロは敷物の水を足で払い、次の相手を待っている。いつでも右足が前へ出る。看板の文字を確かめようとして、あなたは貸剣を持った手で顔の前を隠してしまった。

- もう一人の挑戦を、足元まで見てから出る。→ [02へ](#s02)
- 看板を表へ返し、そのまま敷物へ上がる。→ [03へ](#s03)
- 休憩を取ったジェロへ、自分の教室の話をする。→ [04へ](#s04)

<a id="s02"></a>

### 02 笑い声の底

小柄な女が二度踏み込み、二度とも剣を弾かれた。三度目、女はわざと大きく舌を出す。ジェロが笑った。

兜が鳴る間、左膝の留め具が僅かに浮いた。女の剣先は胸を追っていて、足元を通り過ぎるその隙間には届かない。笑いが止まる直前、小さな金属音。膝が伸び、女の踵が敷物を離れた。

ロクの腕が間に入り、女は尻餅だけで済んだ。「見た？」と女があなたへ尋ねる。「何を」と聞き返す前に、彼女は観客の輪へ消えている。

**「間」の印を付けます。**

- 貸剣を借り、相手の動きを引き出すつもりで上がる。→ [05へ](#s05)
- 剣を低く構え、まず距離をつかむ。→ [06へ](#s06)

<a id="s03"></a>

### 03 昔の踏み込み

初手だけは身体が覚えていた。踏み込み、上段、手首を返して横へ。師匠の前で何百回も繰り返した三つの動きだ。

二つ目でジェロの剣があなたの剣腹を叩いた。三つ目は、指が動かなかった。柄を落とす前に左手を添えたところで、鎧が一歩退く。

「最後までやると、手から抜ける」

笑い声のない言い方だった。あなたは肩を回し、指を一本ずつ曲げる。見物人の輪から、誰かが看板を読み上げる声がした。まだやめたくない。

ジェロの右肩には、錆びて薄くなった留め金が見える。そこを叩けば腕は止まるだろう。止まった腕で、明日も剣を振れるかは別だった。

- 痺れが残る手で力を競わず、間合いを取り直す。→ [06へ](#s06)
- 右肩の留め金を壊してでも、一本を取りに行く。→ [07へ](#s07)

<a id="s04"></a>

### 04 師範と、客寄せ

ジェロは兜を取らずに、内側へ布を差し入れた。布から雨水が落ちる。

「教室か。俺は、一人に長く教えるのが下手でね。同じ間違いを見てると、先に身体が動く」

あなたは、今日の賞金で稽古用の棒を揃えるつもりだと話した。話してから、勝つ前に使い道を言うのは子供じみていると思った。

「俺は次の町までの車代だ。歩くと道が減るって、街道守に怒られた」

脛には、大きな泥の塊が付いている。あなたが笑うと、兜の下も鳴った。ただし笑い終わった鎧は、賞金の箱に手を置いた。

「教室の宣伝だからって、転んでやることはないぞ」

- 本気で相手をしてほしいと答え、敷物へ上がる。→ [05へ](#s05)
- 転んでもらうのでなく、客に見える勝負を一緒に作りたいと誘う。→ [09へ](#s09)
- 今日は挑まず、観客の輪で最後まで見る。→ [15へ](#s15)

<a id="s05"></a>

### 05 大げさな礼

あなたが剣を掲げると、ジェロも掲げた。腰を折ると、同じ深さまで折る。そこでさらに深く頭を下げてみた。

鎧は真似をし、兜の庇で敷物をつついた。

観客がどっと笑う。ジェロが起き上がる。あなたを責める代わりに、剣を背へ隠してから、空の手で襟を直した。

「よし。礼儀では負けた」

その笑いを追って、左膝の隙間が開く。胸元を打つには近すぎる距離だ。あなたは柄を握り直した。

- 笑いの最後まで待たず、剣を囮にして左足の外へ回る。→ [08へ](#s08)
- 足元に決めつけず、低く構えて応酬を続ける。→ [06へ](#s06)
- 礼をもう一度大げさに返し、見せる勝負を提案する。→ [09へ](#s09)

<a id="s06"></a>

### 06 一歩を譲る

ジェロは、こちらが引いたぶんだけ進んでくる。水を踏む音が一つ、あなたの靴の音が一つ。その二つが揃うのが気に入らず、あなたは途中で歩幅を変えた。

鎧の剣先が、初めて空を切る。

しかし追いかけると、すぐに剣の背が肩へ来た。ロクが「そこまで」と片手を挟む。一本ではない。あなたはまだ立っていた。

「いまの後退、もう一度やってみろよ」とジェロが言う。「さっきと同じに見えて、違った」

勝負の最中に教えられている。そのことが悔しく、少しだけ楽しい。

- 後退を生かし、打ち合うより足運びを客に見せる勝負へ変える。→ [10へ](#s10)
- 関節の薄い留め金を狙い、相手の剣腕を止める。→ [07へ](#s07)
- 一本を取る前に、剣を下げて降参する。→ [12へ](#s12)

<a id="s07"></a>

### 07 飛んだ留め金

あなたは胸へ剣先を向け、受けた腕の付け根を横から叩いた。

金具は思ったより小さな音で折れた。右の籠手が剣を握ったまま落ちる。ジェロは左腕を伸ばしたが、あなたはその肘の下へ踏み込み、胸当てを押した。

鎧の背が敷物につく。ロクの手が上がる。一本。

歓声が来るより先に、あなたは自分の看板を見ていた。雨の筋で、書いたばかりの姓が少し滲んでいる。

ジェロは座り、外れた右腕へ左手を伸ばした。届かない。転がった籠手は、あなたの靴の横にある。

- 籠手を拾って返し、賞金を受け取る。→ [11へ](#s11)

<a id="s08"></a>

### 08 笑い終わる前

**「間」がある場合：** さっき聞いた金属音を待たず、胸へ剣先を向けた。ジェロの上体が反応する。その間に、あなたは左足の外へ入る。

**「間」がない場合：** 礼のやり取りで見えた膝の隙間へ、足を入れる。胸を追わせた剣にジェロの上体が反応し、あなたの身体が左足の外へ出た。

膝が伸びる金属音より、踵に掛けた足のほうが早かった。

重いものが傾くとき、人はどちらへ逃げるかを先に考える。あなたは逃げず、胸当てを押す手の角度を変えた。ジェロの背が敷物へ落ち、兜はその端から出ない。

ロクの手が上がった。あなたの指は、まだ鎧の襟を掴んでいる。見物人の一人が「いま何をした」と別の人に聞いた。

ジェロは自分の膝を曲げ伸ばしし、それから仰向けのまま笑った。

- 立つのを手伝い、自分の教室の看板を掲げる。→ [13へ](#s13)
- 立つのを手伝い、明日の稽古で今の一手を一緒に見せてほしいと誘う。→ [14へ](#s14)

<a id="s09"></a>

### 09 負け役はいらない

「客に見せるって、ゆっくりやるのか」

「違います。何をしているか、離れた人にも見えるように」

ジェロは少し考え、敷物の端に剣先で線を引いた。ロクへ、外に出たら負けにするかと尋ねる。ロクは首を振った。

「元の一本のまま。線は目安。余計な規則を増やすと、俺が忘れる」

あなたは看板を客席へ向ける。ジェロは賞金箱を少し奥へ押す。どちらも、譲るつもりのないものを片付けてから、向き合った。

- 刃と刃の速さより、身体の位置が見える勝負を始める。→ [10へ](#s10)

<a id="s10"></a>

### 10 二人ぶんの足音

一歩引く。ジェロが進む。あなたは同じ拍子で二歩目を踏み出すふりをして、足を置かない。

空振り。輪の外の子供が、声を上げて笑った。

その笑いにジェロが応じた。膝の留め具が浮く。

**「間」がなければ：** 声の終わりと膝の戻る順番を、今度は足元まで追えた。

**「間」があれば：** 見学のときと同じ金属音が、今度は自分の手の届く距離で聞こえた。

ジェロもこちらの足を見ている。次も同じ後退をするなら、もう追ってこないだろう。雨は弱くなり、敷物に残った足跡が見え始めていた。

**まだ「間」がなければ、ここで付けます。**

- こちらから間を詰め、笑っている間に左足の外へ回る。→ [08へ](#s08)
- 二人で派手に飛び退く動きを提案し、自分は大きく後ろへ跳ぶ。→ [16へ](#s16)
- 剣を下げ、「今の後退を教室でも練習したい」と伝える。→ [12へ](#s12)

<a id="s11"></a>

### 11 箱の中の銀貨

**結末 E1：留め金の一本**

銀貨が五枚、あなたの掌へ落ちた。隣の掌には、拾った留め金の欠片がある。ジェロは両方を見比べ、欠片だけを指差した。

「それはこっち」

あなたが返すと、彼は腰の小袋に入れた。興行の旗は下ろされる。今日の仕事は、あなたが終わらせた。

見物していた若者が看板の場所を尋ねた。「ああいうのを習えるんですか」。あなたは、どの一手を指しているのか、聞き返した。

帰り道で稽古用の棒を五本買った。教室へ立て掛けると、まだ木の匂いがした。看板の滲んだ姓は乾いていたが、最後の一画だけが太い。

<a id="s12"></a>

### 12 先に手を開く

**結末 E2：習う側の場所**

あなたは剣を置き、開いた手をジェロに見せた。ロクが降参を告げると、子供の一人が「もう？」と言った。

「今日は、足だけ持って帰ります」

自分でも妙な言い方だと思った。ジェロは膝当てを外すふりをする。子供たちが騒ぎ、あなたも笑ってしまう。

片付けの間、二人で先ほどの後退を繰り返した。ジェロは途中で先に動いてしまい、そのたびにあなたが剣を下げる。今度は彼のほうが、教わるのを待つ練習をしていた。

銀貨のない財布を懐へ戻す。教室の看板には雨粒が残っている。あなたは拭かず、剣の代わりにその重さを確かめてから帰った。

<a id="s13"></a>

### 13 読み上げられた名前

**結末 E3：勝った人の教室**

ロクが看板を高く掲げ、あなたの名を読み上げた。姓を一度間違えたので、言い直してもらう。二度目には観客も覚えていた。

ジェロは敷物を乾いた側へ裏返している。こちらを見ずに、足だけであの外回りを真似した。遅い。あなたが「笑い終わってからでは」と声を掛けると、鎧は肩をすくめた。

賞金の五枚で棒を買った。店主へ教室の場所を話している間に、広場で見た女が一本を手に取る。

「初手からやるの？」

あなたは少し考えた。

「今日は、一歩引くところから」

<a id="s14"></a>

### 14 大きすぎる生徒

**結末 E4：二人の看板**

ロクから賞金の五枚を受け取り、あなたは明日の稽古の話を続けた。

「明日一日なら」とジェロは言った。「次の町へ行く車が、明後日だ。あと、床は丈夫か」

あなたは丈夫な場所だけを思い浮かべた。入口、壁際、梁の真下。真ん中は言わなかった。ジェロはその沈黙で察したらしく、屋外の稽古を提案した。

翌朝、あなたが看板を出すより先に、鎧が土を踏み固めていた。昨日の女と二人の子供が来る。ジェロが受け手をし、あなたが歩幅を見せる。

子供が転びかけると、ジェロの手が早すぎた。あなたはその腕を軽く叩く。待つ。子供は自分の足を置き直した。

鎧は小さく笑い、今度は膝が伸びるまで動かなかった。

<a id="s15"></a>

### 15 輪の外の先生

**結末 E5：見ていた場所**

樽の上の看板を表へ返したが、あなたは敷物へ上がらなかった。

挑戦者が引っ掛かるたび、足元を指差してしまう。その指を見ていた子供が、次には自分から同じ場所を指した。二人とも、胸当てを見ている大人たちより早く笑った。

興行が終わってから、子供があなたの看板を指す。

「あそこへ行けば、ここみたいに見える？」

「見えるようになるまで、一緒に見ます」

ジェロは旗を畳みながら、こちらの会話へ割り込まなかった。帰るときだけ、子供とあなたへ同じ深さの礼をした。

<a id="s16"></a>

### 16 跳んだほうの負け

**結末 E6：敷物の外の笑い**

あなたが跳んだとき、ジェロは跳ばなかった。

「そこ、水たまり」

忠告は空中で聞こえた。足が滑り、ロクが襟を掴み、あなたの背は半分だけ敷物に載った。一本。観客が笑う。あなたも笑ったが、喉に入った雨水のせいで咳になった。

ジェロが大きな手を差し出す。あなたは剣でなく、その手を取った。

「今のは、教えないでくれよ」

「転ぶ場所を見ることなら、教えます」

帰る前に、看板の裏へ小さく一行加えた。転び方も扱います。ジェロは読み終えると、今度こそ派手に跳び退いた。

## 作者用設計メモ（読了後）

### 体験と人物

狙いは、技を見抜く気持ちよさと、勝ちたい虚栄が相手をよく見ることへ変わる可笑しさ。主人公は教室の開業資金と名前を欲しがる。賞金だけが生活を救うという設定ではない。ジェロは車代を稼ぐ興行者で、転んでやる役を拒む一方、技の応酬は楽しむ。ロクは勝負と安全な中断を担当する。

### 固定前提と機構

ジェロは自律する鎧で、人間の中身を隠した仕掛けではない。笑う間は左膝の保持が緩み、笑いの終端で復帰する。02は観察、05は利用機会、10は応酬中の取得経路。08は膝の隙と横からの崩しが結び付く。右肩の留め金を壊す07は別の確実な勝ち方で、興行停止を生む。禁止されていない打撃を、後から反則にはしない。

### 選択と記録

「間」は02または10で取得し、08・10の体験の語り分けに使用する。05でも膝の隙を目撃するため、印なしで直ちに試す行為を認める。10から08へは必ず取得後。03の手の痺れはその場の身体経験で、力比べを避ける動機となるが、別の記録にはしない。記録の不変条件は、一度知った間を合流で忘れないこと。07にはどの経路でも関節破壊と興行停止の見通しが先に提示されている。

### 代案と回収

見学だけの15を認め、教室を開くための決闘を義務化しない。技を見て学ぶ12、力で勝つ11、動きを読んで勝つ13、勝負後の共同稽古14、身体の失敗を笑いへ変える16は、異なる行為の帰結。14の受諾はジェロ自身の出発日と床への懸念から一日限定となる。全ての終わりへ賞金や生徒の入会を配らない。

### 確認した経路と限界

- 01→02→05→08→13：観察で得た「間」を使い、破損させず正式な一本を取る。
- 01→03→06→10→08→14：初手の失敗から機構を取得し直し、勝利後の誘いへ進める。
- 01→03→07→11：関節を壊すと興行が終了し、賞金は規則どおり受領する。
- 01→04→09→10→16：提案に応じた相手が、危険な跳躍まで模倣するとは限らない。
- 01→04→15、01→03→06→12：見学と降参を別の完了として読める。
