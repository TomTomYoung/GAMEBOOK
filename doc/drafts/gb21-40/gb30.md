# GB30 牙のない獣の冬

ドラフト第1稿／設計モデルv1.2b／作成日2026-10-21／ゲーム実装済み（2026-10-23）

[20作の目次](README.md)

## 導入

山小屋の扉を閉めようとすると、隙間へ灰色の鼻が入った。

岩犬だった。荷車ほど大きい若い個体もいる獣だが、これは腰が落ち、頬の毛が白い。唸るために開いた口には、牙がない。あなたの袋から落ちた干し粥の欠片を舐め、噛めずに床へ戻した。

首輪の金具に「ムク」とある。五年前まで、この道の荷運びに使われていた岩犬だ。夏には古い放牧地で見掛けた。秋になってからは、見ていない。

あなたは乾燥茸を二袋、この小屋へ取りに来た。村で売れば家の屋根を塞ぎ、冬の粉を買える。午後から風が強まり、帰り道の雪が崩れ始めたので、今夜はここへ泊まることにした。

ムクは扉の内側へ前足を置き、それ以上は入ってこない。外の吹雪が、背の毛の溝を白く埋めていく。

## 遊び方と記録

冬の山小屋で二晩を過ごし、風が収まってから村へ下る話。読書中の実時間は使わない。山の場面や食事量は、この架空世界の人物と獣についての設定。

初期記録は「食料＝3包」「薪＝3束」「餌＝0回」「準備＝なし」「夕食＝未定」。食料一包は、人一人またはこの老いた岩犬が一日をつなぐ分の干し粥。湯で戻せばムクも食べられる。薪一束で、夜の食事を作り、小屋の蓄熱炉を一晩暖められる。水は雪を融かして得られる。食料はあなた自身の旅の分でもある。

「餌」はムクが一包を食べるのを見た回数。「夕食」は二晩目にあなたが食べたかどうか。空腹だから直ちに歩けなくなるわけではないが、荷を運ぶ身体には響く。指示がある選択を確定したとき、一度だけ増減する。置いていくだけの食料では「餌」を増やさない。

茸は二袋とも最初から小屋にある。普段のあなたなら二袋を背負って村へ下りられる。ムクを手製の橇で運ぶなら茸は一袋、もう一袋は小屋へ置く。村で共同橇と引き手を半日以上頼む代金も、茸一袋分になる。ムクを連れ帰った後の飼料は、あなたが用意することになる。

01から始めよう。ムクの気持ちは言葉では聞けない。食べる、動く、離れるといった振る舞いを見ることになる。

## 本文

<a id="s01"></a>
### 01 戸口の白い背

あなたが脇へ退くと、ムクは前足をもう一本入れた。床を嗅ぎ、壁を嗅ぎ、炉から離れた隅で体を丸める。毛の下の肋が、息のたびに浮いた。

鍋へ雪を入れる。火をつけると、ムクの耳だけがこちらを向く。顔はまだ床に伏せている。

食料は三包。あなた自身の今夜と明日の分を取れば、残りは一包だ。ムクはここ何日も十分に食べていない様子で、立ち上がるたびに後ろ足を置き直している。今夜一度食べれば元通り、という体には見えない。

鍋の水が白く濁る。あなたは干し粥を割る。ムクが顔を上げた。舌が一度、歯のない口の端を舐める。

- 二包を戻し、自分とムクが一包ずつ食べる。「食料−2」「薪−1」「餌＝1回」にする。[02へ](#s02)
- 一包だけ戻して自分が食べ、ムクには炉のそばへ古毛布を敷く。「食料−1」「薪−1」にする。[03へ](#s03)

<a id="s02"></a>
### 02 空になる皿

ムクは差し出した皿をすぐには舐めなかった。あなたの手が離れるのを待ち、それから鼻先を入れる。温かい粥が白い髭に付いた。

途中で何度も顔を上げる。飲み込むたび、喉の毛が小さく動く。皿が空になると、底を押す鼻のせいで、皿が炉へ近づいていった。

あなたは自分の粥を食べ、もう一度、袋の底を確かめた。残りは一包。屋根の隙間から雪が入らないよう、茸袋を少し移して隙間を塞ぐ。

夜半、薪の割れる音で目が覚めた。ムクが立っている。あなたの足元まで来て、匂いを嗅ぎ、また壁際へ戻った。尻尾は上がらない。昔、荷を運んでいたときと同じ、短い足取りだった。

- 朝、戸の隙間から天候を見る。[04へ](#s04)

<a id="s03"></a>
### 03 毛布の端

ムクはあなたが鍋を下ろす間、顔を上げていた。皿が自分の方へ来ないと分かると、鼻を前足の間へ戻す。

あなたは食べ終わり、古毛布を炉の近くへ敷いた。ムクはそこへ移る前に、空の鍋を嗅いだ。底に残る薄い粥を舐める。食料袋にはまだ二包ある。

夜中、風が小屋を押した。ムクは戸口へ向かい、扉の下の隙間を鼻で突いた。あなたが掛け金を押さえると、しばらくこちらを見ていた。それから毛布へ戻る。

あなたは残りの袋を鞄の奥へしまった。家の天井の染みを思い出す。去年より広がった茶色い輪の下で、冬の粉袋をどこへ移すか考えていた。ここにあるものは、全部、どこかで使うはずのものだった。

- 朝、戸の隙間から天候を見る。[04へ](#s04)

<a id="s04"></a>
### 04 半日の働き先

朝の光は青かった。谷へ下る斜面では、風が雪を剥がしている。今日はまだ、あの下を通れない。小屋の裏の岩陰なら歩けるが、午後には風向きが回る。今のうちに、ひと仕事して戻る時間がある。

北の貯蔵穴には、秋にあなたが春の山仕事用に取っておいた食料が三包ある。口は凍っているだろう。融かすための火に薪一束が要る。

裏の倒木なら薪を三束拾える。食料は増えないが、蓄熱炉を長く暖められる。もう一つは、小屋の板と薪一束分の木材で橇を作ることだ。ムクを載せて下れる代わり、あなたが背負える茸は一袋になる。

ムクは戸口に立った。風へ鼻を向け、くしゃみをする。歩き出しても、二、三歩で止まった。今の脚で村までついて来られるかは、まだ分からない。

- 北の貯蔵穴を開けに行く。「準備＝食料」にする。[05へ](#s05)
- 倒木から薪を集める。「準備＝薪」にする。[06へ](#s06)
- 小屋で橇を組む。「準備＝橇」にする。[07へ](#s07)

<a id="s05"></a>
### 05 氷の栓

貯蔵穴は腰ほどの高さの石積みだった。秋に掛けた板の縁が、氷で岩と一つになっている。あなたは持ってきた薪で小さな火を作り、石に沿って少しずつ温めた。

氷が割れる音を聞くと、手を止める。板を引く。動かない。もう一度待つ。風は岩の向こうで鳴り、ここへは細い雪だけを運んでくる。

ようやく開いた中には、油紙に包まれた三包が残っていた。秋の自分の結び目を解く。紙の内側は乾いている。

戻ると、ムクが小屋のすぐ外にいた。あなたが食料を床へ置くと鼻を寄せるが、包みを破ろうとはしない。前足の爪に雪が固まっていたので、あなたは入口で落としてやった。

食料は増える。その分、春の山仕事に使うはずだった貯えは空になる。あなたは貯蔵穴の場所を帳面から消さず、小さく丸だけをつけた。

- 三包を食料へ加え、使った薪を引いて、夕食の支度をする。「食料＋3」「薪−1」にする。[08へ](#s08)

<a id="s06"></a>
### 06 倒れた木の内側

倒木の雪を払い、外の濡れた皮を剥ぐ。内側の枝は乾いていた。あなたは膝で押さえ、一本ずつ折って束ねる。

風が回り始める頃、三束ができた。欲張ってもう一本取ろうとしたが、手袋の指が利きにくくなっている。斧を腰へ戻し、できた束を順に小屋へ運ぶ。

最後の束を引きずっていると、ムクが戸口から出てきた。昔なら、荷紐を噛んで運ぶのを手伝った獣だ。今は紐へ鼻を当て、口を開き、それから閉じた。あなたは紐を自分の腕へ巻き直す。

小屋の棚に、薪の薄い樹皮が積もる。炉の前で手を擦ると、指の間へ木の匂いが戻った。食料袋は朝と同じ数だ。あなたは束ね終わった薪を、湿った床へ触れないよう横木の上へ並べた。

- 三束を薪へ加え、夕食の支度をする。「薪＋3」にする。[08へ](#s08)

<a id="s07"></a>
### 07 獣一頭の幅

小屋の棚から外した二枚の板を、滑走部にする。薪の束から真っすぐな木を選び、横木を渡す。紐は茸の荷綱から一本取った。

ムクは木屑へ鼻を入れ、くしゃみをした。あなたができかけの橇を動かすと、離れた場所へ座り直す。呼んでも来ないので、毛布だけを先に載せた。

夕方、あなたは入口の雪に橇を出し、茸袋を載せて引いた。板は滑るが、重い荷を引きながら二袋とも背負う姿勢は取れない。ムクを載せるなら、茸は一袋だけだ。もう一袋は春までここへ残すことになる。湿りや鼠にやられることもあるだろう。

橇を戻すと、ムクが毛布へ前足を置いた。あなたは紐を引かず、そのまま待った。やがて後ろ足も載り、板が低く軋んだ。

- 木材一束分を薪から引き、夕食の支度をする。「薪−1」にする。[08へ](#s08)

<a id="s08"></a>
### 08 二つの器

風が小屋の裏へ回った。戸口の雪が膝まで積もっている。あなたは外へ出るのをやめ、炉へ薪を入れた。

鍋の横へ、自分の椀とムクの皿を置く。片方は縁が欠け、片方は裏に昔の荷主の印がある。どちらも、湯が入れば同じくらい白く曇る。

残っている食料と薪を確かめよう。今夜、炉へ使う薪は一束。食料を二包使えば二人分、一包なら、どちらかの器へ一日分を入れられる。

ムクは皿を見て、あなたを見た。あなたの腹も鳴る。雪を踏んだ脚には重さが残り、明日は下る道を歩かなければならない。

- 食料が2包以上あるなら、二包を戻して自分とムクが食べる。「食料−2」「薪−1」「餌＋1回」「夕食＝食べた」にする。[09へ](#s09)
- 食料が1包以上あるなら、自分が一包を食べる。「食料−1」「薪−1」「夕食＝食べた」にする。[10へ](#s10)
- 食料が1包以上あるなら、ムクへ一包を与え、自分は今夜を抜く。「食料−1」「薪−1」「餌＋1回」「夕食＝抜いた」にする。[11へ](#s11)

<a id="s09"></a>
### 09 並んで食べる

ムクの皿を、炉から少し離して置く。今度はあなたが手を離す前に鼻を近づけた。皿の縁が熱いのに気づくと、一度引き、待ってから舐め始める。

あなたも粥を食べる。喉を通る熱が、背中まで届くようだった。二つの器の底が見えた後、ムクは前足を伸ばした。長い爪の間に詰まっていた雪が、床へ小さく落ちる。

餌が2回なら、ムクは夜中に自分で立ち、戸口まで歩いて戻った。足を引きずる音はするが、昨日より短い間隔で板が鳴った。

餌が1回なら、立ち上がるとき、まだ腰が一度落ちた。あなたが手を出す前に自分で立て直し、炉の前へ一歩だけ場所を変えた。

- 朝まで休み、外の道を確かめる。[12へ](#s12)

<a id="s10"></a>
### 10 椀の底の熱

あなたは自分の椀へ粥をよそった。ムクは匂いを追ったが、手を伸ばしてはこなかった。食べ終えた鍋へ湯を足し、薄い汁を皿へ入れる。ムクはそれを舐める。食料一包の代わりになる濃さではない。

あなたは荷綱を締め直し、明日の荷の重さを確かめた。粥が腹へ落ちると、指先に力が戻ってくる。茸の二袋を並べると、家の屋根の穴も、粉屋へ払う分も、その形に見えた。

ムクは寝る場所を三度変えた。炉のそば、戸口、あなたの足元。最後は足元へ横になり、鼻先だけを毛布の外へ出した。

夜の間に風の音が途切れた。あなたは一度起き、扉の隙間に指を当てる。外から押してくる力が弱くなっていた。

- 朝まで休み、外の道を確かめる。[12へ](#s12)

<a id="s11"></a>
### 11 食べる音を聞く

一包を全部、ムクの皿へ入れた。あなたは湯を飲む。口の中の温かさが消えると、腹の空いている場所がはっきり分かった。

ムクが食べる音を聞きながら、あなたは横になる。眠りは細く切れ、そのたびに鍋の形を見た。茸も食べ物ではあるが、乾いた山茸だけでは粥の代わりの腹持ちにはならない。茸袋を開き、ひとつかみを湯へ入れる。香りは強く、腹はまだ空いていた。

餌が2回なら、夜明け前、ムクはあなたを跨いで戸口へ行った。腰は低いが、足が止まらなかった。あなたが起きると戻ってきて、鞄の結び目を嗅いだ。

餌が1回なら、ムクは立とうとして一度座り直す。あなたは体を起こし、床へ手をついた。二人とも、朝までに若くはならない。

- 少しずつ荷をまとめ、朝の道を確かめる。[12へ](#s12)

<a id="s12"></a>
### 12 下り道の始まり

朝、空は硬い青になっていた。斜面から雪が剥がれる音は止まり、尾根の風も弱い。あなたは小屋の周りを一周し、下り口の足場を確かめて戻る。炉の上には、昨夜の湯がまだ温かく残っていた。

餌が2回なら、ムクはあなたの後を外まで来る。平らな雪で向きを変え、また戸へ戻る。急がなければ、自分の脚で下れそうだ。荷を背負わせられる体ではない。

餌が0回か1回なら、ムクは入口の段差を下りたところで止まる。後ろ足を何度も置き直し、最後は座る。村まで歩かせるには、まだ弱すぎる。

あなたの夕食が「抜いた」なら、二袋を持ち上げただけで息が上がった。途中で休む時間を多く取る必要がある。小屋の戸には、ムクが夜中につけた鼻の跡が残っている。扉を開けたままにすれば、自分で出入りできる。

- 餌が2回なら、茸二袋を背負い、ムクの速さに合わせて下る。[13へ](#s13)
- 準備が「橇」なら、ムクを載せ、茸一袋だけを背負う。もう一袋は小屋の棚へ残す。[14へ](#s14)
- 村へ下り、茸一袋分を使って共同橇と引き手を頼み、迎えに戻る。[15へ](#s15)
- 残りの食料があればすべて昨夜の湯で戻して器へ置き、戸を出入りできる幅だけ開け、茸二袋を持って村へ帰る。「食料＝0」にする。「餌」は増やさない。[16へ](#s16)

<a id="s13"></a>
### 13 牙の代わりの鍋

ムクはあなたの足跡へ足を置いた。深いところでは前へ出ようとせず、あなたが雪を踏み固めるまで待つ。荷を運んでいた頃と、前後が逆だった。

夕食を食べていれば、途中の平らな岩で二度、荷を下ろした。抜いていれば、木立ごとに立ち止まり、茸袋を雪へ置いて息を整えた。ムクもそのたびに座る。あなたが歩き出すまで、鼻を前足へ載せていた。

村の煙が見える頃、日が山の反対側へ移っていた。家へ着くと、あなたは茸の一袋を粉屋へ運んだ。冬の分の粉に加え、ムク用の粗い挽き麦を買う。屋根は全部を張り替えられず、いちばん漏る場所から塞ぐことにした。

翌朝から、小さな鍋が一つ増えた。ムクは硬い干し肉を噛めず、粥を舐める。若い頃のように荷を運ぶこともない。

冬の半ば、屋根の継ぎ目を直して戻ると、ムクが戸口にいた。あなたの手より、先に鍋を見ている。あなたは雪を払って中へ入り、火を起こした。

**結末 E1：小さな鍋の冬**

<a id="s14"></a>
### 14 一本増えた跡

毛布を載せた橇へ、ムクが前足を置く。後ろ足はあなたが腰を支えて上げた。身体を丸めると、板の幅がほとんど見えなくなる。

あなたは茸一袋を背負い、残りを小屋の棚の奥へ押した。春まで保つよう油紙を掛ける。橇の紐を肩へ渡すと、体を起こすだけで足が雪へ沈んだ。

下り坂でも、橇は勝手には進まない。平らな場所では引き、急な場所では前から速度を抑える。夕食を抜いていたなら、最初の木立で腕が震え、長く休んだ。ムクは橇から降りようとしたが、あなたが毛布の端を直すと、また丸くなった。

村へ入る頃には、茸を背負った右肩より、綱を掛けた左肩の方が熱かった。

残った茸を売り、まず冬の食料を買う。屋根の張り替え代は足りない。あなたは隣家の薪割りを何日か引き受け、その代わりに板を分けてもらった。仕事から戻るたび、ムクの粥を作る。

橇は家の裏へ立て掛けた。二本の滑走跡の間に、ムクの尻尾が引いた細い一本が、村の入口まで続いていた。

**結末 E2：橇の三本の線**

<a id="s15"></a>
### 15 戻ってくる足音

あなたはムクを小屋へ戻し、毛布と水の器を近くへ置いた。残った食料があれば、一包を炉の上の湯で戻し、皿へ残す。薪があれば一束を使って蓄熱炉を暖め、残りの束を炉のそばへ積んだ。なければ毛布を二つ折りにして、床の冷たさを厚く遮る。

村への道を一人で下る。夕食を抜いていたなら、着くなり温かい汁を買って飲み、それから共同橇の小屋へ行った。

引き手のソウは、あなたの話を聞きながら荷綱を二本取った。「帰りは暗くなる。灯りも持っていく」

茸一袋分を払い、空の橇と一緒に山へ戻る。途中で足を止めたくなるたび、先を歩くソウの灯りを見る。小屋の扉を開けると、ムクが立ち上がった。最初に嗅いだのは、あなたの顔ではなく、ソウが置いた新しい食料袋だった。

二人で橇へ載せ、交代で引く。村へ戻ったときには、家々の灯りはほとんど消えていた。

翌日、あなたは残る茸の代金からムクの挽き麦を分けた。屋根の不足分は、冬の間の荷運びで埋めることにした。ソウが返された橇の上を見て、灰色の毛を一本つまむ。「次は袋だけにしてくれ」

あなたは苦笑し、その毛を取って、空になった橇を一緒に立てた。

**結末 E3：二度下った山**

### 16 戸口に残るもの

あなたは茸の二袋を背負った。毛布を炉のそばへ置き、水の器を倒れにくい隅へ寄せる。戸は、ムクの体が通る幅だけ開けておいた。

外へ出ると、ムクも戸口まで来た。そこから先へは来ない。雪の上へ鼻を出し、あなたの足元を嗅いでいる。

あなたは一度、荷紐を緩めた。それから締め直す。下の家には塞ぐ屋根があり、今夜の炉には薪を入れなければならない。

背を向けて歩き始める。振り返ったとき、ムクの顔はまだ戸口にあった。次の曲がり角からは、小屋の屋根だけが見えた。

村へ着き、茸を売った。板と粉を買い、屋根の穴を二つ塞ぐ。家の中へ落ちる雪は止まった。夕食の粥を器へ移すと、鍋の底が見える。

夜、戸の外で風が鳴った。あなたは掛け金を確かめ、炉へ戻る。山小屋の戸を開けてきた手が、膝の上にあった。
