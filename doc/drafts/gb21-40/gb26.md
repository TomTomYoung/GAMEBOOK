# GB26 百年遅れの開演

ドラフト第1稿／設計モデルv1.2b／作成日2026-10-21／ゲーム実装済み（2026-10-23）

[20作の目次](README.md)

## 導入

開館百年祭の夜、あなたは市民劇場の舞台袖で、古いやかんを磨いていた。明日の子ども劇に使う、底の抜けたやかんだ。あなたの役は「やかんを持って通り過ぎる人」。台詞はない。

閉館の鐘を鳴らそうとしたとき、舞台中央の青い種火が伸びた。足の透けた男が、その炎から右足を出した。もう一人、台本を胸に抱えた小柄な女が、男の長い裾を踏んで転んだ。

「開演五分前！」と女が言った。

客席の後ろには、百年祭の片付けをしていた町の人々がまだいる。誰かが拍手した。男は当然のように受け取り、あなたに言った。

「使者が来た。これで王は帰れる」

## 遊び方と記録

あなたは生きている劇場の代役、相手は百年前の俳優ハルドと舞台助手ロゼ。二人の芝居は、初日の洪水で中止になった。今夜の百年灯は、夜明けまで二人を舞台へ呼び戻す。芝居を終えても終えなくても、灯は同じ時刻に消える。

二人は青い照明の当たる舞台にいられ、舞台用の衣装と小道具に触れられる。客席へ降りることはできない。舞台へ上がった生きた人と話し、一緒に演じることはできる。

記録するものは「冠」一つ。最初は未選択。02または03の選択で「古い冠」「やかん」のどちらかを書き、最後まで使う。指示は選択を確定したときに一度だけ行う。

01から始める。拍手の数を競う必要はない。どんな舞台に付き合うかを選ぼう。

## 本文

<a id="s01"></a>
### 01 百年分の五分前

ハルドはあなたの肩越しに客席を数えた。二十人ほど。祭りの飾りを持ったままの人もいれば、外套に片腕だけ通した人もいる。

「王侯の来場は」

「魚屋さんなら三人」とロゼが答える。彼女は客席を覗いたばかりだ。「百年たてば、客筋も変わります」

ハルドは聞こえなかった顔をした。胸には銀糸で縫った大きな太陽。縁が少しつれていて、その下に細かな縫い直しの跡がある。あなたが見ていることに気づくと、男は胸を張りすぎて顎を引っ込めた。

ロゼが台本を開く。「あなたは帰国した王を迎える使者。私は袖から台詞を教える。先生は、教えても聞かない」

客席で誰かが椅子を引いた。劇を見てから帰るつもりらしい。今なら、演じ方を考える時間が少しある。

- ロゼに台本の筋を聞く。[02へ](#s02)
- 客席へ声を掛け、今夜の客の様子を知る。[03へ](#s03)

<a id="s02"></a>
### 02 王が戻る話

『王は帰る、鐘は鳴る』。遠い戦から戻った王が、故郷の門を開かせる短い芝居だ。使者は帰還を告げ、町の人々が鐘を鳴らす。最後は王が客席へ向き直り、「私が戻った。鐘を鳴らせ」で幕になる。

「鐘は本物じゃないの。私がこれを」

ロゼは小さな鉄皿を叩いた。乾いた音がして、客席から「落とし物？」という声が飛んだ。

ハルドは磨き布を探している。古い冠は小道具箱の底にあった。飾りの実が一つ取れ、細い針金が飛び出している。内側に布を巻けば使える。あなたの手のやかんも、底が抜けているので頭には載る。

ロゼがやかんを見て吹き出す。ハルドは、その笑いを自分の衣装への感嘆と受け取ったらしい。

- 古い冠の内側に布を巻き、王へ渡す。「冠＝古い冠」と記録する。[04へ](#s04)
- 「今世紀の王冠です」と、やかんを差し出す。「冠＝やかん」と記録する。[05へ](#s05)

<a id="s03"></a>
### 03 正装の魚屋

あなたが「少し、劇を」と声を掛けると、魚屋のナツが外套から腕を抜いた。

「長いの？　氷の箱を閉めてない」

袖からロゼが顔を出した。「王が帰って、鐘を鳴らすまでです」

「それなら、王様には手早く帰ってもらおう」

ナツは最前列へ移り、隣の席に店の前掛けを置いた。後ろのパン職人は片付けの脚立を畳み、子どもを膝に乗せる。劇場の管理人は青い灯を見つめていたが、やがて「百年祭らしくなった」と言って扉の鍵を戻した。

袖ではハルドが銀の冠を探している。あなたは小道具箱から、飾りの取れた古い冠を見つける。手には明日の劇のやかんもある。

「お客さんは王侯貴族ではありません」と伝えると、ハルドは一瞬黙り、肩の埃を払った。「ならば、今日だけ王侯にして差し上げよう」

- 古い冠を整え、荘重な帰還を始める。「冠＝古い冠」と記録する。[04へ](#s04)
- やかんを王冠として渡し、客席へ大きくお辞儀する。「冠＝やかん」と記録する。[05へ](#s05)

<a id="s04"></a>
### 04 開かない門

幕の代わりの暗がりが上がる。ハルドは古い冠をいただき、舞台の端から端まで、ただ歩くだけで海を渡ってみせた。透けた靴の下で、板がかすかに鳴る。

あなたは木の門の前へ進み、「王の、お帰りである」と告げる。ロゼが袖で口を動かしたので、慌てて「御」を一つ足す。

ハルドは門に手を置いた。「開け、わが都よ」

門は開かない。明日の子ども劇用に、裏から留めてある。あなたが留め金を外す前に、最前列からナツの声がした。

「王様、鍵は？」

客席が笑った。ハルドの指が門の木目を強くなぞる。ロゼは鉄皿を抱えたまま、あなたと男を交互に見ている。

- 門の留め金を外し、台本の言葉で王を迎える。[06へ](#s06)
- ナツに「城の留守を預かった方ですね」と呼び掛ける。[07へ](#s07)

<a id="s05"></a>
### 05 王冠の注ぎ口

ハルドはやかんを両手で受け取り、注ぎ口を真正面にしてかぶった。

「左右から剣を防げる、よい造りだ」

あなたが訂正する前に舞台へ出た。客席の笑いが波のように押し寄せる。ハルドは一歩退き、やかんを確かめる。ロゼが袖で体を二つに折っている。

あなたは使者の杖を三度ついた。「王は百年の旅から、お湯を切って戻られた！」

ハルドはあなたを見た。それから、とてもゆっくりと首を傾けた。注ぎ口から星形の紙吹雪が一枚落ちる。明日の仕掛けの残りだ。

「長旅で、少々煮詰まっておる」

今度の笑いを、男は逃さなかった。ナツが立ち上がり、「それなら蓋を開けなさい」と言う。王は蓋の取っ手に触れ、あなたへ目を走らせた。

- ナツを、王を待っていた町の代表として舞台へ招く。[07へ](#s07)
- 「町にはもう次の王がいます」と、台本にない反乱を始める。[08へ](#s08)

<a id="s06"></a>
### 06 縫い目の太陽

あなたは門を開き、使者の長い歓迎の言葉を読んだ。王はあなたの足元へ両膝をついた。帰還を喜ぶ場面だったはずなのに、その背中を見ると、客席の笑いは静まった。

合間に袖へ戻ると、ハルドが太陽の縫い目を押さえていた。

「母が縫った。王の衣装など見たことがないから、太陽なら大きい方がよいと言ってね」

初日の母の席は三列目の端だった。洪水で公演が流れ、その後、衣装は何度も直された。俳優は大きな劇場にも出たが、この芝居の最後の一言だけは、人前で言う機会を失った。

ロゼは黙って頁を送る。最後の頁の余白に、彼女の字で別の台詞がある。「お帰りを待っていたのは、鐘ではありません」。その上に消し線が何本も引かれていた。

「私は舞台助手でしたから」と彼女は言って、頁を閉じかける。

- 二人を舞台へ呼び、最後の場面を作る。[09へ](#s09)
- 劇をいったん止め、二人自身の話を客席へ届ける。[13へ](#s13)

<a id="s07"></a>
### 07 留守番の女王

「上がっていいなら、言いたいことはありますよ」

ナツはあなたの差し出した手につかまり、舞台へ上がった。ハルドが胸を張ると、彼女はその胸の太陽を指でつまんだ。銀糸の厚みはあるのに、見上げた顔の向こうには舞台の柱が透けている。驚いて手を引っ込め、それから舞台衣装の外套を肩へ掛ける。

「王様。こちらは百年間、屋根を直し、魚を売り、子どもを育てました。そちらは？」

ハルドが使者へ助けを求める前に、ロゼが袖から言った。「海を渡られました」

「一往復で百年？」

客席から笑いと拍手が起きる。ハルドは唇を結び、やがて外套の端を持ってナツへ捧げた。

「留守番が、王よりうまくやっていたらしい」

ナツは外套を受け取らない。「そういう台詞は、みんなに聞こえる声で」

ロゼが袖から半歩出た。ハルドは、その小さな動きを目で追う。

- 王と使者と町の人で、最後の帰還を演じる。[09へ](#s09)
- 客席にも役を頼み、王の帰る町そのものを作ってもらう。[12へ](#s12)

<a id="s08"></a>
### 08 王位争奪湯沸かし

あなたは使者の杖を逆さに持ち、「新しい王には取っ手が二つあります」と宣言した。ハルドが舞台の洗い桶を見つける。

「二つも！　卑怯な！」

王は洗い桶と決闘を始めた。桶を蹴ろうとした足が、勢い余って持ち手に入る。ロゼが飛び出し、桶を引く。ハルドも引く。二人が同時に離したため、桶だけが舞台の真ん中に残った。

客席の子どもが「桶の勝ち」と言う。ハルドは荒い息をするふりをやめ、桶の前に片膝をついた。

「陛下。水はけのよい国にしてください」

ロゼが腹を抱える。その笑い声は、さっきまで袖から聞こえていた小さな声とまるで違う。ハルドもつられて笑い始め、次の台詞が出てこない。

- 桶王の即位式を客席に任せ、二人を舞台の端の椅子へ案内する。[12へ](#s12)
- 笑いが収まるのを待ち、「百年前もこうでしたか」と二人に聞く。[13へ](#s13)

<a id="s09"></a>
### 09 最後の一言の前

ロゼが鉄皿を置く。これから王が帰還を宣言し、鐘が鳴る。使者役のあなたは、最後まで王の横に立つことになっている。

「冠」が古い冠なら、ハルドは曲がった飾りを直す。やかんなら、注ぎ口を少し斜めに向ける。どちらの王も、今度は客席の顔を一人ずつ見ている。

「先生。あの最後の台詞、私は百年、言い方を考えていました」

ロゼが言う。ハルドは「私もだ」と答えてから、彼女を見た。

「君が？」

「王が帰ってくる方ではなく、待っていた方を」

ロゼは使者の杖を見る。あなたが渡せば、彼女は初めて客席に向けて台詞を言うことになる。ハルドは長い間、誰もいない三列目の端を見ていた。やがてあなたへ向き直り、芝居が続くのを待った。

- 杖を持ったまま王を迎え、ハルドに帰還の宣言を任せる。[10へ](#s10)
- 杖をロゼに渡し、自分は鐘の鉄皿を持つ。[11へ](#s11)

<a id="s10"></a>
### 10 鐘が鳴る

あなたが門を開ける。ハルドは一歩入って、立ち止まった。片手は胸の太陽の上にある。

「私が戻った。鐘を鳴らせ」

ロゼの鉄皿が澄んだ音を立てた。百年前の台本は、そこで終わる。

けれど拍手の中で、ナツが「お帰り」と言った。パン職人も、管理人も続いた。ハルドは何度も頭を下げたため、冠を落としかけた。

「冠」が古い冠なら、あなたは外れかけの飾りを押さえ、一緒に礼をする。やかんなら、落ちる前に受け止め、そのまま王の前へ差し出す。彼は空のやかんから見えないお茶を注ぎ、三列目の端へ一杯を掲げる。

夜明けまで、ハルドは同じ台詞を二度とは言わなかった。客たちから店や仕事の話を聞き、目を丸くし、よく笑った。ロゼは台本の末尾に今夜の日付を書いた。

灯が細くなると、あなたは王の外套を受け取る。透けた肩が消えた後も、銀糸の太陽は手元に残っていた。明日の子ども劇では、その太陽を窓の向こうへ吊ろう。

**結末 E1：百年目の「お帰り」**

<a id="s11"></a>
### 11 使者の声

ロゼは杖を握った。袖から客席へ向くまでの、たった半歩に時間をかけた。

ハルドが門の外で待つ。今まで誰かを待たせる側だった男が、ロゼの息が整うまで黙っている。

「お帰りを待っていたのは、鐘ではありません」

ロゼは一度、台本の置かれた袖を見た。あなたは鉄皿を持ったまま首を振る。次の言葉は、まだどこにも書いていない。

「あなたが何を見たのか、聞きたい者がいるのです」

王は大きな宣言の形に開いていた口を閉じた。冠を取り、腕に抱えた。「海に、丸い月が二つあった。空のものと、船の下のものと」

ロゼは門を開けた。客席に笑いは起こらない。あなたが鉄皿を小さく鳴らすと、二つ目の月に触れたような音になった。

夜明け前、ロゼは使者の杖をあなたへ返す。「明日は、通り過ぎるだけ？」

あなたは首を振った。やかんを持って通る人にも、窓の月を見た話くらいはできる。消えてゆくロゼは、初めて台本を閉じたまま、真ん中でお辞儀をした。

**結末 E2：まだ書かれていない台詞**

<a id="s12"></a>
### 12 客席にいた役者たち

あなたは舞台の端に椅子を二つ並べ、ハルドとロゼを座らせる。生きている客たちが、その前へ集まった。

「私は城門」と、脚立を畳んだパン職人が両腕を開いた。「私は雨」と子どもが父親の膝の上で指を鳴らす。ナツは町の市場を引き受け、魚の値段を読み上げた。それだけで、百年の王国は港町になった。

あなたは王役を募集したが、誰も手を挙げない。代わりに三人がいっせいに帰還の使者を名乗り、別々の方向から戻ってきた。王はどうやら道に迷ったらしい。

「冠」がやかんなら、あなたは洗い桶を中央の王座へ運んだ。桶が王を務め、やかんはその旅の荷物になった。古い冠なら、ナツがそれを舞台へ置く。「王が来るまで、持ち回りでやろう」

ハルドは口を挟みかけ、ロゼに袖を引かれた。しばらくして、誰より大きく笑っているのは二人だった。

夜明け、椅子が二つ空になる。即席の王国も解散した。あなたが最後の小道具を集めていると、三列目の席からパン職人が声を掛けた。「明日のやかんの人、見に来るよ」

**結末 E3：王が留守の大入り劇場**

<a id="s13"></a>
### 13 幕間というには長い

あなたは使者の杖を床に置いた。「少し、芝居の外の話をしませんか」

ロゼが鉄皿を引き寄せる。ハルドは青い光の縁まで歩き、客席へ下りようとした足を止めた。あなたは舞台の前へ三つの箱を並べる。観客が椅子を寄せると、段差は低い食卓のようになった。

「名前を呼ばれるのは、いつも役名でした」とロゼが言う。「怒られるときだけ、ロゼ」

ハルドは王冠を取り、膝へ置いた。「では今、君の名を呼ぶのは難しいな」

「怒らずに練習してください」

二人は少し笑った。ハルドは本名をラウル・バルタザールという。看板屋が「長い」と言って、勝手に芸名を決めたらしい。

- 自分も名前を言い、最初の舞台で失敗した話をする。[14へ](#s14)
- 二人の間へ鉄皿を置き、今夜いちばん笑った場面を聞く。[14へ](#s14)

<a id="s14"></a>
### 14 名前の残る朝

話は、舞台に出る直前の腹痛から、衣装の裾に隠した菓子へ移った。客席にも菓子を隠す人がいて、ナツは劇場へ来るたび鰊の匂いを落とそうとしていた話をした。

ハルドが笑いすぎて王冠を落とした。あなたは拾い上げ、二人の真ん中へ置く。「冠」がやかんなら蓋が鳴り、ロゼはその音にもう一度笑う。古い冠なら飾りの実が一つ転がり、ロゼは拾う代わりに、それが転がり切るまで見ていた。

客が一人ずつ帰る。ナツは氷の箱を閉めに戻り、夜明け前に温かいパンを持ってきた。幽霊は食べられないので、彼女は一つを割り、断面を二人へ見せた。

「これは変わらんな」とラウルが言った。

灯が消えるとき、あなたは台詞を促さなかった。ロゼも頁を開かなかった。二人が互いの名前を呼ぶ声が、最後まで残った。

翌日の出演者表で、あなたは「やかんを持つ人」の横に自分の名前を書き足した。その下に、小さく二つの名前を書く。いまなら、誰に読んでほしいのか分かっていた。

**結末 E4：ラウルとロゼ**

## 作者用設計メモ（読了後）

この節の検証記述は2026-10-21の原稿作成時点です。ゲーム実装後の仕様と確認結果は[実装記録](../../SHORTS_21_40_IMPLEMENTATION.md)を参照してください。

### 体験の核

百年前の大仰な役者と現在の気軽な観客が噛み合わず、そのずれを受けて舞台を変える喜劇。中心は05のやかんを自分の芝居へ取り込む応答と、09でロゼが袖から出ようとする瞬間。完演、即興の新しい台詞、客の芝居、役を脱いだ会話を、それぞれ一晩の到達点にする。

### 固定前提と仕組み

百年灯は初演予定日の百年後の一夜だけ二人を呼ぶ。公演の成否を帰還条件にせず、途中で会話へ移る代案を成立させる。二人は舞台の青い照明内にいる。舞台衣装と舞台小道具に触れるため、衣装・冠・桶・鉄皿・箱は扱え、普通のパンは食べられない。衣装は実物なので消失後も残る。生前の洪水と二人の死の時期は別であり、洪水死や百年間の拘束は設定していない。

### 人物ごとの欲望と反応

ハルドは06で、母が縫った衣装と未完の最後の台詞を見せる。最初の尊大さだけで献身を要求しない。05の笑いを取り込む、07で留守を守った人を認める、11で相手の発話を待つ、12で観客になるという別の反応がある。ロゼは舞台を支えつつ、自分の声を客へ届けたい。09で要求を自分から口にし、11では未知の台詞を作る。ナツは早く店を閉めたいが、面白い芝居なら参加する。王への質問を自分の言葉で続ける。主人公には無言の代役という現在を与え、11・14で明日の出演へ結び直した。

02・03の冠は声色と動作を変え、04・05で異なる開幕を作る。以後も09・10・12・14に物として残る。07・08から観客に任せる選択は12で幽霊の立場を観客へ変える。09の役割交代は、王の定型句を完結させる10と、使者の新しい言葉から王が応じる11を分ける。13の二つの呼び掛けは、会話へ踏み出す態度の差であり、別の結末を約束しない。

### 自然な代案と核の再評価

幽霊を成仏させる義務や、客を帰せない結界を置かない。13では上演を止めて直接話せるし、客は店の都合で帰れる。そのため中心は「必ず公演を完成させる」から「一度だけ同じ夜に居合わせた相手と何をするか」へ置いた。古い台本を成功させる10も、作者に劣った答えとして扱わない。06の母の話を聞かない経路でも、09で最後の言葉への執着は読める。

### 公開記録と作用

「冠」は未選択から古い冠またはやかんへ一度だけ変わる。02か03を必ず通るので、参照時の未選択はない。役者の反応や観客参加を数値化しない。07・08を通ったかを終幕で前提にしないため、10・11はナツが客席にいても舞台にいても成立する。12は到着直後に参加者を改めて募る。
