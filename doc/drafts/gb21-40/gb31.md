# GB31 燃えない手紙を燃やす日

ドラフト第1稿／設計モデルv1.2b／作成日2026-10-21／ゲーム未実装

[20作の目次](README.md)

## 導入

母が死んで三年、あなたは母の椅子に誰も座らせなかった。

妹の千花は、その椅子に洗濯物を積む。「人が座っちゃいけないなら、せめて服には使わせて」。言われるたびに服を畳み、椅子を空けてきた。空いた椅子を守ることが、母のいない家であなたにできる仕事だった。

今日、千花は向かいの町へ引っ越す。あなたも来月から週に三日、町の食堂で働くことにした。家は売らない。ただ、二人とも毎晩ここへ戻る暮らしをやめる。

最後の箱を閉める前に、千花が母の椅子を指した。

「このまま置いていくの、少し嫌なんだ。姉さんがここで誰かとご飯を食べるとき、邪魔になるから」

あなたのポケットには、母の最後の手紙がある。もう読む場所さえ覚えている。今日はこれを燃やすつもりだった。

## 遊び方と記録

あなたは姉の立場で選びます。01から始めてください。紙と鉛筆がなくても、次の三項目を覚えられれば遊べます。

- 「余白を読んだ」「千花の話を聞いた」の印を用意します。最初はどちらもありません。
- 「食卓」は未定です。06または07へ進む選択で「共同」か「別々」になります。
- 「返事」は最初「まだ」です。08の選択で「声」「手紙」「まだ」のいずれかにします。

記録するのは選択を確定したときだけです。本文を読み直しても印を増やしたり、選び直したりはしません。条件付きの文章は、あなたの記録に合うものを読みます。

この町には、家庭の炉では燃えない「火守り紙」があります。母は台所で使う覚え書きにもそれを使っていました。古い火守り紙は、共同窯の紙口で処分できます。窯は夕方まで開いていますが、今日使わなくても困ることはありません。

## 本文

<a id="s01"></a>
### 01 四つに折られた頼み

手紙は母が入院する前夜に書いたものだ。

「台所の窓は雨が吹き込むので、留守にするときは掛け金を。千花の長靴は裏口。あの子はまた片方なくすでしょう。家を頼みます。あなたは昔から、最後までちゃんとしてくれるから。

追伸。煮豆は火曜まで。私の分を取っておかなくていいよ」

母は帰ってこなかった。あなたは煮豆を火曜の夜に捨てた。それから、母の服は季節ごとに虫干しし、椅子は磨き、金曜には母の好きだった魚を買った。母の分は買わない。その程度には、ちゃんとわかっているつもりだった。

千花が運送屋の荷札を取りに出た。台所が静かになる。

- 予定どおり、手紙を炉の前へ持っていく。[02へ](#s02)
- 今日は折り目を全部開いて、窓辺で読む。「余白を読んだ」に印を付ける。[03へ](#s03)

<a id="s02"></a>
### 02 火のつかない端

炉には朝の熾火が残っている。手紙の端を近づけても、白い縁は赤く照らされるだけだ。火守り紙だと知っているのに、心のどこかで、今日は燃えると思っていたらしい。

鍋敷きの上へ戻すと、紙の冷たさが早く指に返ってきた。母の字は傷んでいない。「最後まで」の四文字だけが、そこに居座っている。

戻った千花が、炉と手紙を見比べる。

「窯なら午後も開いてるよ。行くなら、荷物を出したあとにして。机を運ぶのを手伝ってほしい」

燃やすなとも、早く燃やせとも言わない。それがありがたくて、少し腹立たしい。

- 千花に、この手紙のことをどう思っていたか聞く。「千花の話を聞いた」に印を付ける。[04へ](#s04)
- 手紙をポケットへ戻し、荷物のそばへ行く。[05へ](#s05)

<a id="s03"></a>
### 03 母の次の夏

折り込まれていた裏面には、別の鉛筆書きがある。あなたも以前見たはずだ。ただ、表の頼みほど大切なものだとは思わなかった。

「退院したら、北の海。宿代を調べる。千花は来るか？　あの子に任せると泳ぐ旅になる。姉さんには留守番を頼まない。一緒に来るか、自分の休みにするか聞く」

母の字なのに、母からの命令ではない。母が、母自身のために迷っている字だ。「宿代」の下に二本線が引かれている。財布の心配までして、次の夏へ行くつもりだった。

紙を裏返す。「最後まで」は、どこまでのことだったのだろう。退院までか。豆を捨てるまでか。それとも、母にも終わりを決められない言い方だったのか。

答えを見つけた気はしない。けれど、手紙の裏にも母がいた。

- まだ千花の話を聞いていないなら、この裏面を見せて話す。「千花の話を聞いた」に印を付ける。[04へ](#s04)
- 手紙を畳み、引っ越しの続きを手伝う。[05へ](#s05)

<a id="s04"></a>
### 04 「ちゃんとして」の外側

千花は手紙を読んで、まず煮豆のところで笑った。

「私、昔この『ちゃんとして』が嫌いだった。私が何か失敗すると、姉さんならって言われる気がして」

あなたは、母はそんなつもりでは、と言いかける。千花は荷札を折る手を止めなかった。

「そうかもしれないよ。でも嫌だった。姉さんだって、あれを言われて楽なことばっかりじゃなかったでしょう」

覚えている。学校の遠足より母の寝込んだ日を選んだとき、うれしそうに言われた。うれしそうだったから、次もそうした。

「お母さんの椅子、捨てたいわけじゃないんだ」と千花は言う。「私が座って、お母さんの悪口を少し言ってもいい椅子にしたい」

母への悪口なのに、久しぶりに家族の話をしている気がした。

- まだ余白を読んでいないなら、手紙を全部開いてみる。「余白を読んだ」に印を付ける。[03へ](#s03)
- 千花と最後の箱を閉じる。[05へ](#s05)

<a id="s05"></a>
### 05 椅子が通れない

運送屋は三時に来る。荷物は二箱と、千花が自分で買った机だけだった。母の椅子は運ばない。

机を廊下へ出そうとして、食卓につかえた。母が座っていた位置だけ、庭がよく見えるように食卓が斜めになっている。三年間、あなたはその斜めを一度も直さなかった。

「半回転したら、二人で向かい合えるよ」

千花が食卓の端を持つ。今動かすなら、家を出る前に一緒にお昼を食べられる。動かさなくても机は脚を外せば運べるし、千花は駅前でパンを買える。

どちらを選んでも引っ越しはできる。ただ、今日の台所の景色は変わる。

- 食卓を動かし、千花に昼食までいてほしいと言う。「食卓」を「共同」にする。[06へ](#s06)
- 今日は配置を残し、机の脚を外す方を選ぶ。「食卓」を「別々」にする。[07へ](#s07)

<a id="s06"></a>
### 06 床の白い四角

食卓を動かすと、脚の下だけ床が白かった。千花がそこへ自分の靴を載せて、足が四本あるふりをする。あなたは笑い、そのあとで少し泣いた。千花は靴を戻したが、何も尋ねない。

母の椅子を庭側から横へずらす。新しい位置では肘掛けが鍋棚に当たらない。

「こっち、ずっと座りやすい」

千花は遠慮なく腰を下ろした。あなたの許可を待たずに、棚から二人分の器を出す。母の小皿も一枚、漬物用に取った。

千花は新居の合鍵を食卓の端へ置いた。「姉さんの分。来るときは連絡してね」

米を研ぐ手を止めると、水の音が消えた。口にするなら、食卓ができた今なのかもしれない。

- 米を水に浸し、千花の向かいに座る。[08へ](#s08)

<a id="s07"></a>
### 07 脚を外す人

あなたが工具箱を持ってくると、千花は黙って机を裏返した。怒っているのかと思ったが、一本目のねじが抜けたところで「これ、先にやれば楽だったね」と言った。

食卓は斜めのまま残った。千花は駅前のパン屋へ寄ることにして、引っ越し先の合鍵を窓辺へ置く。

「来るときは連絡して。寝てたら出ないから」

許しの言葉ではなく、これからの暮らしの案内だった。

荷物が減った廊下に、あなたの足音だけが大きく響く。千花はまだ玄関で靴ひもを直している。伝えたいことがあるなら、呼び止められる距離だ。

- 玄関まで出て、千花の名前を呼ぶ。[08へ](#s08)

<a id="s08"></a>
### 08 自分の文章

あなたが言いかけると、千花は待った。いつもなら「お母さんが言っていたから」で始める。けれど今は、その言葉を借りたくない。

母が倒れた前の晩、あなたは外の町から来た仕事の誘いを断った。母に頼まれたわけではない。断ったあとで「家を頼む」という手紙を渡され、頼まれるより先に断っていたことを誰にも言えなくなった。

千花が出ていくのをうらやましいと思った。そのうらやましさまで、母に背負わせていたのかもしれない。

すぐに話せる気持ちと、まだ紙の方が持ちやすい気持ちがある。

- 「私も、あのとき行きたかった」と声に出す。「返事」を「声」にする。[09へ](#s09)
- 千花には「あとで読んで」と伝え、母ではなく千花への手紙を書く。「返事」を「手紙」にする。[10へ](#s10)
- 今日は「引っ越し先、遊びに行くね」とだけ言う。「返事」は「まだ」のままにする。[11へ](#s11)

<a id="s09"></a>
### 09 妹の荷物

「知ってた」

千花の返事は、あなたの胸の中で準備していた慰めより短かった。

「誘いの封筒、食器棚に挟んでたでしょう。私に怒ってると思ってた。私が出ていけば、姉さんが残ることになるから」

怒っていた、とあなたは認める。千花は「それは嫌だった」と言った。それから少し考えて、「でも、今日その話をしてくれてよかった」と付け足した。

あなたは謝る。千花は一度うなずき、上着のポケットから引っ越し先の古い流し台の写真を出した。

「次はここで、二人ともちゃんとしない晩ご飯を食べよう。焦がしたらパン買ってくる」

あなたはその写真を覚えるために、しばらく見た。

- 母の手紙をどうするか決める。[11へ](#s11)

<a id="s10"></a>
### 10 うまく終わらない手紙

「引っ越し、おめでとう」から書こうとして、その紙を裏返した。おめでとうは本当だが、それだけでは今日書く意味がない。

「うらやましいと思っています。私も行きたかった。あなたが出ていくせいにしていたことがあります」

そこで筆が止まる。最後を美しい言葉にすれば、この気持ちを片付けたふりができる。あなたは「ここまでしか今は書けません」と書いて、千花に渡した。

千花は「向こうへ着いてから読む」と、荷物ではなく上着の内ポケットへしまう。

「返事、すぐには書かないかも」

「うん」

その返事だけは、すぐにできた。

- 母の手紙をどうするか決める。[11へ](#s11)

<a id="s11"></a>
### 11 紙の行き先

引っ越しの荷物は玄関に揃った。あなたは母の手紙を食卓へ置く。

「余白を読んだ」に印があるなら、海の宿代に二本線を引いた字も見える。印がなければ、いつもの「家を頼みます」が折り目の上にある。

千花の話を聞いたなら、あの「ちゃんとして」が妹に別の重さで届いていたことを思い出す。聞いていなければ、椅子を見ていた妹の顔が浮かぶ。

手紙は、燃やせば戻らない。残しても母は帰らない。それでも、いつでも取り出せる紙のある暮らしと、もう探さない暮らしは違う。

共同窯へ行く道も、台所の引き出しも、今日は開いている。

- 母の字がある原本を共同窯へ持っていき、燃やす。[12へ](#s12)
- 原本を、今使っている料理帳にはさんで残す。[13へ](#s13)
- 自分がこの三年で手紙に重ねた言葉を別の紙に書き、その紙を燃やす。原本は残す。[14へ](#s14)

<a id="s12"></a>
### 12 紙口

窯番は、紙を受け取る前に小さな引き出しを開けた。奥で白い火が静かに動いている。

あなたは「これだけです」と手紙を置く。窯番はうなずき、あなたが手を放すまで引き出しを動かさなかった。

母の最後の字を、もう一度全部覚えようとはしなかった。長靴のこと。煮豆のこと。ちゃんとしてくれる、という言葉。思い出せる順に、ばらばらに浮かんだ。

引き出しが閉じる。小窓の向こうで紙の縁が灰色になり、折り目がほどけるように崩れた。燃えなかった手紙は、ここでは燃えた。

空の手で帰り道を歩く。悲しみも軽さも、期待した順番では来なかった。まず、ポケットの中で紙が擦れないことが気になった。

- 「食卓」が「共同」なら、二人の昼食へ戻る。[15へ](#s15)
- 「食卓」が「別々」なら、静かな台所へ戻る。[16へ](#s16)

<a id="s13"></a>
### 13 しみのつく場所

料理帳を開くと、母の煮豆のページにあなたが書き足した「砂糖は半分」がある。千花の字で「もっと少なくてもいい」と、その下にある。

あなたは手紙をそこへはさんだ。専用の箱には入れない。料理帳を使えば、また豆の汁が飛ぶかもしれない。

「食卓」が「共同」なら、千花が鍋をのぞいて「今日は私の量で」と言う。あなたは一度、味を見るための小皿を渡す。

「食卓」が「別々」なら、千花は運送屋と出ていく前に、料理帳の表紙を指で叩く。「砂糖、増やし直さないでよ」。あなたは「私が食べる分は私が決める」と答えた。

母の手紙の隣に、自分の字で今日の日付を書く。指示を書き写すのではなく、豆を煮た日の記録として。

- 料理帳を台所へ戻す。[17へ](#s17)

<a id="s14"></a>
### 14 私が書いた命令

普通の紙に、あなたは「この家を変えてはいけない」と書く。母の手紙には、そんな文はない。

「妹より先に、自分のことを考えてはいけない」

これもない。書くと、母への腹立たしさが全部消えるわけではなかった。母が言った「ちゃんとして」に、自分で何枚も紙を足していた。それだけは指で触れられる形になった。

小さな炉に、その紙を入れる。端から火が進み、自分の字が丸まる。母の手紙は鍋敷きの上に残した。

「余白を読んだ」に印があるなら、原本は海の予定の方を上にして畳む。印がなければ、追伸の「私の分を取っておかなくていいよ」が見えるように畳む。

灰を見ながら、燃やす言葉を自分で書けたことに少し驚く。

- 炉の戸を閉め、原本を引き出しにしまう。[18へ](#s18)

<a id="s15"></a>
### 15 向かいに座る

帰ると、千花は母の椅子で豆の筋を取っていた。「遅い」と言って、半分をあなたの前へ寄せる。

「返事」が「声」なら、二人は途中から千花の流し台に合う鍋の話をする。「手紙」なら、千花は胸のポケットを一度押さえ、それから皿を並べる。「まだ」なら、あなたは食堂で働く曜日を初めて詳しく話す。

母の椅子はきしんだ。千花は座り直し、漬物を落とした。あなたは叱らずに笑い、拾った漬物を別の皿へ移す。

午後、千花が出ていってからも、食卓は二人が向き合った角度で残った。あなたは一人分の夕食を、その端で食べた。

**結末 E1：母の椅子で豆をむく**

<a id="s16"></a>
### 16 一人分の鍋

千花の荷物はなくなっていた。窓辺に合鍵と、パン屋の紙袋が一つある。あなたが昔よく買っていた、端だけ固い丸パンだった。

「返事」が「声」なら、袋には「焦がす日の予行」と書いてある。「手紙」なら「着いたら読む」とある。「まだ」なら「店、まだあったよ」とだけ書いてある。

あなたは母の椅子へ手をかける。今日動かすには疲れていたので、やめた。手紙を燃やしたことと、家具をすべて動かすことは、同じ一つの仕事ではなかった。

小鍋でスープを温める。丸パンを割ると、湯気がまだ少し出た。明日の朝は食堂へ行く。そのために、今日は食べて眠る。

**結末 E2：空のポケットと丸パン**

<a id="s17"></a>
### 17 書き込みの余地

夕方、豆の味を料理帳に書き足す。母の字が消えるわけではない。あなたと千花の字で、その周りの空白が少し狭くなる。

「返事」が「声」なら、千花から「流し台の下、鍋が入らない」という電話が来て、二人で笑う。「手紙」なら、夜に「読んだ。今は、おやすみ」と短い便りが届く。「まだ」なら、あなたは合鍵を自分の鍵束に付ける。

母の手紙を残すと決めた日は、母の好きだった味を変えた日にもなった。紙があることを、守り続ける約束とは呼ばずに済む。

料理帳を閉じたとき、角から手紙が少しはみ出していた。今日は押し込まず、そのままにした。

**結末 E3：砂糖は半分**

<a id="s18"></a>
### 18 灰になった自分の字

炉が冷めると、自分で書いた命令は、ほかの灰と見分けがつかなくなった。原本のありかは知っている。必要になれば、また読める。

「食卓」が「共同」なら、二人で洗った皿が新しい角度の食卓に伏せてある。「別々」なら、千花のいなくなった部屋へ風を通し、あなたは台所の椅子に座る。

「返事」が「手紙」なら、千花へ書いた文の続きを今夜は足さない。「声」なら、自分の言葉を聞いた千花の顔を思い出す。「まだ」なら、便箋を一枚だけ机に置く。書き始めなくても、その一枚を母のために取り置く必要はない。

明日の食堂の献立には、あなたの知らない料理がある。寝る前に、店でもらった名前を一度声に出してみた。

**結末 E4：原本の隣の空白**

## 作者用設計メモ（読了後）

### 体験の核

家族の言葉そのものと、自分がその言葉に重ねた約束を読み分け、残す物と始める関係を選ぶ家庭劇です。手紙の処分だけを回復の合否にしません。01の「ちゃんとしてくれる」は愛情としても役割の固定としても読め、03は母自身の未来、04は妹の異なる受け止めを加えます。どの追加情報も、故人の本当の意図を最終確定する証拠ではありません。

### 固定前提と仕組み

火守り紙と共同窯は架空の生活道具です。02で家庭炉が効かなくても、12の処分を阻む試練にはしません。母の死、手紙の原文、主人公が仕事を断った時系列は全経路で同じです。主人公は食堂で働くことを既に決めており、結末だけで突然自立できるようになる設計ではありません。引っ越しには午後の予定がありますが、手紙を今日処分する必然や家を失う危機はありません。
