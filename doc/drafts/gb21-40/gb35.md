# GB35 魔王の留守番

## 導入

魔王は歯医者へ行った。

「奥歯に穴がある。世界の穴ならふさげるのに、どうして歯はだめなんだ」

それが出かける前の最後の言葉だった。恐ろしい響きのある声も、頬を押さえていると少し聞き取りにくい。

あなたは近所に住む、今日だけの留守番だ。頼まれた仕事は、赤い鍋を午後に一度混ぜること、窓を閉めること、来客の相手をすること。五時になれば魔王が帰る。

玄関の敷物には目と短い脚がある。名前はモフ。

「主人がいない日は、留守番の方針で客を扱います」とモフが言った。「お迎え重視、働き手歓迎、玄関で用事だけ。前の人は『昼寝重視』でした」

まだ方針を答えないうちに、戸が三度、勇ましく叩かれた。

## 遊び方と記録

01から始めます。次の二項目だけ記録してください。

- 「方針」は未定。01の選択で「迎える」「手伝う」「玄関」のいずれかにします。
- 「鍋」は最初「まだ」。05・14の指定された選択で「自分」か「勇者」にします。誰が一度混ぜたかを示します。

更新は選択を確定したときだけです。条件付きの文章は自分の記録に合う部分を読みます。最初の方針は、モフと客の振る舞いへ作用しますが、最後まで変えられない命令ではありません。

魔王の家は、友人や近所の人がしばしば出入りする家です。客に茶を出すことや、台所の来客用の炉を使わせることは任されています。赤い鍋については、台所に使い方の札があります。

## 本文

<a id="s01"></a>
### 01 下見に来た勇者

戸の外に、勇者アサが立っていた。剣は鞘に収め、腕には小さな帳面を抱えている。

「明日の手合わせの下見です。魔王様の椅子から、私の登場がどう見えるか確かめたい」

魔王の手合わせは毎月木曜だ。今日は水曜。アサは日付を間違えたのではなく、登場の準備に一日を使うつもりらしい。

モフはあなたの足元を一周した。敷物なので、足元から相談してくる。

「本日の方針は？」

アサは耳を澄ます。客として迎えられるのか、仕事の手を頼まれるのか、玄関で見取り図を渡されるのか。どれでも、今ここでの過ごし方が変わりそうだ。

- 「まず座ってもらおう」と迎える。「方針」を「迎える」にする。[02へ](#s02)
- 「来た人にも、できる仕事を頼もう」と言う。「方針」を「手伝う」にする。[03へ](#s03)
- 「今日は玄関を窓口にしよう」と言う。「方針」を「玄関」にする。[04へ](#s04)

<a id="s02"></a>
### 02 魔王の椅子の目線

モフは玄関から居間まで伸び、アサの足を丁寧に案内した。居間の大椅子には「腰を痛めるので飛び降りるな」と札がある。

アサが魔王の席に座り、あなたに入口へ立ってほしいと言う。

「そこから、少し影を背負って入ってきてください」

あなたが買い物袋を持って入ると、彼女は真剣にうなずいた。「袋はない方が威厳が出ます。でも、かなり参考になります」

モフはクッションを次々と運び、客が座れる場所を増やし始めた。玄関の外にまで一つ置く。あなたが驚くと「迎える方針ですので」と誇らしげに答える。

その外のクッションへ、ちょうど大きな箱を抱えた小鬼が腰を下ろした。

- 次の来客を迎えにいく。[05へ](#s05)

<a id="s03"></a>
### 03 名乗る前に薪

モフはアサへ軍手を一組渡した。自分の毛の下から出したので、少し暖かい。

「薪を台所へお願いします。五本なら、登場の稽古にもよい長さです」

アサは薪を持ち上げ、入口から歩いてみた。「両腕が塞がっている方が、胸を張りすぎないで済む」。予想より熱心に、歩幅を帳面へ書く。

あなたが手伝おうとすると、「最後の一本は持ちます。五本という約束だったので」と言って戻っていった。モフはその背中を見送り、次の客用に布巾を並べる。

「仕事を頼むと、居場所ができる方もいますね」

玄関に来た小鬼は布巾の列を見て、自分の袖をまくった。「今日はそういう日か。ちょうど粉だらけになる予定だ」

- 小鬼の大きな箱を置く場所を空ける。[05へ](#s05)

<a id="s04"></a>
### 04 玄関にも舞台はある

あなたはアサへ居間の簡単な見取り図を渡した。彼女は少し残念そうだったが、すぐ戸の前の段を数え始める。

「外から呼びかける登場なら、ここで練習できますね」

モフが戸を開け、アサが名乗る。閉める。もう一度開け、今度は少し短く名乗る。三回目には、通りがかったパン屋が「今のがいい」と声をかけた。

モフは玄関の脇へ『用事はこちら』と札を立てた。アサは客が階段を塞がないよう、小石で待つ位置を示す。遠ざけられた顔ではなく、自分の劇場の客席を作る顔だった。

大きな箱を抱えた小鬼が小石の列に並び、「私は登場なしでいいですか」と尋ねる。

- 次の客の用事を聞く。[05へ](#s05)

<a id="s05"></a>
### 05 王座のケーキ

小鬼は菓子職人のトトだった。箱の中には、まだ焼いていない巨大な椅子型のケーキがある。

「魔王様の奥歯が治ったお祝いに。うちの炉だと背もたれが入らなくて」

トトは、自分の小さな屋外炉も荷車へ積んできたと言う。外で焼くなら、背もたれを別に焼いて後で組める。家の大きな炉なら一度に入る。どちらでも四時には焼けるという。

台所から、赤い鍋が蓋を鳴らした。札には大きな字でこうある。

「スープは出来上がり。一度混ぜると脚が眠ります。混ぜないと、客のいる方へ自分で配りに行きます。汁はこぼしませんが、廊下では人より優先してください」

鍋の下から小さな足が二本、試しに出ている。

- あなたが先に鍋を一度混ぜる。「鍋」を「自分」にする。[06へ](#s06)
- 勇者に鍋を混ぜる役を頼み、あなたはトトの箱を案内する。「鍋」を「勇者」にする。[08へ](#s08)
- 先にケーキをどこで焼くか決める。鍋は「まだ」のまま。[07へ](#s07)

<a id="s06"></a>
### 06 留守番のひと回し

長い匙で鍋を一周すると、脚が中へ収まった。蓋の隙間から豆と玉ねぎの匂いが出る。世界を滅ぼす匂いではなく、少し胡椒を入れすぎた昼の匂いだ。

「方針」が「迎える」なら、アサは居間の椅子を客の人数に合わせて動かしている。「手伝う」なら、薪を運び終え、次の仕事をモフに尋ねる。「玄関」なら、名乗りを中断してトトの箱を階段へ載せる。

トトが台所をのぞく。「匙は洗わず置いておいて。味を見るのに使います」。料理をするつもりの声だった。「方針」が「玄関」なら庭の炉へ戻り、それ以外なら家の炉を使って、ケーキを焼き始める。あなたが全部を指図しなくても、他人は持っている手つきで家に入ってくる。

窓から午後の風が入る。鍋は静かになったが、家全体は少しにぎやかになっていた。

- 居間と玄関を見渡し、午後の過ごし方を決める。[09へ](#s09)

<a id="s07"></a>
### 07 背もたれを焼く場所

「方針」が「迎える」なら、トトは台所の大きな炉を選ぶ。アサが居間から見に来て、ケーキの椅子を背景に登場する案を帳面へ書いた。モフは菓子を食べる席まで増やそうとする。

「方針」が「手伝う」なら、トトは薪の量を見て炉の火を整える。アサへ「今度はこの板を水平に」とケーキを持たせた。彼女は剣より慎重に板を運んだ。

「方針」が「玄関」なら、トトは庭へ屋外炉を置き、背もたれを切り分ける。アサが小石の列を延ばし、熱い炉の前を通らず客が歩ける道を作った。

その最中、台所から、こつ、こつ、と足音がした。赤い鍋が扉を抜けてくる。蓋に匙を載せ、誰よりも準備を整えている。

- 動き始めた鍋と一緒に、客の集まる場所へ行く。[09へ](#s09)

<a id="s08"></a>
### 08 勇者と赤い鍋

アサは匙を受け取ると、剣を抜くような姿勢をした。すぐ自分で笑い、肩の力を抜く。

「それだと天井に当たりますね」

彼女が鍋を一周混ぜると、脚が収まった。味を見たアサは、帳面の端へ「手合わせ前に食べると眠くなる量」と書く。明日の作戦にまで関わるらしい。

その間に、あなたとトトは箱を置く。「方針」が「玄関」なら庭へ、「迎える」か「手伝う」なら台所の炉のそばへ運ぶ。トトは自分の炉か家の炉を使い、ケーキを焼き始めた。

アサは匙を洗って戻り、「鍋は済みました。次は私の登場を一度だけ見てほしい」と頼む。引き受けた仕事のあと、自分の用事を遠慮なく持ち出す顔になっていた。

- 勇者の一度だけの登場を見てから、午後の席を決める。[09へ](#s09)

<a id="s09"></a>
### 09 家の真ん中を決める

モフがあなたのところへ戻ってきた。クッションか布巾か案内札を背に載せ、最初に頼んだ方針をまだ覚えている。

風がカーテンを持ち上げた。あなたは台所と居間の窓を順に閉め、掛け金を下ろす。

「方針」が「迎える」なら、居間には客が増えてもよいだけの席がある。「手伝う」なら、炉の前に薪と洗った道具が揃っている。「玄関」なら、外の待つ場所に日陰の長椅子が出ている。アサとトトが、自分たちで使いやすくした結果だった。

魔王が帰るまで、まだ二時間ある。客と食べる午後にも、何かを一緒に作る午後にも、早めに用事を終える午後にもできる。

「鍋」が「まだ」なら、次は動く鍋への対応を選んでください。それ以外なら、以下の四つから選びます。

- 「鍋」が「まだ」なら、廊下を歩く鍋に追いつく。[14へ](#s14)
- 鍋を混ぜてあるなら、居間にスープと茶を出す。[10へ](#s10)
- 鍋を混ぜてあるなら、客と台所を作業場にする。[11へ](#s11)
- 鍋を混ぜてあるなら、客も食事も庭へ連れ出す。[12へ](#s12)
- 鍋を混ぜてあるなら、客の用事をまとめて終え、家を静かにする。[13へ](#s13)

<a id="s10"></a>
### 10 座るための王座

あなたが居間へ器を並べると、モフは入口に寝そべり、入ってくる客の足を拭き始めた。

「方針」が「玄関」なら、モフは札を持って迷う。あなたが「ここからは席へ案内して」と言うと、『用事はこちら』の札を裏返し、『おかわりはこちら』と書いた。

アサは魔王の椅子ではなく、その向かいに座る。明日は相手を倒すための距離を測るが、今日はスープの皿を渡せる距離でよいらしい。

トトは炉へ戻り、ケーキの焼け具合を確かめてから茶を飲む。庭で分けて焼いていたなら、二つをつなぐ甘い糊も持ってきた。

食べ終えた皿を片付けようとすると、アサが自分の分を持った。「見学の続きは、洗い場でもできます」

- 五時の戸の音を、居間で迎える。[15へ](#s15)

<a id="s11"></a>
### 11 作業場の魔王城

トトはケーキの小さな飾りを、あなたとアサへ一つずつ任せた。あなたは背もたれの角、アサは王冠を作る。

「方針」が「迎える」なら、モフがクッションを炉から離し、代わりに作業台を運ぶ。「玄関」なら、外の案内札を洗い場の前へ移し、道具の行き先を示す。「手伝う」なら、並べてあった布巾がようやく全部使われる。

アサの王冠は、角が一本多い。「勇者から見た魔王は、そのくらい大きく見えるので」と本人が説明した。トトは直さず、その王冠が載るだけの砂糖の台を足す。

あなたは合間にスープをよそった。王冠の縁にはアサの指の跡があり、背もたれの角にはあなたの丸いへこみが残っている。トトは二つを並べ、粉砂糖をひと振りした。

- 完成したケーキを、大きな皿へ移す。[16へ](#s16)

<a id="s12"></a>
### 12 庭が客間になる

あなたが長椅子を庭へ向けると、モフは玄関に敷かれていた自分の端をくるりと丸め、外へ出た。草の上で敷物になるのは少し勇気が要るらしく、まず一角だけ試している。

「方針」が「迎える」なら、クッションが後から運ばれる。「手伝う」なら、アサが台所の台を一つ持ってくる。「玄関」なら、すでに並んだ長椅子をトトが炉から少し離した。

「鍋」が「まだ」なら、赤い鍋は自分で客の間を歩き、器を差し出されると止まる。混ぜてあるなら、あなたとアサで鍋を運び、台の中央へ置く。

アサは戸の前に立ち、空の庭へ勇ましく名乗った。今度はモフが拍手の代わりに両端を叩く。トトはケーキの背もたれを掲げ、王座の完成を知らせた。

- 庭で一緒に食べ、帰りの足音を待つ。[17へ](#s17)

<a id="s13"></a>
### 13 用事を終わらせる人

あなたは五時までに台所を片付けたいと伝えた。トトは「では、焼き上がったら冷ます場所だけ借りよう」と答える。最後の焼き上がりを待ち、ケーキを棚へ置く頃には四時になっていた。アサも明日の入口からの距離をもう一度測り、帳面を閉じる。

「方針」が「迎える」なら、モフは余ったクッションを少し惜しそうに積む。「手伝う」なら、アサとトトが最後の道具を洗う。「玄関」なら、外の案内札が早くも『本日の用事は終了』へ変わる。

トトは店へ戻り、ケーキは魔王への贈り物として残す。アサも、明日のために剣を手入れすると言って帰った。二人の用事は終わり、まだ夕方を自分で使える。

あなたは一人分のスープをよそった。モフが隣に丸まった。

- 静かな家で、五時を待つ。[18へ](#s18)

<a id="s14"></a>
### 14 廊下の行進

鍋は廊下の真ん中を、こつ、こつ、と歩いていた。アサが道を空け、トトが匙を持って追いかける。客へ配りに行くと言いながら、客の方がついていっている。

モフが進路へ寝そべると、鍋は行儀よく止まった。敷物を踏まずに回り道を探している。

「通せば庭へ出ます」とモフが言う。「止めるなら、今は混ぜやすいです」

汁はこぼれていない。鍋が動くことで、あなたが最初に思い描いた居間や台所の使い方だけが、少し追い越された。

このまま動く食卓に付き合ってもよい。脚を眠らせて、用意した場所へ戻してもよい。

- あなたが混ぜて脚を眠らせ、居間に食事を出す。「鍋」を「自分」にする。[10へ](#s10)
- あなたが混ぜて脚を眠らせ、台所を作業場にする。「鍋」を「自分」にする。[11へ](#s11)
- モフに道を空けてもらい、歩く鍋と一緒に庭へ出る。「鍋」は「まだ」のまま。[12へ](#s12)
- あなたが混ぜて脚を眠らせ、客の用事を終わらせる。「鍋」を「自分」にする。[13へ](#s13)

<a id="s15"></a>
### 15 魔王の席が空いていない

魔王が帰ると、居間にはスープの匂いがあり、大椅子の上に巨大な椅子型のケーキが載っていた。アサが登場の見え方を確かめたあと、トトが冷ます場所に使ったのだ。

「私の席は」

あなたが普通の椅子を引くと、魔王はそこへ座った。両膝が少し高くなるが、皿は持ちやすそうだ。歯医者から今日の食事は柔らかい物にと言われたらしく、スープを喜んだ。ケーキは明日食べることにする。

「鍋」が「勇者」なら、アサが「本日の鍋は私が」と胸を張る。それ以外なら、あなたは鍋を混ぜたときの丸い手つきを、ついもう一度してしまう。

魔王はあなたの留守番代を渡し、居間を見回した。

「明日もこの椅子に座ろうかな」

アサはすぐ帳面を開く。「登場の角度が変わります」

**結末 E1：普通の椅子の魔王**

<a id="s16"></a>
### 16 角が一本多い

帰ってきた魔王は、ケーキの王冠を見て自分の頭を触った。「増えたか？」

アサが理由を説明すると、魔王は角の多い方を自分へ向けて眺めた。トトは満足そうに腕を組む。あなたの作った背もたれの角は少し丸いが、誰も削り直さなかった。

「鍋」が「勇者」なら、アサはスープも自分が混ぜたと付け足す。魔王は明日の手合わせの前にも一杯出そうと言い、彼女は慌てて「量は少なめで」と答えた。

魔王は柔らかなスープを食べ、ケーキは翌日の楽しみに残した。留守番代を受け取ったあなたが帰ろうとすると、トトが余った飾りを一つくれる。

「今度は、うちの炉に入る椅子を作ろう」

一日だけの留守番の終わりに、小さな菓子作りの誘いが残った。

**結末 E2：王冠を作った午後**

<a id="s17"></a>
### 17 玄関より先に庭

魔王は玄関へ入る前に、庭から自分を呼ぶ声を聞いた。勇者、菓子職人、留守番、敷物。それに赤い鍋。

「鍋」が「まだ」なら、鍋は魔王の前まで歩き、ぴたりと止まる。「混ぜなかったのか」と言う魔王へ、あなたは「庭の配膳を頼みました」と答えた。魔王は匙を一周させ、仕事を終えた脚を眠らせる。

混ぜてあるなら、アサが鍋を持ち上げ、魔王の皿へスープをよそう。誰も決闘の構えにはならない。今日は下見の日だからだ。

ケーキは明日のお祝いに残し、皆で少しずつ家へ戻った。モフは草を二本くっつけているが、外の客間も悪くなかったと言う。

あなたは留守番代を受け取り、振り返る。魔王の家が今日は、戸の外まで広がって見えた。

**結末 E3：歩く食卓の帰宅**

<a id="s18"></a>
### 18 留守番の昼寝

五時、魔王は静かな玄関を開けた。洗った器、閉じた窓、冷めていく椅子型のケーキ。モフは玄関の端で丸くなっている。

「誰も来なかったのか」

あなたが二人の客の話をすると、モフがアサの名乗りをまねた。敷物の低い位置から出る勇ましい声に、魔王は頬を押さえて笑った。歯はもう痛くないが、まだ少し慣れないらしい。
