# GB22 雪原の二番手

## 導入

あなたは雪橇の帆を縫う職人イサです。去年まで三年続けて、冬渡り競争の二位でした。勝ったのは三度ともエン。普段はあなたの仕事場へ来て、帆のほつれを直してくれと頼む人です。

今年の橇は、自分のためだけに縫った青い帆を載せています。幅の狭い機体、よくしなる足踏み板。エンより軽く、踏み込みで短い加速を作れる代わり、長い直線では幅広の帆に押されます。

決勝に出るのは四人。凍った入江を抜け、白樺の曲がり角から河口へ下る一周勝負です。エンが発走線の向こうで手袋を引き、こちらへ顎を上げました。

「今年も、お前の帆を追うところから始めるのか」

いつも先に出て、最後に抜かれてきた。その言い方が気に入らないのは、本当だからです。

## 遊び方と記録

「余力」を2、「先行」の印をなしにして始めます。余力は、この短い競争で強く踏み込める回数です。選択に消費の指示があるときだけ1減らします。0未満にはしません。先行の印は、合流する節でエンとの位置を読むための記録です。

氷や風の性質は、この架空の雪橇競技での条件です。乱数や読速による判定はありません。本文に書かれた障害と自分の記録から選びます。出走前、救援用の太綱は全機に一本ずつ積んであります。[01へ](#s01)進んでください。

## 本文

### 01 旗が上がる前

出発係の赤い旗が、風に向かって大きく膨らみました。エンの帆は張り切らず、上端だけが揺れています。最初の加速をあなたに使わせ、あとから風で追い付くつもりでしょう。

去年のように飛び出せば、曲がり角へ先に入れます。今度は彼の後ろへ入れば、他人の橇が風を裂く感触を使えるかもしれません。横の二人は後ろの発走区画で、旗の落ちる瞬間だけを見ています。

旗が落ちました。足踏み板があなたの靴底を押し返します。

- 強く蹴り、先頭へ出る。余力を1減らし、先行に印を付ける。[02へ](#s02)
- 踏み込みを急がず、エンの背後へ入る。先行はなしのまま。[03へ](#s03)

<a id="s02"></a>
### 02 青が先にある

雪面の白い筋が、両側へほどけていきます。あなたの帆の影だけが前を走っています。最初の歓声は、今年もあなたのためのものでした。

エンがぴたりと後ろへ入ります。振り返らなくても分かります。あなたが風へ押し広げた道を、彼の長い橇が滑ってくる重い音。ここで振り切ろうとすれば、最初の坂でさらに脚を使うことになります。

あなたは膝を柔らかくして、それをこらえました。白樺の曲がり角が見えてきます。内側は短い固雪、外側は広く磨かれた氷。エンが後ろで帆綱を引き、内側を狙える姿勢へ変わりました。

- 先頭のまま、曲がり角で使う道を選ぶ。[04へ](#s04)

<a id="s03"></a>
### 03 誰かが割った風

エンの橇の後ろへ入ると、帆の震えが小さくなりました。自分の呼吸が聞こえます。前にいるエンの右肩だけが、規則正しく上がっていました。

彼は一度こちらを見て、笑いませんでした。帆を左右へ振り、あなたを風の外へ出そうとします。あなたは動きを追い過ぎず、彼の作った太い雪筋を残して走ります。

三年見ていたのは、最後に遠ざかる背中です。今は、その背中がどう風を拾うのかを、初めて近くで見ています。外へ膨らむ前、右肩が下がる。白樺の角へ向かうエンの肩が、まさにその形になりました。

- 残した脚の力を確かめ、曲がり角の道を選ぶ。[04へ](#s04)

<a id="s04"></a>
### 04 二つの弧

白樺の根元を巻く内側は短く、雪が硬い段になっています。踏み込み一回で橇を浮かせれば、刃を引っ掛けずに越えられます。外側の氷は長い弧ですが、帆だけで滑れます。

エンはあなたの先を選ぶのでなく、あなたがどちらへ向くかを見ています。内側で前へ出れば、幅のある彼の橇は同じ隙間へ並べません。外へ開けば、彼は大きい帆を畳んで短い方を抜けるでしょう。

先の低い尾根にはもう一つ、強く踏み込む場所があります。足の力をここで使うか、まだ残すか。白樺の幹が、ぐっと近付きます。

- 余力が1以上なら、内側の段を跳び越える。余力を1減らし、先行に印を付ける。[05へ](#s05)
- 外側の氷を滑り、脚を残す。先行の印を消す。[06へ](#s06)

<a id="s05"></a>
### 05 木の匂いがする距離

橇が白樺のすぐ横へ浮き、枝の粉雪が頬へ当たりました。着地の音は一つ。あなたは短い道を抜け、エンの帆を肩の後ろへ置きます。

指先はまだ余分な力で固くなっています。エンが遅れて同じ角を出てきました。こちらの選んだ跳び方を見て、彼は次の尾根へ少し低い姿勢で向かっています。もう同じ一手では驚かないようです。

尾根の手前には、短く跳べる切れ目があります。脚が残っていれば先へ出たまま越せる。踏み込みが鈍ければ、風を張った帆だけが先へ持ち上がり、霜の枝へ引かれる高さです。脇の広い斜面なら、跳ばずに回れます。

- 余力が1以上なら切れ目を跳ぶ。余力を1減らし、先行を付けたまま進む。[07へ](#s07)
- 脇の斜面へ回り、エンの進路を見ながら下る。先行の印はそのまま。[08へ](#s08)
- 余力が0の場合でも、帆の力で強引に切れ目を越えようとする。帆が枝へ触れる危険は見えています。[09へ](#s09)

<a id="s06"></a>
### 06 橇一台ぶんの貸し

エンは内側から抜け、すぐにあなたの正面へ入りました。雪煙が頬へ飛びます。彼がこちらを見ずに左手を開いたのは、先に行く、といういつもの合図です。

あなたは握り返しません。外側の氷はよく滑り、脚にはまだ力が残っています。エンが大きい帆を張り直すあいだ、白樺の先の低い尾根が近付いてきました。

尾根の切れ目は、軽いあなたの橇なら一度の踏み込みで越せます。エンは長い橇を脇の斜面へ向けています。ここで跳べば前へ出られる。彼の後ろで斜面へ入れば、河口の長い直線まで脚を残せます。

- 切れ目を跳び、前へ出る。余力を1減らし、先行に印を付ける。[07へ](#s07)
- エンの後ろから広い斜面へ回る。先行はなしのまま。[08へ](#s08)

<a id="s07"></a>
### 07 見えた手袋

あなたの橇は尾根を越えました。着地を吸った足踏み板が大きくしなり、青い帆が頭上で音を立てます。

下の斜面から金属の短い音がしました。エンの片刃が埋もれた根に挟まり、橇が横を向いています。本人は雪へ尻をつき、帆を落として風を逃がしました。あなたへ向けて手袋を上げます。立てるという合図です。

彼は刃を抜こうとしていますが、一人で押すともう片側が雪へ沈みます。曲がり角の救援係も走り始めました。あなたが綱を引けば、係員より早く機体を戻せます。ただし後ろの二人は、もう尾根の入口へ来ています。

- エンの上げた手へ自分も手を上げ、そのまま競争を続ける。[11へ](#s11)
- 橇を止め、救援綱を持って斜面へ下りる。[10へ](#s10)

<a id="s08"></a>
### 08 肩で言い返す

先行の印があるなら、あなたが斜面へ先に入り、エンが一台ぶん後ろから降りてきます。

先行の印がなければ、エンの帆を前に見て、あなたが一台ぶん後ろから斜面へ入ります。

根の露出した低い縁を避け、二人は広い雪の帯を滑っています。

エンがあなたを見て、帆を外へ膨らませました。彼の得意な長い直線へ誘う動きです。河口の風は下流へ吹いていますが、斜面の出口だけは岩に遮られています。ここで一度強く踏み込めば、彼が帆を張る前に前へ出られます。

あなたが姿勢を低くすると、エンの口元が引き締まりました。初めて、彼の方がこちらの足を見る。出口の影が、すぐそこです。

- 余力が1以上なら、影のうちに踏み込んで先頭へ出る。余力を1減らし、先行に印を付ける。[11へ](#s11)
- 脚を使わず、エンの帆が開くまで追う。先行の印を消す。[12へ](#s12)

<a id="s09"></a>
### 09 裂けた青

踏み板は沈みましたが、戻す脚が足りませんでした。橇の鼻が尾根へ当たり、帆だけが上へ引かれます。霜の枝が、青い布へ長い白線を引きました。

あなたは帆綱を放し、膝で橇を押さえます。機体は雪へ腹を付けて止まりました。指を開くと、震えてはいますが動きます。救援係が駆け寄り、あなたの返事を聞いてから、裂けた帆を下ろしてくれました。

縫い目は残っています。裂けたのはその横。昨夜、少し薄すぎるかもしれないと迷った部分でした。

河口へ下る道は見えます。帆を畳めば、橇を歩いて運べます。競争を終えた人の歓声が、風に運ばれてきました。

- 係員の手を借りて帆柱を倒し、自分で橇を終着線まで引く。[16へ](#s16)

<a id="s10"></a>
### 10 抜けない刃を引く

「来るな、行け！」

エンはあなたの綱を見て叫びました。あなたが橇の横木へ結ぶと、今度は叫ぶのをやめ、反対側へ体を入れます。合図を一つ合わせて引きました。刃が根から抜け、二人そろって雪へ背中を打ちます。

その上を、残る二台の帆が通り過ぎました。

エンは起きるなり橇を立て、あなたの綱を手渡します。「借りたまま走ったら、お前も引っ張るところだった」

息が苦しくて、あなたは笑えません。彼も笑っていませんでした。優勝はもう前の二人の争いです。それでも河口までの道は、まだ残っています。

- 橇へ戻り、エンに「三位は譲らない」と告げて走り出す。[14へ](#s14)

<a id="s11"></a>
### 11 最後の横風

あなたの橇が先に河口へ出ました。見物人の並ぶ堤が右へ流れ、終着線の黒い杭が、まだ小さく前に見えています。

しばらくして、後ろからエンの刃の音が近付きました。彼は右へ出て、大きな帆へ横風を受けようとしています。その上端はまだたるみ、開き切るまでには少し間がありそうです。

堤の旗が、一斉にこちらへ向きました。短い機体なら、小さく風上へ曲がれます。ただし曲がる瞬間には速さが落ちる。真っすぐの雪筋は終着線へ最も短く続き、さっきからよく滑っています。エンの橇の先端が視界の端に出ました。

- 橇を風上へ浅く向け、エンが広がる先の風を自分の帆へ取る。[13へ](#s13)
- 余力が1以上なら、最後の一踏みで押し切る。余力を1減らす。[13へ](#s13)
- 向きを変えず、残った速さで真っすぐ終着線を目指す。[15へ](#s15)

<a id="s12"></a>
### 12 帆の陰から

エンの大きな帆が開き、あなたはその後ろへ入ります。風が薄くなり、青い帆が一瞬たるみました。彼の橇が作る溝は、あなたのものより深い。その真ん中ならよく滑れます。

エンは振り返りません。あなたが同じ線にいることを知っています。彼が風上へ寄ると、こちらも風を拾い直さなければなりません。離れる瞬間を選べるのは、一度だけです。

遠くの杭を結ぶ赤い縄が見えました。縄そのものは高く上げてあり、その下を橇の先が通った順に決着します。そこまで滑り切るだけなら体は動く。横へ飛び出すには、脚に残した一回が要ります。

- 余力が1以上なら、帆の陰から踏み出して並び、そのまま小さい橇を先に入れる。余力を1減らす。[13へ](#s13)
- エンの線を最後まで追い、今ある速さで走り切る。[15へ](#s15)

<a id="s13"></a>
### 13 一番手の背中

**結末 E1：一台ぶんの空**

赤い縄が頭上を過ぎました。終着係の腕が、あなたへ向かって上がります。後ろでエンの橇が雪を削り、すぐ隣へ止まりました。

あなたは帆綱を握ったまま、まだ前へ体を倒しています。もう踏み込まなくていいのだと、脚より遅れて頭が理解しました。

一番。声に出す前に、息が変な形で漏れます。エンは自分の手袋で頬の氷を払い、あなたの青い帆を見上げました。

「今度は、最後まで見てた」

あなたが振り向くと、彼は口を曲げます。「お前の背中だよ」

表彰台へ向かう途中、帆の端を彼につかまれました。縫い方を教えてくれと言われるかと思い、あなたは一度強く引き返します。エンの手には、小さな氷の塊が残っていました。帆へ付いたものを落としただけです。

あなたは笑って、帆を自分の肩へ巻きました。今年の一位の橇は、仕事場へ帰ってからも他人の注文品にはなりません。

<a id="s14"></a>
### 14 三位のための全力

**結末 E2：まだ終わらない相手**

先に入った二人が堤で振り返っていました。あなたとエンは、そこからもう一度速くなります。

刃を抜くために一緒に引いた腕が、いまはそれぞれの帆を引いていました。エンが外へ出れば、あなたは内へ寄る。あなたが前へ出れば、彼は雪煙へ潜る。最後の杭で、あなたの橇の先が半分だけ先に入りました。

三位でした。表彰台は一段だけあり、呼ばれたのは別の名前です。あなたは悔しさを飲み込み、飲み込めなかった分だけ、帆をきつく巻きました。

エンは四位の札を受け取り、あなたの橇へ戻ってきます。

「助けたから勝たせてくれるとでも思ったか」

「思ってたら、追い越してない」

彼は初めて笑いました。それから、自分の刃を引いた太綱をあなたの荷台へ、ほどきやすく巻き直しました。

帰りの坂でも、二台は並びませんでした。少し前へ出るたび、もう片方が追ってきます。日が暮れるまで、三位と四位の競争は終わりませんでした。

<a id="s15"></a>
### 15 二番手の顔

**結末 E3：見上げない表彰台**

エンの帆が先に縄をくぐりました。あなたは一台も離されずに続きます。去年までより短い差でしたが、旗の向く先は変わりません。

止まってから、あなたは足踏み板を靴で一度押しました。板はまっすぐ戻ります。橇のせいにするには、よく出来すぎています。

エンが二位の札を持ってくると、あなたは手を伸ばして受け取りました。「惜しかった」と言われるより前に、「どこから抜く気だった」と尋ねます。

彼は河口の岩を指しました。次にあなたが自分の思っていた場所を指すと、少しだけ眉が上がります。

「そこは、嫌だった」

嬉しくなりかけて、あなたは首を振りました。嫌がらせたくて走ったのではありません。勝ちたかった。その気持ちは、札を受け取っても薄くなりませんでした。

仕事場へ帰ると、青い帆を棚にしまわず、天井へ広げます。縫い直す場所を、今夜はまだ決めません。まず、最後にエンの橇がどう傾いたかを、空いている床へ描きました。

<a id="s16"></a>
### 16 青い布を引いて

**結末 E4：橇の歩幅**

帆柱を倒した橇は、思ったより重くありませんでした。雪へ擦れる音を聞きながら、あなたは終着線へ歩きます。声援は小さくなりましたが、赤い縄はまだ上にありました。

エンが堤を降りてきます。橇を押そうとしたので、あなたは首を振りました。彼は手を引き、代わりに倒した帆柱が横へ振れないよう、端を持ちます。引いているのはあなた、柱を持っているのは彼。そのまま二人で縄の下へ入りました。

帆を広げる頃には、表彰式が始まっていました。人前で失敗した青い布は、仕事場で試すどの布よりも、はっきり弱いところを見せています。

「それ、直せるか」

エンが聞きました。

「直すだけなら、今夜」

言ってから、あなたは裂け目の両側を離しました。「でも、同じ形にはしない」

エンは頷き、帆柱をあなたへ返しました。帰りは歩きです。歩く速さなら、雪原の曲がり角が、いくつも別の形に見えました。

この節の検証記述は2026-10-21の原稿作成時点です。ゲーム実装後の仕様と確認結果は[実装記録](../../SHORTS_21_40_IMPLEMENTATION.md)を参照してください。

### 体験の核

三年二位だった主人公が本当に勝ちたい競争。前へ出る快感、脚を残す我慢、相手の大きな帆へどう対抗するかを行為にする。優勝を道徳的に疑わしい報酬へしない。救援後も「助けたから実質勝利」と言い換えず、優勝を逃した悔しさと残った競争を14で同時に描く。

### 固定前提と仕組み

四人の決勝、一周の架空の帆付き雪橇競技。軽い主人公機は二度まで強く踏み込める。余力は全身の健康値ではなく、この競争で確実に加速・跳躍へ使える回数。0でも帆走・歩行・短い共同救援はできる。内側の段と尾根の切れ目は踏み込み一回を要し、最終直線の帆の陰から出る行為にも一回を使う。風上への小さな進路変更は機体の短さを使い、同じ消費に数えない。

07の事故は、エンが広い斜面の低い縁を通る競走線で根に刃を取られた結果。主人公も広い帯を通る08では、エンが相手を見て中央寄りに並走し、この根を通らない。単に主人公が助けを選ぶための事故を全経路へ追加しない。救援係は初めから曲がり角にいる。07で本人の安全を確かめられ、継続は見捨てて死亡させる選択ではない。07を通って11へ進む間に係員がエンの機体を抜く。主人公はその作業を見たとせず、11の記述を現在のエンの再追走として読む。

### 人物ごとの欲望と反応

イサは職人としても走者としても自分の機体で勝ちたい。既知の傾向へこだわる02、相手の背中を読む03、足が足りないと知りつつ飛ぶ09、最後まで勝ちを諦めない15に同じ欲望の異なる働きを置く。

エンは相手を二番手へ固定したいだけの人物ではなく、自分も勝つために追随、内側の追越し、外への誘い、最後の帆走を選ぶ。03ではいつもと違う出方を受け、笑うのをやめる。救援を最初は断るが、綱が掛かれば共同作業へ切り替え、終われば再び勝負する。13の言葉、14の綱の巻直し、15の戦術の返答、16の帆柱だけを支える動作を分ける。

### 主な選択と回収

発走で使う一回は曲がり角以後へ持ち越す。04の内側は先頭を買う選択、外側は脚を残す選択で、その後も別の勝ち筋がある。07の救援は明示された後続二台の通過を招き、14の三位へ実際に残す。11の現在位置から風を取る戦術と、12の後ろから脚で出る戦術は別。単に余力が大きければ自動的に勝つ設計ではない。

### 自然な代案と核の再評価

安全な広い斜面、序盤を他人の後ろで走る、救援係へ任せる、帆を畳んで歩く方法を採用。安全策を失格や怪我へ変えない。最初から優勝を狙わず完走する読みも可能だが、主人公の勝ちたい意志と、その意志をどう行動へするかを中心に据える。障害そのものを修理・撤去する時間は、開催中の短い競走には使わない。
