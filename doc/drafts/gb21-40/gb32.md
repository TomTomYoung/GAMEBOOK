# GB32 砂漠の競売人

## 導入

あなたの茶屋は、荷車一台でできている。茶釜と椅子三脚、祖父の看板、それに風の強い日は役に立たない日除け。

茶の味は悪くない。客も来る。けれど毎年この市場へ着くたび、あなたは、客が用もなく長居する店をうらやましく思う。今日の競売には、そんな場所が一つ出る。

「折り庭、一式。敷物を開けば、石の腰掛けと木陰が現れます。畳めば荷車の屋根に載る。碧香樹の根付き株も込み」

競売人が指を鳴らすと、台の上に小さな庭が開いた。枝の影が三つの腰掛けを渡る。茶を飲み終えた客が、もう少し座っていたくなる影だった。

あなたは店の改良用に貯めた金貨十枚を握る。旅費と明日の仕入れは、別の財布に入っている。

## 遊び方と記録

01から始めてください。記録は「残金」だけで、最初は10です。選択肢に書かれたときだけ更新してください。代金は金貨で、1は一枚です。

この市場では、上乗せは金貨一枚単位で、何枚分をまとめて上げてもかまいません。競売人が槌を打つまでは、値を上げる、降りる、共同の買い手を申し出ることができます。一つの品はまとめて売りますが、買ったあとの使い方や部品の譲渡は買い手が決めます。品の途中で一度、茶の休憩が入り、その間はほかの参加者と話せます。

本稿では競りの要所で選びます。数字を自由入力したり、ほかの人の内心を記録したりする必要はありません。普通の日除けでも茶屋は営業できます。「庭を買えないと旅が終わる」という賭けではありません。

## 本文

<a id="s01"></a>
### 01 影を買いに来た人

庭の周囲に、二人が長く立っている。

青い服の女は腰掛けに座り、立ち、木の後ろへ回る。何かから隠れるように身をかがめ、同行の少年に笑われた。香料商のオルンは庭に入らず、枝先へ鼻を近づけている。あなたの茶屋にも来る男だが、茶を褒めるときさえ、飲み終える前に取引の話を始める。

競売人は次の品を説明している。庭の番まで、少し時間がある。

- 折り庭の足元と、畳む仕組みを見ておく。[02へ](#s02)
- 青い服の女に、庭で何をするつもりか尋ねる。[03へ](#s03)
- 自分の席を取り、競りが始まるのを待つ。[04へ](#s04)

<a id="s02"></a>
### 02 庭の裏側

売り手は敷物の縁を持ち上げた。裏には、折る順番を示す丸い印が三つある。腰掛けも木もその折り目に収まり、土はこぼれない。木陰は枝が作る普通の影で、夜になると特別明るくなるような品ではなかった。

根元には、小さな株が一つ、別の陶器に植わっている。

「去年、親木から分けたものです。鉢ごと外せます。大きな木は残りますよ」

あなたは日除けの代わりとしてだけでなく、長く使える店の道具として庭を見る。畳む前に枝をひもで寄せる一手間は必要だ。今日の夜に使い、明日朝に片付けても出発には間に合う。

オルンがその小鉢を指で回した。親木より、こちらを熱心に見ている。

- 青い服の女にも声をかける。[03へ](#s03)
- 品物から離れ、競りの席へ向かう。[04へ](#s04)

<a id="s03"></a>
### 03 姫が隠れる木

女はセラと名乗った。旅の劇団の座長だ。

「今夜、王子が姫を探す劇をやるの。うちの姫は、この子」

少年はひげを描いた顔で会釈した。今夜の姫は父王に変装して逃げるらしい。

「背景の木を、昨日やぎに食べられた。紙だったからね。この木なら姫が隠れるたび、観客の方へ葉が揺れるでしょう」

セラは金貨六枚を、手の中で数え直した。それ以上は出さない。明後日の船賃を庭へ変えるつもりはないと言う。

「ただ、持ち主になることより、今夜使えることが大事なの。あなたの茶屋にこれがあったら、役者は絶対居座るわ」

庭の腰掛けが、あなたには初めて舞台の道具に見えた。

- 開始を告げる鈴を聞き、席に戻る。[04へ](#s04)

<a id="s04"></a>
### 04 六、七、九

競売人が五枚から呼びかけ、青い服の女が「劇団のセラ、六枚」と言った。オルンは指を二本上げる。

「九枚。細かく刻む時間を節約しよう」

「節約していただいた時間で、お茶にします」と競売人が応じた。槌はまだ台に置かれたままだ。

あなたが十枚を出せば、オルンより上になる。彼は従者に「九までだ。店の予算をここで使い切るな」と話していた。セラは財布を閉じ、庭の枝を見ている。

庭そのものが欲しい人は、自分だけなのかもしれない。あるいは、今はそう見えるだけかもしれない。茶の休憩の間なら、まだ話せる。

- 十枚を提示し、自分一人で落札する。「残金」を0にする。[05へ](#s05)
- オルンに、どの部分が欲しいのか聞く。[06へ](#s06)
- セラに、今夜の庭の使い方を持ちかける。[07へ](#s07)
- 競りを降り、オルンの九枚に任せる。[08へ](#s08)

<a id="s05"></a>
### 05 槌の音のあと

「十枚」

あなたの声は思ったより大きかった。オルンは肩をすくめ、セラは小さく拍手をした。ほかに札は上がらず、槌が鳴る。

金貨を十枚並べると、売り手は折り庭の縁に付いていた自分の名札を外した。代わりにあなたの茶屋の看板を、腰掛けに立てかける。

急に、客の入っていない店ができた。うれしさのすぐ隣に、空いた財布を確かめる癖が残る。予定していた改良用のお金は使い切ったが、明日の茶葉を減らす必要はない。

セラが庭の外から「今夜だけ借りる相談、まだしていい？」と聞いた。

- 庭を一度開き、今日どう使うか考える。[09へ](#s09)

<a id="s06"></a>
### 06 小鉢一つの値段

オルンは「碧香樹の若い株だ」と即答した。店で育てている木は雄株ばかりで、この株と合わせると来年の花の香りを比べられるらしい。

売り手が小鉢を外し、独立した底を見せる。庭の大きな木は、そのまま残る。

「この小鉢を三枚で買えるなら、私は競りを降りよう。庭の持ち主は誰でもいい」

オルンは競売人にも聞こえる声で言った。セラはすぐに財布を開き直す。「私が落札しても、その小鉢は三枚で譲る。だったら、私は六枚のままいる」。あなたに遠慮して降りるつもりはないようだ。

オルンが降りれば、あなたは七枚で庭を買える。小鉢を渡して三枚を受け取れば、手元には六枚残る。セラへ譲れば、庭は彼女の舞台になる。

- 七枚で落札し、オルンに小鉢を渡して三枚受け取る。「残金」を6にする。[09へ](#s09)
- セラの六枚を残し、「舞台の隣で茶を売らせて」と誘う。残金は10のまま。[12へ](#s12)

<a id="s07"></a>
### 07 三枚分の夜

セラは、あなたと自分の財布を順に見た。

「共同で買って、明日から所有権でもめるのは嫌。庭はあなたのものにして、私は今夜の使用料を三枚、先に払う。それならどう？」

彼女が先払いし、あなたが十枚で落札すれば、手元は三枚になる。今夜は庭を劇に使い、終演後に返す。あなたの茶屋は舞台の脇で営業しても、一晩休んでもよい。

セラは続ける。「ただし姫が木の陰で転ぶのは台本。心配して駆け込まないで。去年、果物屋が王子を押しのけて助けちゃった」

あなたの庭が始まる最初の晩に、知らない役者たちの足跡が付く。それを面白いと思うか、最初は自分の店にしたいと思うか。

- 三枚を受け取り、十枚で落札して今夜の舞台に貸す。「残金」を3にする。[13へ](#s13)
- まだ約束はせず、オルンが欲しがる部分を先に聞く。残金は10のまま。[06へ](#s06)
- この買い方は選ばず、競りから降りる。残金は10のまま。[08へ](#s08)

<a id="s08"></a>
### 08 勝った人の荷車

あなたが手を上げないと、競売人は九枚を三度呼び、槌を下ろした。オルンの従者が庭を畳み始める。

セラはすぐ少年を呼び、「木は客席に想像してもらおう。隠れているときは、誰より堂々と立ちなさい」と言った。少年は胸を張る。庭がなくても今夜の劇をやめるつもりはない。

オルンはあなたに「茶屋に欲しかったんだろう」と声をかけた。慰めなのか、商談の入口なのか、まだわからない。

あなたの財布には十枚ある。市場の反対側では、普通の丈夫な日除けが四枚で売られている。庭に並べたかった三脚の椅子は、荷車で待っている。

- 四枚で日除けを買い、今日の茶屋を開く。「残金」を6にする。[10へ](#s10)
- オルンに「その庭で、茶を一杯おごらせて」と言う。残金は10のまま。[11へ](#s11)

<a id="s09"></a>
### 09 持ち主の最初の仕事

庭はあなたのものになった。折り目の丸い印を順に合わせると、荷車に積める大きさに収まる。もう一度開くと、石の腰掛けが影を待っている。

残金が6なら、小鉢はオルンの胸に抱えられている。彼は鼻を近づけすぎて葉にくすぐられ、くしゃみをした。残金が0なら、小鉢は親木のそばにあり、あなたは帰りの旅で二つの鉢へ水をやることになる。

セラが三枚を差し出す。「今夜一晩、うちの木になってくれる？　明日はあなたの茶屋へ返す」

あなたは最初から自分の茶屋として庭を開いてもよいし、今夜を舞台に渡してもよい。どちらでも、庭を持って明日出発できる。

- 今日は自分の茶屋として開く。残金はそのまま。[15へ](#s15)
- 三枚の使用料で、今夜の庭を劇団に貸す。「残金」に3を足す。[13へ](#s13)

<a id="s10"></a>
### 10 布を張る

新しい日除けは、庭ほど美しくはない。縫い目が太く、端に重りが入っている。商人は風の来る方へ向けて張り、あなたに縄の持ち方を見せた。

自分の店へ戻ると、椅子を三脚とも客の方へ向ける。いつも一脚は荷物置きにしていた。長居してほしいと思いながら、どこかで自分の荷物を優先していたのだ。

セラの少年が通り、「木がなくなったから、姫が砂漠を横切る話になりました」と言って笑う。あなたは最初の茶を注ぎ、今夜見に行くと答えた。

庭は買わなかった。今日の店を変える仕事は、それでも残っていた。

- 湯を沸かし、三つの席を客へ空ける。[14へ](#s14)

<a id="s11"></a>
### 11 一杯から始まる値段

オルンは少し驚いた顔をした。「私の庭で、君がおごるのか」

「今日は、ここに座ってみたかったから」

あなたは荷車から茶器を持ってきた。オルンは庭を畳む手を止めさせる。従者の分も注ぐと、その従者が真っ先に腰掛けた。

茶を飲みながら、オルンは小鉢を撫でる。「本当は、これが目当てだった。庭は店先には大きすぎる。今夜うちへ来ないか。香りを客に見せるとき、君の茶があるといい」

彼は店先で使う間の茶代を払うと言う。庭をあなたへ贈る話ではないが、競りの勝ち負けとは別の入口ができた。

- 今夜、香料店へ茶釜を持っていくと答える。[18へ](#s18)

<a id="s12"></a>
### 12 姫のための茶屋

セラの六枚で槌が鳴った。オルンは彼女へ三枚払い、小鉢を受け取る。セラは残った三枚を見て「船の上で卵が食べられる」と言った。

あなたの茶屋を舞台の横に出す提案には、その場でうなずいた。代わりに、開演中は姫が隠れる側へ客を通さないでほしいという。

「お茶を注文するふりで逃げる場面を足そう。あなた、嫌なら役はしなくていいけど」

あなたは一つだけ返事を考える。「姫でも王子でも、代金は同じです」。セラは手を叩いた。

庭を自分の店にする予定は変わった。今夜は、知らない劇の中に茶屋を開く。

- 茶釜を舞台の脇へ運ぶ。[16へ](#s16)

<a id="s13"></a>
### 13 木陰の持ち主

槌のあと、セラはすぐに庭の周りへ縄を張った。役者たちの足の位置を決める縄だ。あなたにも端を持たせる。

「店を開けるならこっち。姫が逃げてくるから、釜は一歩下げて」

あなたが庭を持っていることと、今夜の舞台を彼女が作ることは、簡単に両立した。木を無理に曲げたい役者には、セラの方が「それは借り物」と止める。

あなたは釜を下げ、舞台の脇に看板を出した。姫が稽古中に茶を本当に飲んでしまい、王子が迎えに来ても立たない。皆が笑う。今夜の売上はまだわからないが、庭が使われる景色はもう始まっている。

- 開演の灯を待つ。[17へ](#s17)

<a id="s14"></a>
### 14 席が三つある店

夕方、最初の客が茶を飲み終えても立たなかった。二人目が市場の裏道を尋ね、三人目がその話に口を挟んだ。

新しい布の下に、庭で見た石の腰掛けはない。それでも三つの椅子に三人が座ると、あなたは釜の向こうから会話に加わりたくなった。

残金は6。次に買いたい物は、客が荷物を置ける小さな台だ。競りに負けた埋め合わせではなく、今日の客を見て思いついた。

閉店してから劇を見る。木のない舞台で、姫は王子の目の前に堂々と立ち、観客にだけ隠れているつもりの顔をした。

**結末 E1：木陰を買わない商売**

<a id="s15"></a>
### 15 あなたの庭

看板を枝から吊るすと、祖父の店の名が葉の影に揺れた。最初の客は茶を頼む前に「座っていていいか」と聞いた。

「そのための店です」とあなたは答える。

残金が0なら、二つの鉢に水をやってから店を開ける。残金が6なら、残したお金で何を買うかは後で考えることにし、親木の枝に茶巾を掛ける。

今夜の劇は広場の別の一角で始まった。セラはあなたの庭へ未練を言いに来ず、自分の劇を作っている。あなたも自分の最初の客に、二杯目の茶を注いだ。

**結末 E2：用のない客を待つ**

<a id="s16"></a>
### 16 姫でも代金は同じ

姫は本番で、大きく転んだ。観客が息をのみ、あなたは釜を押さえる。次の瞬間、姫は匍匐前進で茶屋へ来て「父には内緒で」と注文した。

あなたが用意した一言を返すと、広場が笑った。

庭はセラのものだ。あなたの財布には改良用の10が残り、今夜の茶の代金は別の皿で少しずつ増えた。いくらになるかより、自分の店の名前が劇中で呼ばれるのがうれしかった。

終演後、セラが次の町を教える。「また隣に来る？」。あなたは旅程帳を開いた。今夜は庭を持ち帰らず、次の客がいる方角を一つ増やした。

**結末 E3：持たない庭の隣で**

<a id="s17"></a>
### 17 最初の足跡

終演後、セラたちは縄を外し、腰掛けを拭いた。木の枝には、姫のひげに使った紙が一片引っかかっている。少年が取ろうとしたので、あなたは「それは明日の客に話すために、少しだけ」と止めた。

あなたは残った金貨を袋へ戻した。残金が3なら、次の町で買う茶器は一つずつ選ぼうと思う。残金が9なら、日除けを買い替えるつもりだった金で、今度は何を試そうかと考える。翌朝、庭を畳んで自分の荷車へ載せる。

新しい茶屋の最初の一夜は、あなた一人の思い描いた形とは違った。けれど次の町で庭を開くとき、椅子を置く場所だけはもう決まっていた。姫が茶を飲んで立たなかった、あの場所だ。

**結末 E4：開店前夜の芝居**

<a id="s18"></a>
### 18 高い買い物をした客

香料店で、オルンは小鉢を店の中央に置いた。折り庭は入口の脇に開き、あなたの茶釜と客を迎えた。

「九枚の庭だ」とオルンが自慢すると、従者が「小鉢では？」と口を挟む。あなたは笑い、彼にも茶を注いだ。

今夜分の茶代は受け取った。改良用の残金は10のまま。庭を今後どう使うかはオルンの仕事で、あなたの店がここに移ったわけではない。それでも閉店間際、彼は茶の香りを初めて取引の言葉に変えずに褒めた。

帰り道、あなたは競売人の槌の音を思い出す。あの音で決まったことは確かにある。そのあと、まだ持ちかけられる一杯があった。

**結末 E5：一杯のあとに続く話**

## 作者用設計メモ（読了後）

この節の検証記述は2026-10-21の原稿作成時点です。ゲーム実装後の仕様と確認結果は[実装記録](../../SHORTS_21_40_IMPLEMENTATION.md)を参照してください。

### 体験の核

同じ品を求めていても欲しい部分と用途は違う、と会話と取引で発見する競売劇です。落札の勝敗だけでなく、自分の店を開く、他人の舞台へ貸す、所有を譲って商売に参加する、普通の設備を買う、落札者を客として誘う体験を分けます。最大効率の購入法は存在し、それを見つけても核は消えません。核を「絶対に誰かが損する競争」としていないためです。

### 固定前提と仕組み

折り庭と碧香樹は架空です。庭は移動できる舞台・店舗設備で、生活必需の水や食糧を生みません。最低額5、セラの上限6、オルンの上限9が本文で現れ、主人公の上限10は公開済みです。競りは槌まで撤回可能という作中ルールを持ちます。02の独立した小鉢は06でも売り手が示すので、見学を省いた読者もその場で取引を判断できます。小鉢を譲ることで大木まで枯れる罰はありません。

### 人物ごとの欲望と反応

主人公は居心地のよい店を欲しています。セラは所有より今夜の上演を望み、03で用途と予算、07で具体的な先払い案を出します。競りに負けても08で木のない演出へ変えます。13では借りた庭を守り、舞台の運営権を実際に行使します。オルンは香料用の若い株を求め、04で高い札、06で撤回と購入、11で客を迎える仕事への誘いを出します。親切に変身したから協力するのではなく、自分の用途を満たすために提案を変えます。

### 主な選択と回収
