# GB21 百足椅子の晩餐

ドラフト第1稿／設計モデルv1.2b／作成日2026-10-21／ゲーム実装済み（2026-10-23）

## 導入

あなたは家具職人の見習いコノです。大伯母ベラの晩餐会へ、今年初めて客として呼ばれました。これまでは子供部屋でパン籠を持たされていたのです。新品ではないけれど、ちゃんとした燕尾服。胸には自作の木のボタン。今夜こそ、食卓の人々に名前で呼ばれたいと思っています。

もう一つの目当ては、料理人タムの焼く洋梨の大パイです。屋敷の窓より幅が広いという噂を、あなたは八歳の頃から信じています。

食堂には銀の皿が並び、椅子にはそれぞれ百本の細い脚がありました。ベラは杖で自分の椅子を一度たたきます。

「脚は机の下に。これはあなたにも、椅子にも言っているのよ」

## 遊び方と記録

記録するのは「拍子」の印一つです。初めはありません。選択肢に指示があるときだけ印を付け、読み返しでは変更しません。印は椅子を歩かせる拍子を自分で試した記録です。

本文に時計の判定はありません。場面に書かれた出来事は、節を進むことで起こります。選択を読んでいる時間で料理が冷めることはありません。[01へ](#s01)進んでください。

## 本文

<a id="s01"></a>
### 01 席札のある席

席札には「コノ様」とあります。あなたがそれを見つめていると、隣の貿易商が首を伸ばしました。

「パン籠の子が、ずいぶん大きくなった」

コノです、と返す直前、椅子が前へ出ました。膝が卓の裏へ当たり、スプーンが唇を通り過ぎます。椅子の前脚は、床に落ちた丸パンを追っているようです。パンは転がり、百本の脚が小さく波打ちました。

あなたが椅子を戻すと、椅子はまた半歩進みます。貿易商は会話のために身を寄せたのだと思ったらしく、海運税の話を始めました。後ろでは給仕がスープ壺を持ったまま、あなたの移動に合わせて横歩きしています。

- 卓の下へ身をかがめ、椅子の動きを調べる。[02へ](#s02)
- 客らしく座ったまま、靴で椅子を押さえ込む。[03へ](#s03)
- 給仕へ小声で助けを求め、厨房のタムを呼んでもらう。[04へ](#s04)

<a id="s02"></a>
### 02 卓の下の舞踏会

長い卓布の向こうでは、二十四脚の椅子が、ほとんど同じ方向へ足先を向けていました。丸パンの匂いを嗅いでいるのかと思いましたが、パンはもう止まっています。まだ動いているのは、遠くで鳴る楽団の靴です。

あなたは指で床を二度たたきました。椅子の前脚が二歩出ます。三度目を打たず手を止めると、後ろ脚がそろいました。踵でも同じことができます。

座面の裏には、古い金文字で「ベラと百足楽団」とあります。客の椅子になる前、この家具たちは何をしていたのでしょう。卓布の隙間から、ベラの片足も二度だけ動くのが見えました。

- 二歩と休みを踵で試し、「拍子」に印を付けて卓の外へ出る。[07へ](#s07)
- 「拍子」に印を付け、今度はタムに、この椅子で料理を食べる方法を尋ねる。[04へ](#s04)

<a id="s03"></a>
### 03 作法の綱引き

両足で床を踏ん張ると、椅子も百本の脚を突っ張りました。足の数では負けています。あなたの腰だけが少しずつ前へ滑り、燕尾服の裾が座面に取り残されました。

「たいへん熱心にお聞きになる」

貿易商が喜んでいます。あなたは鼻先のスープを吸わないように、浅くうなずきました。ベラの口元が、グラスの縁に隠れます。

いま、卓布の端が手の届く所にあります。強く引けば体は戻せそうですが、その上には銀器が乗っています。足元を調べるなら、膝を折って卓の下へ潜る余地もあります。

- 卓布を引いて、まず自分の体勢を戻す。[05へ](#s05)
- 見栄をいったん引っ込め、卓の下で脚の動きを見る。[02へ](#s02)

<a id="s04"></a>
### 04 厨房から来た雷

タムは長い木べらを肩に担いで現れました。あなたの椅子を一目見て、顔をしかめます。

「今年もか。去年は魚料理を追い越したんだぞ」

ベラが聞こえないふりをします。タムは椅子の鼻にあたる飾り木を木べらで軽く押し、進路を厨房の扉へ向けました。椅子は素直に向きを変えます。力で止めるより、行き先を与える方が好きらしい。

扉の奥から、甘い焼き汁の匂いがしました。タムはあなたの名札を見ずに「コノ、窯から出すのを手伝え」と言います。先ほどから初めて、パン籠以外の呼び名が聞こえました。

- 椅子に乗ったまま厨房へ入り、パイを出すのを手伝う。[06へ](#s06)
- 料理が来るまでに椅子の扱いを覚えようと、食堂脇の広間へ向かう。[07へ](#s07)

<a id="s05"></a>
### 05 銀器は意外によく滑る

あなたが卓布をつかむと、椅子は後ろへ進みました。銀器の列が一斉にあなたへ近付きます。給仕が壺を持ち上げ、貿易商がグラスを持ち上げ、ベラが燭台を持ち上げました。

誰も何も言わない一秒のあと、卓の中央にあった大きな花瓶だけが、するすると滑ってきます。あなたは両腕で受け止めました。百本の脚は花瓶の重みに驚き、ぴたりと止まります。

「コノ様、お花のご注文ですね」

給仕が言い、今度はベラが声を立てて笑いました。あなたは花瓶を床へ置きます。いつの間にか食堂の全員が、あなたを見ています。

- 見られているうちに腕前を見せようと、椅子を広間へ走らせる。[08へ](#s08)
- 一礼して卓の下へ潜り、次は仕組みを確かめる。[02へ](#s02)

<a id="s06"></a>
### 06 パイの直径

パイは窓より小さく、あなたの想像よりずっと大きいものでした。タムが厚い布を渡し、二人で鉄板を窯から引きます。表面の洋梨が透き通り、隙間から泡がひとつ弾けました。

「椅子には食わせるな。あいつら、熱さが分からん」

厨房の床には背の低い作業台があり、見習いたちの皿も並んでいます。タムは割れた縁の部分を小皿へ載せ、あなたの前へ置きました。食堂へ戻れば、立派な切分けを待つことになります。ここなら、焦げた砂糖を一番先に食べられます。

扉の向こうで楽団が曲を変えました。あなたの椅子は座ったまま、脚先だけで忙しく踊っています。

- 今夜は厨房の低い台で食べることにし、椅子から降りる。[14へ](#s14)
- 大パイが食堂へ出る前に、椅子たちの道を空けに戻る。[07へ](#s07)

<a id="s07"></a>
### 07 ひとり分の舞台

広間には、磨かれた床と巻き上げられた古い絨毯がありました。壁の肖像画のベラは、いまより若く、椅子の背に片足を載せて笑っています。額縁の隅には丸い傷。何度か落ちた絵らしい。

食堂から椅子が三脚、客を乗せたままついてきました。あなたが先に行くなら行ってみよう、という顔です。貿易商までがナプキンを畳んでいます。

ベラも入口へ来ました。杖で指す先は、廊下でも出口でもなく、広間の真ん中です。

「さて、コノ。座ったままで済ませる？」

- 「拍子」の印がある場合、二歩と休みを踵で打ち、椅子を曲へ合わせる。[09へ](#s09)
- ベラに、肖像画の続きが見たいと頼む。[10へ](#s10)
- 広間の向こうまで一直線に走り、先頭を取る。[08へ](#s08)

<a id="s08"></a>
### 08 抜かれる晩餐

椅子は、あなたが前へ身を倒した分だけ速くなりました。背中の燕尾が旗のように伸びます。後ろでは貿易商が「船より静かだ！」と叫んでいました。静かという部分には同意できません。

広間の先へ、タムと給仕が大パイの載った台車を押して出てきました。あなたは半身をひねり、台車を避けます。百本の脚が床を打ち、椅子の列も同じ方へ曲がりました。

正面には中庭への大扉。左には丸めた絨毯。足元には、床を擦る自分の燕尾服の裾。どこへ力を逃がすか、もう考え込める距離ではありません。

- 絨毯の縁を踏ませて広げ、滑り込める幅を作る。[11へ](#s11)
- 開いている大扉へ向かい、中庭で大きく回る。[12へ](#s12)
- 燕尾服の長い裾を前脚の下へ噛ませ、自分の椅子を止める。服は破れるでしょう。[16へ](#s16)

<a id="s09"></a>
### 09 二歩、ひと休み

二歩。休み。椅子の細い足が、あなたの踵に返事をしました。左右の重心をずらすと、椅子は体をゆっくり回します。あなたは隣の客へ手を伸ばし、椅子の背を押して半円を作りました。

食堂から出てきた楽団が、歩く速さへ曲を落とします。誰かが笑い、誰かが数え間違え、給仕は困った顔のまま、その間を抜けました。

ベラの杖が、あなたの休みに一度だけ入ります。椅子が跳ね、あなたの心臓も跳ねました。ベラは昔の肖像画と同じ顔をしています。

- 休みを長く取り、給仕の台車が通る踊りの輪を作る。[13へ](#s13)
- もっと大きな輪にしようと、中央の絨毯を広げる。[11へ](#s11)

<a id="s10"></a>
### 10 肖像画は腰を伸ばす

ベラは杖をあなたへ預けました。両手を空けると、背もたれを握り、椅子の上で膝を伸ばします。

「本当はこれ、晩餐用じゃないの。舞台がなくなったあと、食べる場所だけが大きく残ったのよ」

前脚が二歩出て、止まります。ベラの片足が、古い肖像画の位置に上がりました。あなたは思わず杖を差し出しますが、彼女は顎で拍子を取れと促しました。

あなたが二度たたいて休むと、百本の脚がきれいにそろいます。食堂の客が拍手しました。ベラは降りてから、ほんの少しだけ椅子の背へ体を預けます。

- 習った動きを踵でも試して「拍子」に印を付け、ベラの隣へ椅子を寄せる。[09へ](#s09)
- 「次は私の番です」と、椅子を広間へ走らせる。[08へ](#s08)

<a id="s11"></a>
### 11 絨毯の海

絨毯がほどけ、椅子の列はその上へ滑り込みました。脚が一度に毛足をつかみ、百本ずつの足音が、波のような音へ変わります。

あなたの椅子は端で止まり、後ろの椅子も続きました。貿易商が両腕を上げます。進水式だ、と言いかけて、ベラに椅子ごと押し返されました。

タムが台車を絨毯の真ん中へ置きます。「この島から先は、料理の海だ。走ったら皿を下げる」

皿を下げられるのは困ります。あなたは百本の脚を見下ろしました。靴を一度鳴らすと、椅子は絨毯の上を小さく進みます。体を起こせば止まる。広間の真ん中なら、これだけの歩幅で皆が料理へ届きそうです。大扉の向こうには、食堂に入れなかった楽団の荷運びたちも顔を出しています。

- 椅子の輪を広間に収め、皆が取り分けられる速さで回す。[13へ](#s13)
- 荷運びたちも呼び、台車ごと中庭へ出してしまう。[12へ](#s12)

<a id="s12"></a>
### 12 晩餐は玄関から入らない

中庭の丸い花壇を回ると、椅子の脚は砂利へ沈み、速度が落ちました。あなたはようやく大きく息を吐きます。

塀の上に、近所の子供たちの顔が並んでいました。台車が出てくると一人が「パイ！」と叫び、タムは反射的に木べらを高く掲げます。

「見物料を取るなら、皿を持ってこい！」

ベラが言い直しました。「皿はこっちで出すの。手を洗っておいで」

貿易商は椅子を降り、台車の傾きを直しています。楽団は荷運びと場所を替え、花壇の縁に腰掛けました。あなたの椅子は植木鉢を嗅いでいます。いまなら、首の飾り木をつかんで、好きな場所へ向けられそうです。

- 椅子を花壇へ向け直し、自分も皿を配る側へ回る。[15へ](#s15)

<a id="s13"></a>
### 13 走らないための舞曲

**結末 E1：コノ様の一周**

あなたが短く踵を打つと、椅子の輪が進みました。休めば給仕が皿を差し出す。少し進めば次の料理。貿易商はスープを追いかけずに飲めることへ、深い感謝を示しました。

ベラはあなたの向かいにいます。杖を置き、両足を椅子の横へ楽に垂らしていました。もう誰も、彼女へ背筋を伸ばせとは言いません。

大パイが切り分けられ、最初の一切れがあなたへ来ました。焼き汁は皿の中央に集まり、洋梨の端が薄い光を含んでいます。八歳のあなたが知っていたら、今夜までの待ち時間を数え直したことでしょう。

ベラが席札を立て直します。「来年、椅子の続きを頼めるかしら、コノ」

貿易商はあなたの名前を聞き返しませんでした。あなたは口に入れた熱いパイを急いで飲み込もうとし、結局、頬を膨らませたままうなずきます。

椅子はその小さな動きまで合図だと思い、皆をもう一周させました。

<a id="s14"></a>
### 14 裏側の一番席

**結末 E2：焦げた砂糖の縁**

あなたは燕尾服を脱ぎ、丸椅子に腰掛けました。脚は四本。自分から歩かないというだけで、たいへん優秀な家具です。

タムがパイの端をもう一片くれます。厨房の見習いたちは、焼き上がる時にどの梨が倒れたかで議論していました。あなたは窯の口から見た一番奥の梨を指し、初めてその議論へ入ります。

やがてベラが扉を開けました。空いたあなたの席札を持っています。叱られると思って背筋を伸ばすと、彼女は低い台の端へ札を置きました。

「こちらにいるなら、教えてちょうだい。食堂に、焼き加減を知らない人が二十三人もいるの」

タムは皿を一枚増やしました。ベラの椅子は扉の外で待ち、百本の脚で小さな音を立てています。彼女は靴の踵を二度鳴らして、静かにさせました。

あなたはパイの皮を割り、その音が聞こえる距離へ皿を寄せます。ベラも指で一片つまみました。

<a id="s15"></a>
### 15 塀より大きいパイ

**結末 E3：名前で呼ぶ庭**

皿の足りない子供には、タムが焼き紙を二重に折りました。楽団は食べながら吹ける楽器を真剣に探し、結局、太鼓だけが鳴り続けます。

あなたは椅子の背に立ち、台車の奥の切分けを手前へ回しました。見習いの仕事で鍛えた腕が、今夜はよく役に立ちます。塀の外へも甘い匂いが流れ、誰かが自宅から椅子を持ってきました。四本脚の椅子まで、百足椅子の列へ並びます。

「コノ、皿をもう一枚！」

名前を呼んだのは貿易商でした。あなたは渡しながら、パン籠の子が成長した話の続きをする必要がなくなったことに気付きます。

ベラは花壇の縁でパイを食べています。庭へ出した銀器のことをタムが尋ねると、彼女は匙を一本振りました。「数えるのは明日。今日は、この人たちを覚えます」

その晩から、大パイは屋敷の窓より大きかったという話になりました。あなたはそれを聞くたび、窓ではなく、塀の高さを思い出します。

<a id="s16"></a>
### 16 短くなった正装

**結末 E4：裾を引かない晩餐**

前脚が布へ絡み、あなたの椅子が止まりました。背中で長く裂ける音がします。後ろの貿易商は素早く椅子を横へ向け、壁の手前で降りました。彼は着地してから、自分でも驚いた顔をします。

あなたの燕尾服は、ふつうの短い上着になっていました。百足椅子は奪い取った裾を鼻先でつついています。タムは台車を止め、笑う前にあなたが立てるか確かめ、立てると見るや、腹を抱えました。

「その丈、働きやすそうだな」

あなたも笑いました。客たちは椅子を降り、広間の窓辺で皿を受け取ります。ベラは切れ端を拾い、縫物籠へ放り込みました。

「今度は最初から、その形で仕立てなさい。コノの服ってことにしましょう」

熱いパイを食べるあなたの背中には、風がすっと通ります。座り方を褒めてもらう夜ではありませんでした。それでも、胸の木のボタンだけは、誰よりも立派に光っていました。

### 体験の核

「ちゃんとした客になりたい」と体を固めるほど椅子に振り回され、家具職人として動きに触れる、自分から人前へ出る、厨房へ降りることで、違う居場所ができる喜劇。必須の犠牲や正答の一本化は置かない。客として食べる13、厨房へ加わる14、庭を食卓にする15、服の体裁を捨てる16は、それぞれ別の身体と社交の経験として終える。

### 固定前提と仕組み

椅子はベラが舞台で使っていた歩行家具。近くの足音・乗員の重心・飾り木の向きに応じる。二歩と休みは小さく歩かせる方法であり、唯一の停止法ではない。重い荷、絨毯の毛足、砂利、布の絡まりも具体的に運動を変える。熱い料理へ飛び込ませず、08で台車を避けた後の進路を選ぶ。椅子が食品を消費する機構はない。01のパンへの追跡は主人公の見立てで、02で足音への反応を観察できる。

時間は節による有限の進行。制限時間や隠れた負傷判定はなく、規則を読む速さは評価しない。服の損傷は08で予告した16だけ。誰かの過去の功績や資産を獲得する報酬は設けない。

### 人物ごとの欲望と反応

コノは子供扱いを抜けたいが、パイへの子供の頃からの期待も持つ。体裁を保つ03、観客の前へ出る05、厨房に残る06はその競合を具体的に選ぶ場面。主人公の性別は固定せず、衣服は今回の招待服として扱う。

ベラは旧い舞台を忘れていないが、自分一人で再演を宣言するより、椅子を扱おうとするコノへ舞台を渡したがる。02の足先、07の指示、10の実演、各結末での居場所の変更へつなぐ。無断で全てを計画した黒幕とはせず、事故を楽しみながら応じる人物。

タムは料理を食べてほしく、冷ましたり潰したりする椅子を嫌う。04で進路を変え、06で窯出しを頼み、11で台車を中心へ置く。14は本人の仕事場へ客が入ってくる結末で、ただごちそうを配る装置にはしない。貿易商は序盤ではコノを昔の呼び名で扱い、後には実際の行動を見て呼び方と自分の姿勢を変える。

### 主な選択と回収

02の実験は09の能動的な操縦に使うが、他経路を封鎖する必須の調査ではない。10には直接の実演という代替取得がある。06の厨房残留は豪華な食堂を逃す失敗ではなく、同じ料理の違う食べ方。08の裾を噛ませる行動は衣服の損傷を伴い、16で実際の丈と呼ばれ方へ残す。09と11から13へ合流しても、「拍子」を知らない経路で特定の暗号を記憶していたとは書かず、結末では小さな足の動きに応じる既観測の反応を使う。

### 自然な代案と核の再評価

降りる、厨房へ移る、物を持たせる、広い場所へ出す、ベラへ尋ねる方法を採用。歩く椅子を倒さなければ食事できないという危機にはしない。容易な退出後も、どこで誰として食べたいかが残る。椅子を屋敷外へ破棄する、全家具の工学的修復をする話までは、この一晩に広げない。

「拍子」は初期なし。02のどちらの選択でも印を付け、10から09へ進む選択でも付ける。07から09の選択にだけ必要。その他の身体状態、椅子の場所、衣服の損傷は節から一意に分かるため別記録にしない。印を付けずに09へ到達する経路はない。印なしでも11経由の13へ到達できるが、13は特定の二歩方式を断定しない。
