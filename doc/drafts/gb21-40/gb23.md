# GB23 あなたより先に帰った影

## 導入

玄関の明かりがついています。留守の長かった家へ帰るとき、あなたはいつも、その小さい四角を見ると歩くのを遅くします。急いで帰ってきたくせに、扉を開けるまでの数歩を、もう少し持っていたくなるのです。

今夜は、鍵がありませんでした。

上着の右。左。鞄の底。探しているあいだに、台所であなたの声がしました。

「それは切ってから入れるんだよ」

娘のミオが笑っています。連れ合いの湊も、低く何か言いました。あなたは先週から、こんな声を聞きたかった。窓ガラスの向こうへ目を上げると、あなたが包丁を持って立っていました。

出張に着ていった灰色のシャツ。片方だけ高い肩。手首の古い火傷まで、あなたでした。

足元には玄関灯が落ちています。鞄の影はあるのに、あなたの影がありません。

## 遊び方と記録

数値や印は使いません。節の選択を一つ選んで進みます。読んでいない節の事情を知っている必要はありません。知らないことは、家の中で試したり、誰かの行動を見たりするうちに現れます。[01へ](#s01)進んでください。

## 本文

<a id="s01"></a>
### 01 空いた靴一足ぶん

窓の内側にいるあなたが、鍋の蓋を持ち上げます。湯気で顔が消えました。その一瞬だけ、あなたはひどく安心しました。顔が見えなければ、よく似た誰かだと思えます。

ミオが棚の上の皿を取ろうとし、背伸びをしました。窓の中のあなたは包丁を置き、皿を下ろして渡します。あなたなら、危ないと言いながら、先に自分で皿を運んだかもしれません。

玄関の靴入れには隙間があります。中のあなたは、靴を履いて帰ってこなかったようです。扉の隙間から煮物の匂いがします。湊が塩を少なくする前の、家の匂いでした。

- 扉を開け、自分が帰ったと声を掛ける。[02へ](#s02)
- 窓の下へ寄り、もう少し中を見る。[03へ](#s03)

<a id="s02"></a>
### 02 二度目のただいま

「ただいま」

あなたが言うと、台所の三人がこちらを向きました。包丁を置く音が、やけに高く響きます。

湊はまずミオを自分の後ろへ入れました。それからあなたの濡れた鞄を見て、床へ落ちた水を見て、もう一人の顔を見ます。

「二人とも、そこにいて」

中のあなたが何か言いかけました。湊は手を上げて止めます。「あなたにも言ってる」

あなたが近付くと、ミオが湊の袖を強くつかみました。知らない人を見る目ではありません。知っている顔が、同じことを二度するのを怖がる目でした。

台所の天井灯は、湊とミオの影を床へ置いています。あなたと、あなたの姿のものの足元だけが明るい。そのものは自分でそれを見下ろし、裸足の指を縮めました。

- 足元を指し、卓上灯を使って確かめてみる。[04へ](#s04)
- 包丁から離れて食卓へ座り、まず三人の話を聞く。[06へ](#s06)

<a id="s03"></a>
### 03 あなたの結ばない結び目

ミオが、ほどけた髪紐を差し出しました。窓の中のあなたは、それを二つの輪にします。仕上がりは片方だけ大きく、ミオは首を振って笑いました。

その結び方を、あなたはしません。幼い頃、ミオが自分で考えた結び方です。ほどけやすいので、あなたは普通に結び直していた。それでも窓の中の手は、根気よく二つの輪を同じ大きさにしました。

ガラスにあなたの顔が重なります。湊がそれを見付けました。しばらく、どちらも動きませんでした。

やがて湊は勝手口を開けます。あなたの鞄を受け取りかけて、手を止めました。

「先に帰った方も、いま帰った方も、冷えてる」

そう言って、戸口の脇に掛けてあった毛布を、あなたの肩へ載せます。台所からは、煮物をよそう音が続いていました。

- 湊と台所へ入り、明かりの下で二人の姿を見る。[04へ](#s04)
- 毛布を返し、外にいると伝える。中の自分が出てくるのを待つ。[07へ](#s07)

<a id="s04"></a>
### 04 手の端がほどける

湊が卓上灯を持ってきました。天井灯を消すと、部屋の物が、一つずつ長い影を持ちます。ミオは壁際に座り、膝を抱えました。

あなたが灯りの前へ入ったとき、もう一人の右手の端が薄くなりました。壁に映る黒い指が、本人の指より先に曲がります。あなたが横へ退くと、元の手へ戻りました。

相手は右手を握り、あなたを見ました。

「そこに立つと、引かれる」

声もあなたのものでした。けれど言い方は、あなたが誰かへ頼むときより短かった。足元へ目を戻すと、その裸足は床に載っているというより、床から立ち上がっています。

ミオが灯りを避けて、少し遠くへ座り直しました。卓上灯は温かい黄色で、その輪の外には廊下の暗い入口があります。

- 相手へ手を差し出し、灯りの前で指先だけ重ねてみる。[05へ](#s05)
- 暗い廊下へ誘い、戸を閉じて正体を見ようとする。[08へ](#s08)
- 灯りを元に戻し、先に帰って何をしていたのか尋ねる。[09へ](#s09)

<a id="s05"></a>
### 05 飲んでいない一口

相手はあなたの指を見つめました。それから自分も同じ指を出します。灯りが一つの手の形を壁へ投げる位置で、爪の先が触れました。

舌へ、甘い生姜湯の味が来ます。

あなたは今夜、それを飲んでいません。けれど熱い椀を両手で持ち、ミオが宿題の裏へ描いた小鳥を見た感触が、指の内側にありました。指を離すと味は消え、小鳥の絵の形だけが残ります。

相手が、あなたの鞄を見ました。

「あの駅、まだ工事をしてたんだ」

今度は、あなたが今日見てきた景色でした。相手は眉をしかめ、続く言葉を飲み込みます。互いの中へ入るのは、温かい記憶ばかりではないようです。

壁の二本の指が離れました。あなたは、これが自分の影だったのだと思います。いつ離れたのかは分かりません。相手は、その呼び方を訂正しませんでした。

- この家で何をしたかったのか、影の話を聞く。[09へ](#s09)
- 手だけでなく、身体を重ねて一人へ戻ることを持ち掛ける。[11へ](#s11)

<a id="s06"></a>
### 06 一枚足りない皿

あなたはいつもの椅子へ座りかけ、もう相手が座っていることに気付きました。相手はすぐ立ち上がります。その動きがあまりに素直で、かえって、そこへ腰を下ろせなくなりました。

湊は玄関から小さい椅子を運び、食卓の短い辺へ置きます。ミオが皿を一枚増やしました。誰も乾杯はせず、汁の熱さを吹いています。

相手の作った煮物は、あなたの好きな味でした。湊は黙って湯を少し足します。ミオは人参だけを先に食べました。好きになったのだと、あなたはそこで知ります。

「どっちでもいいとは言わないよ」

ミオが匙を置きました。「それを言うと、二人とも笑うから」

相手は笑いかけていた口を閉じます。あなたも、閉じました。湊が小さい椅子へ座るよう、もう一度あなたを手招きします。

- 食後、卓上灯の下で二人の違いを調べる。[04へ](#s04)
- 皿を下げながら、相手が帰ってきたときの話を聞く。[09へ](#s09)

<a id="s07"></a>
### 07 靴を借りたい

ほどなくして、勝手口が開きました。もう一人のあなたが、左右の合わない庭履きを持って出てきます。

「足があると、靴がいるんだね」

片方が小さいので、踵を踏んで履きました。毛布を渡そうとすると、首を振ります。灯りの外に出た肩が、一度細くなり、道の街灯の下でまた厚みを持ちました。

「あなたを追い出したかったわけじゃない。自分で扉を開けてみたかった」

相手は勝手口を見ています。あなたと同じ横顔なのに、いま家を出ることへ、あなたよりずっと慣れていないようでした。

湊が戸口から二人を呼びました。相手は振り返らず、あなたへ鍵を差し出します。手首の下には、どこまで明るい道が続いているのか確かめるように、裸足の輪郭が揺れていました。

- 鍵を受け取り、家へ戻る。相手が歩き出すのを止めない。[14へ](#s14)
- 鍵をまだ受け取らず、一緒に道の先まで歩く。[12へ](#s12)

<a id="s08"></a>
### 08 暗い戸の向こう

あなたは廊下の先の物置へ相手を入れ、灯りのない戸を引きました。向こうから声がします。

「閉めると、立っていられない」

返事をする前に、戸の下が黒くなりました。薄い紙を水へ置くように、黒いものが隙間から広がります。あなたが退いた足元を通り、廊下の灯りへ届くと、指が五本、床から起きました。

ミオが短く叫びました。湊は戸を開け、物置の明かりをつけます。そこには誰もいません。立ち上がった相手は、あなたを見ずに庭履きを探していました。

「入れ物みたいに、戸で止められると思った？」

怒りよりも、驚きが混じった声でした。あなたが近付くと、相手は先に勝手口を開けます。家の外には街灯が並んでいます。湊は引き留めず、あなたへ言いました。

「話すなら、追い掛けて。ミオはここにいる」

- 道へ出て、影と並んで歩く。[12へ](#s12)

<a id="s09"></a>
### 09 先に開けた引出し

相手は、あなたの部屋の小さい引出しを開けました。中には、壊れた木の舟があります。ミオが去年作り、あなたが時間のあるときに直すと言ったものです。

帆柱には新しい糸が巻かれていました。少し斜めですが、立っています。

「直そうと思った。それで、糊がどこか分からなかった」

相手は糸の端を引き、結び目を締め直しました。あなたの代わりになんでもできるわけではない。それでも、引出しを開けたのは、この人でした。

湊が戸口へ来ました。舟を見ると、あなたへも相手へも、すぐには礼を言いませんでした。

「明日、これを浮かべる約束をしたんだ。ミオは、いまはそれを楽しみにしてる」

相手は舟を置きました。「明日も、ここにいていいか聞こうと思ってた」

湊は部屋の狭さを見回し、折り畳んだ客布団を戸棚から引き出します。敷く場所を作る前に、相手はあなたの返事を待っていました。

- 客布団を広げる場所を空け、今夜は二人とも家にいることにする。[10へ](#s10)
- 一人へ戻れるのか、灯りの下で指先から試したいと言う。[05へ](#s05)
- 相手を誘い、二人だけで外へ出て話す。[12へ](#s12)

<a id="s10"></a>
### 10 布団の幅

部屋の低い机を壁へ寄せました。二枚の布団を並べると、引出しが半分しか開きません。相手が笑い、あなたも少し笑いました。自分と同じ笑い声を外から聞くのは、まだ落ち着きません。

湊は枕を一つ置きました。

「どちらも、明日いきなりいなくならないで」

相手は答える代わりに、鍵を机へ置きました。あなたも鞄をほどきます。ミオは入口に座って、その二つの音を聞いていました。

やがて相手が卓上灯を消しかけ、手を止めます。「暗いと、寝る場所が変わる」

豆灯へ切り替えると、相手の身体は布団の上で薄くなり、壁へ続く影になりました。顔だけが一瞬こちらを向いて、やがて静まります。灯りを強めれば、また肩が起きました。

- 灯りを豆灯へ戻し、空いた布団の横へ自分も寝る。[16へ](#s16)

<a id="s11"></a>
### 11 一つの輪郭へ

二人は卓上灯の前へ立ちました。指先を重ねたときの生姜の味を、あなたは思い出します。相手は自分の手を見て、何度か開きました。

「戻ったあと、さっきのことを、夢だったことにしないで」

あなたは返事の代わりに、飲んでいない生姜湯の小鳥を話します。相手は頷き、もう一度指先を重ねました。それから、あなたが今日の列車で一度だけ泣きかけたことを口にしました。あなたは、その続きを止めませんでした。

湊がミオと椅子に座っています。近くへ寄り過ぎず、目を逸らさずにいました。壁では二つの輪郭が、まだ別々に呼吸しています。

指だけなら離せました。身体を全部重ねたあと、この二人に戻れるかは、誰も知りません。相手は灯りへ背を向け、あなたのために一歩ぶんを空けました。

- その一歩へ入り、影を自分の足元へ迎える。[15へ](#s15)
- 今日は二つのままで眠ると言い、客布団を出す。[10へ](#s10)

<a id="s12"></a>
### 12 最終便の来ない停留所

道の先の停留所には、もう便がありませんでした。二人でベンチへ座ると、街灯は座面に細い棒の影だけを作ります。庭履きの片方は、ここまでで泥だらけになりました。

「出ていくとき、いつも後ろを見ないね」

相手が言いました。

「見たら、仕事へ行けなくなるから」

答えると、自分の言葉が思ったより弱く聞こえました。家へ帰りたい。誰もあなたの帰りを数えない場所へ行きたい。その二つは、同じ夜にありました。

相手は庭履きを脱ぎ、街灯の明るい輪へ裸足を出します。「私は、どこまで歩けるかも知りたい。家しか欲しくないわけじゃない」

ここなら、片方だけを家へ帰すこともできます。けれど家には、二人が道へ出たのを知っている人たちがいます。湊の声が、道の向こうから届きました。迎えに来ず、門のところで待っています。

- 自分が家へ戻り、影には自分の行きたい方へ歩いてもらう。[14へ](#s14)
- 自分がしばらく家を離れたいと話す。影と一緒に戻り、湊とミオへ顔を見せて告げる。[13へ](#s13)
- どちらも今夜の家を出なくていいと、影を誘って帰る。[10へ](#s10)

<a id="s13"></a>
### 13 戸口で終わらせない話

あなたが話し終えるまで、湊は玄関へ入れてくれませんでした。怒っているのではありません。途中で曖昧にして、靴を脱ぎ、翌朝いつもの出張へ変えてしまわないように、そこに立っていました。

「代わりがいれば同じ、とは思ってない」

湊は相手を見ます。「あなたも、引き受ける前に考えて」

相手は木の舟を取りに行き、ミオの前へしゃがみました。明日の舟は一緒に浮かべたい、その先のことは自分にも決めさせてほしい。ミオは舟の帆柱を触り、それからあなたの上着の裾をつかみました。

「帰る前に、電話して。二回ただいまは、怖い」

あなたは約束しました。湊が自分の鞄から小さい宿のカードを出します。町の向こうにある、あなたも知っている宿でした。カードを渡す指には力が入り、礼を言う間もなく手を離しました。

- 今夜はその宿へ向かう。明日の朝に電話をする時刻を告げ、鞄を持つ。[17へ](#s17)

<a id="s14"></a>
### 14 影のいない食卓

**結末 E1：足元の明るい人**

相手は鍵をあなたへ返しました。小さな金属が掌へ落ちます。あなたが家へ向きを変えてから、もう一度振り返ると、影は違う方の街灯へ歩いていました。

湊は玄関を開けて待っていました。ミオは食卓の端を空け、あなたの前へ皿を一枚置きます。あなたは煮物を取り、少し冷えた人参を食べました。

ミオが木の舟を持ってきました。「明日、浮かべる約束をしたの」

あなたは舟の帆柱を見ます。ミオはどこが直っているのかを説明し始め、途中で、あなたが糸を巻いたのでないことを思い出しました。あなたは続きを頼みます。

翌朝、あなたは家の前で水桶を出します。舟は斜めの帆柱を立て、桶の縁へぶつかりました。ミオが指で押し返すと、しばらく真ん中を進みます。

朝日が三人を照らしました。桶と二人の影が長く伸び、あなたの足元だけが明るい。湊はそれを見ましたが、何も言いませんでした。

あなたが桶を運ぶとき、二人が空けてくれたのは、あなたの身体一つぶんの道でした。

<a id="s15"></a>
### 15 知らない一日を持つ

**結末 E2：一人分より重い帰宅**

重なる瞬間は、抱き合うのと違いました。肩が冷たくなり、次に、身体の内側へ暖房がついたような熱が来ます。

知らない午後がありました。台所の棚を開け、糊を探して諦め、ミオの机から糸を一本借りた午後。湊が帰ったとき、自分で扉を開けられた嬉しさ。その嬉しさを、あなたは生まれて初めてのことのように感じました。

膝をついたとき、壁に映っていたのは一人でした。足元には、ちゃんと影があります。あなたが手を上げると一緒に上がり、下ろすと、一拍だけ遅く下りました。

ミオが近付き、指を一本つかみます。「熱い」

あなたは小鳥の絵を見せてほしいと言いました。ミオは走って取りに行きます。湊は何か尋ねかけ、代わりに、生姜湯を入れ直しました。

飲む前から味を知っていました。それでも口に含むと、知っていることと、ここで飲むことは別でした。

玄関の鍵は、あなたの右のポケットに戻っています。明日はその鍵で、自分で扉を開けようと思いました。

<a id="s16"></a>
### 16 二つの寝息

**結末 E3：壁にも朝が来る**

豆灯の下、布団は一枚空いていました。壁の影があなたと同じ形をしているので、何度か、自分が眠らず立っている気がしました。

「眠れる？」

あなたが小声で聞くと、壁の口が動きました。「たぶん」

それきり静かになります。あなたは自分の呼吸を数え、数え間違えて、眠りました。

朝、机へ日が差したとき、影は布団から起きていました。寝癖はありません。あなたの髪を見て、どうやったらそうなるのか尋ねます。あなたは、なろうとしているわけではないと答えました。

湊は四枚の皿を出しました。ミオは木の舟を持ち、どちらに渡すか迷った末、自分で持ちます。

外へ出ると、朝の道に二人ぶんの足音がしました。二人とも影がなく、代わりに、互いが横を歩いています。近所の人が驚いて立ち止まり、湊が先に挨拶しました。

ミオは水桶を置きました。「押すのは一回ずつね」

同じ返事を同時にしてしまい、あなたたちは、次の一言を譲り合いました。

<a id="s17"></a>
### 17 戻る前にかける電話

**結末 E4：あなたのいない夜**

宿の受付で名前を聞かれたとき、あなたは一瞬つかえました。それから、自分の名前を言います。受付の人は何も不思議がらず、鍵を一つ渡しました。

部屋には小さい窓と、一人で使う机がありました。鞄を置いても、誰も土産を尋ねません。あなたはその静けさを、嬉しいと思いました。嬉しいと思えたことが、少し怖かった。

電話には、まだ何も届いていませんでした。家の窓を思い出します。灯りの中に、あなたの横顔がある。ミオの髪を結び、湊と食器を拭く。今度は、見間違いではなく、あなたがそこへ残してきた人です。

机の灯りをつけました。鞄の影は壁へ長く伸び、あなたの座るところだけが白いままでした。

明日の電話の時刻を合わせ、あなたは靴を脱ぎます。帰りたいかどうかを、今夜のうちに決める必要はありません。帰らないまま消えてしまう約束も、していません。
