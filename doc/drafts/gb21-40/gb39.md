# GB39 栄光を食べる獣

ドラフト第1稿／設計モデルv1.2b／作成日2026-10-21／ゲーム未実装

[20作の目次](README.md)

## 導入

凱旋車〈獣鳴号〉を作ったのは、あなたたち七人だった。

車輪が回ると腹の鞴が動き、胸の管から七つの音が出る。屋根には英雄ゼオンが立つ。町を守った英雄の祭りだから、それは構わない。ただ、紹介の垂れ幕に工房の名が一つもなかった。

あなたは自分の名札を裏返して、車の後部へ乗り込んだ。今日は仕掛けを動かす係だ。母が見物に来る。あなたは「真ん中あたりを見ていて」としか言わなかった。

大通りへ出る直前、行列が止まった。

道の中央に、金色の鼻をした獣がいる。山から下りてくる「栄光喰い」だ。普段は大きな犬くらいの獣が、今日は荷馬車の馬と同じ高さになっている。

ゼオンが観客へ手を振った。拍手が起こる。

獣の腹が、もう一回り膨らんだ。

## 遊び方と記録

開始は[01へ](#s01)。選んだ先だけを読みます。

記録する値は「名札」で、初めは「裏」です。指示があった場合に「表」へ変えます。一度表にした後、裏へは戻しません。これは周囲へ名乗ったかどうかを表す記録です。

栄光喰いの性質は物語の中で分かります。人の記憶や評判を消す獣ではありません。倒さないと祭りが終わらない、という規則もありません。

凱旋車は手押しで止められ、広場へ引き返す道もあります。大きくなった獣が車へぶつかれば、木組みは壊れます。読む時間による自動的な悪化はありません。

## 本文

### 01 拍手の下

獣は牙を見せていなかった。鼻を上げ、ゼオンのほうへ歩く。観客はそれも出し物だと思ったらしく、さらに拍手した。

あなたは車の制動棒を下ろす。木の爪が車輪へ入り、〈獣鳴号〉の演奏が止まった。獣は管の音には見向きもしない。最前列で手を叩いている男の前へ、金色の鼻を差し出す。

男が驚いて手を止めると、獣も止まった。

屋根のゼオンが、あなたを見下ろす。「動かないのか？」

その背後には、町を救った日の剣が飾ってある。柄も鞘も磨かれている。あなたの爪には、朝まで組んでいた車軸の油が残っていた。

- 獣の口と腹を見て、何をしているのか確かめる。→ [02へ](#s02)
- ゼオンへ上がってもらった梯子を指し、降りて話してほしいと呼ぶ。→ [03へ](#s03)
- 車の周りを回り、獣と車を動かせる道を探す。→ [04へ](#s04)

<a id="s02"></a>

### 02 金色のため息

拍手の音が鳴るたび、空気に小さな金色の粒が浮かんだ。獣は口を開き、それを吸い込んでいる。

歓声では増えない。誰かが指笛を吹いても、耳が一度動くだけだった。手のひらが打ち合わさる音で、腹がまた膨らむ。

観客の列がいったん静まったとき、獣は前脚を伸ばし、長いため息をついた。鼻から金色の湯気が出る。その間だけ、脇腹がゆっくり細くなる。

あなたは自分の胸へ手を当て、同じ長さで息を吐いてみた。思ったより長い。吐き終える前に次の拍手が起きると、獣はまた吸い始めた。

屋根のゼオンは、自分の名を呼ぶ子供へ一人ずつ手を振っている。悪気はない。そのたびに、どこかで手が鳴った。

- ゼオンに声を掛け、獣が拍手を食べているところを見せる。→ [03へ](#s03)
- 車の脇へ戻り、来た獣係と相談する。→ [05へ](#s05)

<a id="s03"></a>

### 03 屋根から降りる人

ゼオンは梯子を降りた。地面に立つと、思ったより背が高くない。

あなたは獣を指し、拍手のたびに大きくなると伝えた。ちょうど二人の少年が手を叩く。獣がそちらへ顔を向け、腹が揺れた。

「俺が手を振るのを、やめればいいのか」

「まずは。あと、ひとつ」

あなたは名札を表へ返した。工房の名と、あなたの名。ゼオンが読める向きへ、油で汚れた端を持つ。

「車を作った七人を、紹介してください。今すぐじゃなくても」

ゼオンは名札から顔へ目を移す。「垂れ幕に入っていなかったのか」。あなたが頷くと、彼は屋根の布を見上げた。それから、梯子を片付けず車の側面に立てたままにした。

「そのときは、一緒に上がろう。俺は仕組みを説明できない」

彼は観客へ手を振る代わりに、両手を胸の前で止めてみせた。

**「名札」を「表」にします。**

- ゼオンと車の脇へ戻り、獣係に話を聞く。→ [05へ](#s05)

<a id="s04"></a>

### 04 曲がれる角

祭りの正面の道は、石の門をくぐる。〈獣鳴号〉の屋根がぎりぎり通る高さだ。今の獣なら通れても、さらに膨らめば、両方一緒には入れない。

反対側には、朝、車を組み上げた草地がある。車輪の跡が二本、まだ土に残っていた。広場へ戻る道は空いている。

あなたは車の先端に付けた木彫りの顔を撫でた。大きな口から音が出る仕掛けだ。子供の一人が「獣が二匹」と言う。

本物の獣は、木彫りの顔を気にしない。子供が面白がって拍手すると、ようやくこちらを向いた。あなたが「もう一回は待って」と手を出すと、子供は手を離したまま止まった。

通りの端を、獣係のニマが歩いてくる。肩には餌桶でなく、拍子木がある。彼女は子供の止まった両手を見て、頷いた。

- ニマに広場への道を示し、車の脇で話す。→ [05へ](#s05)

<a id="s05"></a>

### 05 獣係の手

ニマは獣の鼻の前で、一度だけ手を叩いた。

金色の粒が小さく飛び、獣が一歩寄る。次を待って舌を出したが、ニマは両手を離したままにした。獣は長く息を吐き、腹を少し縮める。

「大勢に会うと、食べるのが止まらない。山ではこんなに食べられないから」

彼女は拍子木も鳴らしてみせた。乾いた音には、獣は進まない。

「手を叩く音だけ。少し食べて、ちゃんと吐けば、このくらいで済む」

ゼオンがこちらへ身を乗り出し、話を聞いている。ニマは彼へ、観客を静めてほしいと頼んだ。英雄の指が唇へ当たると、先頭から静かになっていく。

あなたは草地への道を指す。ニマはすぐ頷いた。車も獣も通れる広さだ。

〈獣鳴号〉の胸には、まだ鳴らしていない七本目の管がある。いちばん大きな音が出る、今日のために作った管だった。

- 行列を静かに引き返し、一人ずつの小さな拍手で獣を草地へ導く。→ [06へ](#s06)
- ゼオンに客席へ降りてもらい、拍手の合図を観客へ教えてから草地で演奏する。→ [07へ](#s07)
- 自分が車の正面に立って注目を集め、派手な挑戦の演出で獣を追わせる。大きくなれば車へぶつかる距離だ。→ [08へ](#s08)

<a id="s06"></a>

### 06 静かな行列

あなたは制動棒を上げ、車の舵を切った。いつもの曲がり角とは逆だ。工房の仲間が一人、理由を尋ねる前に後輪へ肩を当てる。

ニマが一度、手を叩く。獣が進む。みんなが待つ。

これだけの人数で、こんなに静かに動くのは奇妙だった。車輪の軋む音まで遠くへ届く。屋根を降りたゼオンが車の横を歩くと、小さな子供が何かを言いかけ、両手で自分の口を塞いだ。

「喋るのは大丈夫だよ」とあなたが言う。

子供はほっとして、ゼオンへ昨日なくした靴の話を始めた。英雄は真剣に聞いた。町を救ったときの話より、返事に困っている。

草地へ着くと、獣は三度長く息を吐いた。犬より大きく、馬より小さい。ニマは地面を叩く。獣がそこで座った。

仲間があなたへ尋ねる。「車、まだ鳴らす？」

- 鳴らす前に、自分たちが作った車だと観客へ伝えたい。→ [09へ](#s09)
- 今日は車を休め、獣が落ち着くまで仲間と草地にいる。→ [10へ](#s10)

<a id="s07"></a>

### 07 英雄の拍手教室

ゼオンは客席の真ん中へ降り、両腕を広げた。

「俺の手が上なら、見る。下なら、一回だけ叩く」

最初の練習で、彼自身が二回叩いた。子供たちに指摘され、もう一度やり直す。観客の笑い声では、獣の腹は変わらなかった。

ニマが前を行き、あなたたちは〈獣鳴号〉を草地へ運ぶ。ゼオンは進む方向へ身体を向けて合図する。拍手が小さく一度ずつ起こり、そのたびに獣が付いてくる。

草地では、獣を中央へ、車をその外側へ置いた。屋根の高さからなら、手の合図が遠くまで見える。ニマが獣の息を指で数え、ゼオンが同じ長さだけ腕を上げ続けた。

誰も叩かない間、あなたは七本目の管へ空気を送る。

深い音が、草地にいる全員の足へ来た。獣は驚いて耳を立てたが、大きくはならない。

- 車の周囲を歩く仲間と、演奏を始める。→ [11へ](#s11)

<a id="s08"></a>

### 08 もう一匹の主役

あなたは木彫りの顔の上へ乗り、両腕を上げた。

「こっちだ！」

歓声。そのあとに、待っていた拍手。

獣が身体を起こす。あなたは思わず笑った。これほど大勢が、自分の動きに合わせて声を上げたことはなかった。母の帽子が、列の向こうに見えた気がした。

次の瞬間、獣の鼻が木彫りの顔を押した。

飾りの柱が一本折れる。あなたは屋根の縁を掴み、ぶら下がった。獣は噛みつかず、あなたの背後で拍手している客へ鼻を伸ばそうとしている。

ゼオンが剣ではなく梯子を持って走ってくる。ニマは観客へ背を向け、両手を開いて止めた。誰かが驚いて叩き続けていた手を、隣の人がそっと下ろす。

静かになる。獣の腹が、大きな一息で細くなり始めた。

- 梯子を待ち、獣が息を吐き切る間に横へ降りる。→ [12へ](#s12)
- 壊れた車の飾りを足場に降り、今日は演奏をやめると仲間に伝える。→ [13へ](#s13)

<a id="s09"></a>

### 09 七人の名札

あなたは仲間を呼び、七人で車の前へ並んだ。

まだ名札が裏なら、ここで表へ返した。既に表なら、油の付いた端を服へ擦り付けてみた。汚れが広がったので、それ以上はやめた。

ゼオンが七人の名前を順に読む。三人目で読み間違え、本人に直される。仲間たちは、あなた一人が前へ出ると思っていたらしい。順番が回るたびに、居心地が悪そうに胸を張った。

あなたは七本目の管を指し、それを作った一番若い仲間を前へ押し出した。彼女は頷いてから、逆にあなたの肘を引く。

「車軸が回らないと、鳴らないんです」

観客の前で、自分の仕事の説明をする。うまく始められなかったので、手で車輪の形を作った。母の帽子が動き、今度は本当にこちらを向いた。

**「名札」を「表」にします。**

- 拍手は合図まで待ってもらい、車を鳴らす。→ [11へ](#s11)

<a id="s10"></a>

### 10 草の上の歯車

あなたは最後の制動棒を下ろした。七本目の管は、明日でも鳴る。

仲間が車の影に腰を下ろす。ニマが獣の腹へ耳を当てていると、ゼオンも同じ姿勢を真似し、鼻で押し戻された。客は拍手せずに笑った。

母が草地を横切ってくる。手には、差し入れの包みがあった。

「真ん中あたりって、車の下だったの？」

あなたは後輪の軸を見せた。母は少しも分からない顔で、話の終わりまで聞く。最後に「ここが回ると、あっちが鳴るのね」と、正しい順番で指を動かした。

獣が寝返りを打つ。皆が少しずつ離れ、草の上に輪が広がった。

- 車の影へ母の分の場所を空ける。→ [16へ](#s16)

<a id="s11"></a>

### 11 拍手の間の音楽

車輪を一回転。低い管から高い管へ、空気が順番に送られる。

屋根のゼオンが片腕を上げた。「下ろしたときだけ、一回」。自分の手で一度やってみせ、また腕を上げる。観客は手を離したまま見ている。あなたが横の取っ手を回すと、木彫りの舌が動き、七本目が鳴った。

腕が下がる。一度だけの拍手。

獣は金色の粒を飲み込み、満足そうに鼻を鳴らす。ニマが息を待つ。ゼオンの腕が、また上がる。その待ち時間へ、あなたたちは次の音を置いた。

行列のために作った曲が、獣の呼吸に合わせて伸び縮みしている。最初は戸惑っていた仲間が、途中から待つところへ短い旋律を足した。

**「名札」が「表」の場合：** ゼオンは七人に名前を言ってもらい、曲の合間に一人ずつ呼んだ。呼ばれた人が自分の仕掛けを動かす。あなたの番には、車全体がゆっくり一周した。

**「名札」が「裏」の場合：** ゼオンは工房の人たち、と紹介し、車へ大きく腕を向けた。仲間の一人が帽子を振る。あなたは取っ手から手を離さず、その帽子の揺れを車の影で見ていた。

獣はもう、最初の大きさに近い。観客も一回ずつの拍手に慣れた。終わり方を決める時間だった。

- ここで音を止め、獣が眠るまで草地を静かにしておく。→ [14へ](#s14)
- 最後の一曲を、観客の拍手と獣の息も含めて演奏する。→ [15へ](#s15)

<a id="s12"></a>

### 12 息の長さ

獣が息を吐く。木の顔へ押し付けていた腹が離れ、あなたの足元が広くなった。

ゼオンが梯子を支える。あなたは一段ずつ降りた。途中で膝が笑い、最後の二段は手で身体を支えた。

「次は俺があそこへ立つ、とは言わないぞ」とゼオンが言った。

あなたは頷く。木彫りの片耳が取れ、管を隠していた飾り板が割れている。車輪と鞴は無事だった。仲間の一人が取っ手を回し、小さな音で確かめる。

ニマは少し離れた場所で一度だけ手を叩き、獣を車から退かせた。

七本目は鳴る。壊れた飾りは、そのまま客に見える。

- 折れた柱と割れた飾り板だけを外し、静かな道で草地へ運ぶ。→ [06へ](#s06)
- 今日は演奏をやめ、仲間と車を片付ける。→ [13へ](#s13)

<a id="s13"></a>

### 13 拍手の終わったところ

あなたが止めると告げると、仲間は一人ずつ手を止めた。

最も若い仲間だけが、七本目の管を見ていた。あなたが声を掛けると、彼女は「割れてない」と答える。怒っていないわけではなかった。管を抱えて下ろすとき、あなたが手を出すまで待たなかった。

ゼオンとニマは、観客へ草地への移動を頼んだ。拍手を少しずつ移すと、獣も付いていく。人のいなくなった通りに、木片と縄が残った。

あなたは折れた柱を拾い、仲間が持つ箱へ入れた。言い訳をするには、同じ破片を二人で見すぎていた。

「明日、直す。私の分から始める」

若い仲間は管を抱え直し、「私の管を、先に鳴らして」と言った。

- 工房へ車を押して帰り、翌朝、七本目のために組み直す。→ [17へ](#s17)

<a id="s14"></a>

### 14 祭りの余白

**結末 E1：眠った主役**

最後の音を長く伸ばして止めた。ゼオンの両手が頭の上で静止する。観客も、そのまま待った。

獣は前脚へ鼻を載せる。金色の湯気が細く上がり、それきりだった。

誰かが敷物を広げると、隣の人も座った。出店の売り手が籠を持って歩き始める。祭りは大通りを進まなくても、ここで続いた。

**「名札」が「表」の場合：** 木彫りの顔を見ていた子供が、あなたの名を呼んだ。どうして鳴くの、と聞かれ、あなたは手で車輪の形を作りながら答えた。

**「名札」が「裏」の場合：** 子供は車の仕掛けを指差し、「これ、誰が作ったの」と近くの仲間に尋ねた。仲間があなたの肩を叩く。あなたはまず、七本目を作った人のほうを指した。

夕方、車を戻す前に、あなたは工房の名を書いた板を側面へ取り付けた。名前のない板を使っていたことを、仲間たちも不思議そうに見た。

眠る獣の横を、車輪だけの音で通り過ぎた。

<a id="s15"></a>

### 15 栄光の行き先

**結末 E2：町じゅうの一拍**

最後の曲では、最初にゼオンが失敗した。早く手を下げたため、七本目より拍手が先に来た。

獣が小さく膨らむ。観客が笑う。彼は両手を上げ直し、ニマの指を見て、今度は長く待った。

あなたは笑ったまま取っ手を回す。音が鳴る。手が下がる。一拍。

獣はゆっくり息を吐いた。その金色の息の向こうに、母の帽子が見える。今度は、あなたがどこにいるか、迷っていなかった。

**「名札」が「表」の場合：** 曲が終わると、七人は屋根と側面の足場へ分かれて上がった。ゼオンが名を呼び、客が一人ずつに一拍を送る。あなたの一拍も獣が食べた。呼ばれた名は、食べられずに残った。

**「名札」が「裏」の場合：** 曲が終わり、仲間たちが車の周囲で礼をする。あなたも後部から一度顔を出した。母がこちらへ手を振る。大勢にはまだ名前を知られていないが、車のどこに人がいるか、客は前よりよく見ていた。

ニマが獣を連れて帰る。満腹の獣は、もう次の拍手を探さなかった。

〈獣鳴号〉はその日、英雄一人を乗せるより、ずっと多くの間違いと笑いを運んだ。

<a id="s16"></a>

### 16 裏道の凱旋

**結末 E3：真ん中あたり**

包みには、七人分より多い食べ物が入っていた。母は人数を聞かなかったのだと言い、仲間は八人目の場所を空けた。

ゼオンも端に座ったが、母に英雄だと気付かれたのは、二つ目を食べ終えてからだった。彼は名乗り直し、母は先に食べさせてしまったと笑った。

**「名札」が「表」の場合：** ゼオンは食べながら、七人の名を確かめて手帳へ書いた。「次にこの車を使うとき、垂れ幕を作り直す」。あなたは自分の名の一画だけ直した。

### 17 鳴らし直した獣鳴号
