## この20作について

GB01〜GB20の本文レビューを反映した設計モデルv1.2bで、新たに作成した20作です。各作は独立した短編ゲームブックです。同名の人物がいても、作品間の同一人物や共通世界を前提にしません。

梗概や構成案ではなく、導入、遊び方と記録、番号付きの全本文、選択肢と遷移先、全結末、作者用設計メモまでを収録しています。第1稿として読み直しと原稿上の分岐検査を行った段階です。ゲームへの実装は完了しています。実読者による試読は未実施です。

HTML版ではGB21〜GB40を含む短編40作を選べます。GB01〜GB20の原稿は[初版・第2版の目次](../../scenarios/README.md)にあります。GB21〜GB40については、このフォルダのMarkdownを本文の正本とします。

全333節・81結末を実装しました。ゲームでは記録と本文の条件分岐を自動で処理します。GB21〜GB24の専用画像・BGMは導入済み、GB25〜GB40は未制作です。[素材記録](../../SHORTS_21_40_ASSETS.md)に続きがあります。[実装仕様と検証範囲](../../SHORTS_21_40_IMPLEMENTATION.md)を参照してください。

## 読み方

各作の「導入」と「遊び方と記録」を読み、01から選択肢のリンクをたどってください。必要な印や数値がある作品では、紙やメモに記録します。条件付きの段落は、自分の記録に合うものだけを読みます。節を読み返しただけで、数値や印を重複更新しません。

「結末」のある節で、その経路の物語は終わりです。別の経路を読むときは、最初の記録へ戻して開始してください。作者用設計メモには仕組みや全結末の根拠があるため、初回は読了後に開くことを勧めます。

- **[GB22 雪原の二番手](gb22.md)** — 三年続けて二位だった帆職人が、自作の雪橇で勝ちにいきます。脚を使う場所、風を取る位置、ライバルへの対応を選ぶ競争です。
- **[GB23 あなたより先に帰った影](gb23.md)** — 出張から帰ると、あなたの影が家族と夕食を作っています。同じ顔の微差と、先に始まった生活に触れる怪異譚です。
- **[GB24 赤い傘の相棒](gb24.md)** — 上へ降る雨に傘を広げ、月の珠を盗みにいく夜。相棒には別の目的があり、二人の予定が侵入と脱出を変えます。
- **[GB25 竜の背中の菜園](gb25.md)** — 祖母から預かった畑は、巨大な地竜の背中にあります。水路、雲、鳥、土をたどり、植える、食べる、眺める午後を選びます。

## 第1稿で重視したこと

主人公が欲しいものを、選択の前の台詞や動作に置きました。分岐の結果は、成功・失敗の表示だけでなく、相手の返事、物の位置、次の暮らし、場面の見え方として書いています。

見学する、普通の道を通る、先に話す、持っている物を使う、といった自然な方法も成立させています。すべての作品に犠牲や拒絶を付けず、競争、喜劇、怪異、関係、探索、演奏、街歩きで遊びの中心を分けました。

詳しい仕組み、記録の意味、重要な経路の照合は各作末尾の作者用設計メモへ、20作共通の確認範囲は[REVIEW.md](REVIEW.md)へ分けています。
