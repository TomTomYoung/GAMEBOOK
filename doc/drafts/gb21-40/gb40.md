# GB40 最後の頁を盗んだ子

ドラフト第1稿／設計モデルv1.2b／作成日2026-10-21／ゲーム未実装

[20作の目次](README.md)

## 導入

祖父が作った絵本の、最後の一頁がなくなっていた。

『夜の灯台』。あなたが子供の頃、何度も開いた本だ。海辺の子が光る石を拾い、古い灯台へ運ぶ。夜の船がその光を見つけて帰り、子は灯台の戸を閉める。あなたは最後の、丸い窓の絵が好きだった。

今はあなたが、祖父の製本道具を使っている。今日はこの本の緩んだ綴じ糸を替えるはずだった。

最後の糸だけが、綺麗に抜かれている。落丁ではない。

見開きの海へ顔を近付けると、紙の上に小さな足跡があった。描かれた子が、本来立つはずの場所にいない。

頁の端で、何かが折れる音がした。

「それ、返してもらえる？」

あなたが声を掛けると、波の線の向こうで子供が答えた。

「返したら、また最後になる？」

## 遊び方と記録

開始は[01へ](#s01)。選んだ先だけを読んでください。

記録は「朝の下絵」の印一つで、初めはありません。該当する指示で付けます。これは祖父の未使用の下絵を見たという記録です。成功するための必須印ではありません。

この工房の絵本では、絵の中の人が、開いている頁の線を歩いて話します。本を閉じると眠り、次に開いたときは、綴じられた頁のうち、いちばん後ろにある自分の絵の場所から起きます。閉じた間に苦痛や飢えを感じることはありません。

紙へ描き足した線や、つないだ別の紙も、絵の中では道や場所になります。鉛筆なら消して直せます。人の気持ちは文章を書いただけでは変わりません。

あなたは机の外にいて、手と道具で本に働き掛けます。作業に使う紙は足りています。読む時間で夜が迫ることはありません。

## 本文

<a id="s01"></a>

### 01 いない場所

灯台の前には、足の形に白いところが残っていた。

あなたがそこを指で触れると、海のほうから「今、そこにいない」と声がした。波の端に小さな紙舟がある。帆に見えた白い三角は、折り曲げた頁の裏側だった。

子供の名前はミオ。祖父の字で、最初の頁にそう書いてある。あなたは今まで、声に出して呼んだことがなかった。

「ミオ」

舟が少しだけ、こちらを向いた。

灯台には、光る石が置かれている。火ではないから、誰もいなくても消えない。絵本の最初に書いてあることだ。ところが最後の絵では、ミオはいつも、石の下の椅子に一人で座っていた。

- 祖父の道具箱にある、この本の下絵を開く。→ [02へ](#s02)
- 舟を捕まえる前に、ミオが何をしたいのか尋ねる。→ [03へ](#s03)
- 頁の外へ流れそうな舟へ、手を差し出す。→ [04へ](#s04)

<a id="s02"></a>

### 02 印刷されなかった朝

道具箱の底に、薄い紙が束ねてあった。祖父は絵本になる前の絵を、何でも取っておく人だった。

灯台の頁が三枚ある。一枚は本と同じ夜。一枚は窓の大きさが違う。そして三枚目は、朝だった。

灯台の下に、小さな舟が描かれている。舟の中に人はいない。余白には「遠くから自分の灯を見る」と、祖父の字で書いてあった。

あなたはその字を指でなぞりかけ、止めた。誰が舟へ乗る予定だったかは、書かれていない。朝の絵が本に入らなかった理由もない。

海の頁から、ミオが背伸びしている。

「何があったの」

あなたは朝の灯台を見せた。ミオは目を細めた。「眩しそう」と言い、それから舟のほうを長く見ていた。

**「朝の下絵」の印を付けます。**

- 下絵を机へ残し、ミオの話を聞く。→ [03へ](#s03)
- 朝の絵を横へ置き、今いる海の地形を一緒に見る。→ [05へ](#s05)

<a id="s03"></a>

### 03 舟からの返事

「灯台が嫌になった？」

あなたが尋ねると、ミオは首を振った。

「窓は好き。石を磨くのも。汚れると、光が変な形になるから」

舟の縁に、磨き布が掛けてある。持ち出した道具は、それだけだった。

「でも、最後に座るのは、いつもあの椅子。次に起きても、あの椅子。舟が帰ってくるところしか見たことがない」

ミオは海の端を指した。

「自分が舟に乗って、灯台を見てみたい。そのあと帰るか、もう少し行くかは、見てから考えたい」

あなたは、丸い窓の絵を好きだったと話した。ミオは少し嬉しそうな顔をした。それから「窓の外から見たんだね」と言った。

舟を引き戻したくなる手を、あなたは机の縁へ置く。

「最後の頁は、そこにある？」

ミオは、自分の乗る舟の底を叩いた。

- 海と灯台の間に、舟が着ける場所を探す。→ [05へ](#s05)

<a id="s04"></a>

### 04 指先の防波堤

あなたは紙舟の前に、指を一本置いた。

舟は止まった。ミオが舟の底へしゃがみ込む。掴まれると思ったらしい。あなたは指を動かさず、もう片方の手で本が傾いていたのを直した。

波の線からはみ出した舟の先が、白い余白に乗っている。水も道も描かれていないところでは、ミオは足を置けない。舟を折ったことまでは考えていても、どこまで海があるかは見ていなかったのだ。

「帰す？」

「まず、落ちないようにしてる」

ミオは舟の底から顔を上げた。灯台を遠くから見てみたい、と小さな声で言う。もう少し先へ行けると思っていたらしい。

あなたの指の爪へ、舟の帆が触れる。そこには、祖父の描いた丸い窓の半分があった。

- 指を動かさず、ミオが話し終えるまで聞く。→ [03へ](#s03)
- 舟の横から今の岸まで、鉛筆で細い桟橋を描く。→ [06へ](#s06)

<a id="s05"></a>

### 05 海のあるところまで

本を平らに置くと、舟は頁の下側へ寄った。

ミオは、自分の舟に描かれた灯台と、元の頁に残る灯台を見比べた。最後の頁の夜景を折って舟にしたので、灯台が二つに見える。

「戻してって言われる前に、舟にした。舟がなかったから」

あなたは鉛筆を削り、頁の白い端へ短い線を一本引いた。ミオが舟からつま先を出し、線に載せる。岸まで続いていないので、まだ歩けない。

「道は、つなげれば渡れる。でも、行った先が白いと、また止まる」

ミオが自分で確かめたことを、あなたへ教えた。

灯台の石は、遠くでも光っている。あなたは空いた紙を一枚、机へ出した。海を広げても、桟橋を戻してもよい。最後の頁の印刷を削る必要はない。

- 今の岸へ桟橋をつなぎ、ミオと頁をいったん戻す。→ [06へ](#s06)
- 別の紙に港を描き、海の線をそこまでつなげる。→ [08へ](#s08)

<a id="s06"></a>

### 06 折り目を渡る

あなたは二本の線を平行に引き、間に横木を描いた。ミオが一つずつ足を置く。五本目で、紙の綴じ目に差し掛かった。

本の中央は少し沈んでいる。桟橋も一緒に曲がり、ミオが両手を広げた。

あなたは本の背の下へ畳んだ布を敷く。海の左右の高さが揃う。ミオは揺れの止まった線を踏み、振り返った。

舟が、まだ向こうにある。

「最後の頁でしょう」とあなたが言うより早く、ミオは戻った。端を引こうとして大きすぎたので、舟をもう一度開き、紙の縁を桟橋へ掛ける。

あなたは指で支え、ミオは下から押した。絵の中の小さな肩と、机の外の指が、同じ紙を動かしている。

頁が岸へ上がると、ミオは座り込んだ。怒られるのを待つ姿勢ではなく、本当に疲れたらしい。

- 頁を広げ、ミオの横へ置く。→ [07へ](#s07)

<a id="s07"></a>

### 07 丸い窓の裏

折り目を伸ばすと、丸い窓が戻った。

あなたはこの頁を何度も見た。膝に本を載せた祖父の指、窓の中の黄色、眠くなる前の部屋の温かさ。それが一度に戻ってきた。

ミオは窓の内側を指す。

「椅子の背が、高いんだ。ここからだと、海が少ししか見えない」

椅子の背。あなたは今まで、気にしたことがなかった。窓の輪郭をよく見せるために、祖父が濃く塗ったところだ。

最後の文章は「ミオは戸を閉め、ひとりで朝を待ちました」。朝を待ったところで、本は終わっていた。

「朝の頁を、後ろへ足せる」とあなたは言った。

ミオはすぐ頷かなかった。「どんな朝？」

- すぐ描かず、ミオと次の場所を話す。→ [09へ](#s09)
- 今日は元の頁で休み、明日続きを考える案を出す。→ [10へ](#s10)

<a id="s08"></a>

### 08 机の上の港

あなたは別の紙へ、低い岸壁と三つの階段を描いた。海の線を本の端から伸ばし、紙の端どうしを細い紙帯でつなぐ。

ミオは舟を動かした。印刷された海から鉛筆の海へ来ると、舟の影が少し薄くなる。消えはしない。彼女は水へ指を入れ、その濃さを確かめた。

岸壁には、まだ何もない。

「何屋さんが欲しい？」

あなたが尋ねると、ミオは考えてから答えた。「何屋さんか、着く前には分からないほうがいい」

あなたは店を描く代わりに、曲がり角を一つ描いた。ミオは角へ駆け寄り、向こうが白いのを見て戻ってきた。

「もう少し先も、描いて」

最後の頁だった舟を開くと、港の上に夜の灯台が載った。元の絵は、どこも消えていない。ミオは舟の形がなくなるのを残念そうに見たが、あなたが別の紙を折ると、その手元へ身を乗り出した。

- 新しい小舟を岸へ置き、次の場所を一緒に考える。→ [09へ](#s09)

<a id="s09"></a>

### 09 終わりの先の話

「灯台は残して」とミオは言った。

あなたは頷く。丸い窓も、光る石も残せる。最後の頁を元の位置へ綴じ直し、その後ろへ紙を足せば、次に本を開くときの居場所を新しくできる。

一日だけの舟旅を描くこともできる。別の港へ長く続く折込みの頁を足すこともできる。あるいは、ミオが描きたい場所を聞きながら、少しずつ線を引いてもいい。

ミオは灯台を見て、それから白い紙を見た。

「帰り道も、つけてくれる？」

「行きの道と、つながるように」

彼女はここで初めて笑った。灯台を出たいのと、灯台をなくしたいのは、別のことだった。

- 一日の舟旅と帰り道を、新しい最後の頁として一緒に描く。→ [11へ](#s11)
- 元の結末の後ろへ、遠い港まで続く折込みの頁を足す。→ [12へ](#s12)
- ミオに行きたい線を描いてもらい、その続きを自分の手で描く。→ [13へ](#s13)

<a id="s10"></a>

### 10 今日の寝床

「今日は戻して、明日もう一度開くのはどう」

あなたが言うと、ミオは椅子を見た。それから自分の服に付いた鉛筆の粉を払う。

「今日は、それがいい。桟橋を渡るの、疲れた。でも、明日も同じことを言わないで」

あなたは最後の頁を元の位置へ綴じ直し、その後ろへ新しい紙を一枚、仮留めした。まだ白い。ミオがその上に描かれていないので、次に起きるのは元の椅子だ。

「開いたら、ここに海を描く」

あなたが余白を指す。ミオは場所を一度変えた。「こっち。朝の光が入るほう」

小さな矢印を付けると、彼女は灯台へ戻った。座る前に、椅子を窓のほうへ少しずらす。

あなたは、その位置を鉛筆で描き直した。

- 明日開くための栞を挟み、今夜は本を閉じる。→ [14へ](#s14)

<a id="s11"></a>

### 11 遠くから見る灯

あなたは明るい海を描き、小舟を置いた。ミオが乗る。櫂の幅が大きすぎたので、彼女の腕に合わせて消して直す。

舟を動かすのは、ミオだった。あなたは揺れる舟の下へ、少しずつ波を足す。灯台が小さくなるたび、ミオは振り返った。

「まだ見える」

光る石は、昼の絵の中でも白く残った。あなたが消したわけではない。夜の濃い青がなくなったので、眩しさの形が変わったのだ。

海の途中で、ミオは櫂を止めた。

「ここまでで、今日はいい」

帰り道の波をつなぐ。港に小舟を着けたミオは、今度は灯台を外から見上げた。椅子を置くなら、窓だけでなく、小舟も見える場所がいいと言う。

あなたは最後の頁に、灯台と港を一緒に入れた。ミオの姿は、まだ舟に片足を残している。

- その朝の絵を、元の夜の頁の後ろへ綴じる。→ [15へ](#s15)

<a id="s12"></a>

### 12 長い紙の港町

折込みの紙を広げると、机の端まで届いた。

あなたは海沿いに道を引き、遠くへ港を描いた。灯台へ戻る道は、紙の下側をゆっくり回ってつなげる。ミオが指でたどり、途中で線が切れていないかを見る。

**「朝の下絵」がある場合：** あなたは祖父の朝の絵を、折込みの最初に重ねてみた。ミオは舟の位置だけを少し動かす。「ここだと、帰る舟とぶつかる」。祖父の線と、新しい線が並んだ。

**「朝の下絵」がない場合：** あなたは港に向かう最初の朝を、自分で描いた。ミオは波を一つ増やしてほしいと頼む。「ずっと平らだと、舟に乗った気がしない」。あなたは短い線を足した。

遠い港には、市場を作った。魚屋、縄屋、何を売るかまだ決めていない店。あなたが看板を書いている間に、ミオは縄屋の前へ行っている。

「舟の紐を買いたい。手持ちのお金は、描かれてないんだけど」

縄屋の人は、灯台の光る石の話を聞かせてくれれば短い紐を一本あげる、と言った。ミオは店の前に座り、あなたが知らない磨き方の話を始めた。

- ミオがこの港でも目を覚ませるように、帰り道を残した折込みを最後に綴じる。→ [16へ](#s16)

<a id="s13"></a>

### 13 小さすぎる鉛筆

あなたは削った鉛筆の先を、頁へ寝かせた。ミオが両腕で抱えると、丸太ほどの太さがある。

「これ、動かせない」

あなたは芯の欠片を一つ、紙の上へ置いた。ミオはそれを持ち上げ、両手を黒くした。自分の掌を見て笑い、それから白いところへ線を引く。

線は曲がっていた。あなたは定規を持ちかけ、やめる。

最初に描いたのは道でなく、靴だった。今日、舟へ乗っただけで靴が濡れたから、もう一足欲しいという。あなたは靴を大きく描き直し、ミオはそれを履いて歩いた。

次は低い椅子。次は窓から港へ続く階段。やがて彼女は道の先に、まだ名前のない黒い形を一つ描いた。

「これは？」

「着いてから決める」

あなたはその形を塗り潰さず、道が届くところまでを新しい頁にした。

ミオは低い椅子へ腰を下ろした。あなたは、その姿も新しい頁に描き留めた。

- ミオが描いた線を残したまま、最初の一枚を最後へ綴じる。→ [17へ](#s17)

<a id="s14"></a>

### 14 明日の栞

**結末 E1：今夜はここで**

閉じる前に、ミオは窓から顔を出した。

「朝、最初に開いてね」

あなたは頷き、手の届く場所に本を置いた。頼まれた修理として書いていた作業札の横へ、自分の字で「海を足す」と書く。

翌朝、本を開いた。ミオは描き直した椅子で目を覚まし、すぐに白い紙を見た。

あなたは約束の矢印から、海の線を一本引く。

ミオが椅子を降りた。

その一歩まで描いてから、あなたは朝食のパンを取った。続きはまだ白い。それでも、昨日と同じところで閉じるために、本を開いたのではなかった。

<a id="s15"></a>

### 15 朝を持った本

**結末 E2：帰ってきた舟**

糸を通し直すと、本は一頁ぶん厚くなった。

元の最後の絵は、そのまま残っている。丸い窓の黄色も、祖父の文字も。その次をめくると、ミオが舟から降りかけていた。

「もう一度開いて」

あなたは本を閉じ、開く。ミオは朝の港で目を覚ました。片足が舟に残っているので、最初に少しよろけた。彼女が笑い、あなたも笑った。

**「朝の下絵」がある場合：** 祖父の未使用の絵は、道具箱へ戻した。新しい頁とそっくりではない。あなたは余白へ、自分とミオが別の舟を描いた日付だけを添えた。

**「朝の下絵」がない場合：** あなたは新しい頁の隅へ、自分の名とミオの名を小さく書いた。祖父の名がある扉は、そのままにした。

次にこの本を読む人は、夜の窓を見た後、もう一枚めくることになる。

ミオは濡れた靴を脱ぎ、灯台の外へ並べていた。

<a id="s16"></a>

### 16 折り畳まれた遠く

**結末 E3：帰り道のある旅**

市場の絵を描き終える頃、ミオは短い紐を手にしていた。縄屋へ礼を言い、小舟の先へ結ぶ。結び方はうまくない。二度ほどほどけ、三度目で落ち着いた。

あなたは折込みの最後に、舟を留めた市場の岸を描いた。ミオの姿もそこへ置く。

本を閉じても、紙を切り離したわけではない。灯台から市場への線と、帰る線は、折り畳まれたままつながっている。

次に開くと、ミオは市場の岸で目を覚ました。いちばん先に、帰り道を目でたどる。それから安心したように、昨日は白かった看板を読みに行った。

あなたは本の背へ、新しい細い布を足した。少し太くなった背が、掌へ収まる。

灯台の窓は、本の前のほうに残っている。ミオが帰る日には、またそこから、海の見え方が変わるだろう。

<a id="s17"></a>

### 17 二つの筆跡

**結末 E4：最後の頁の続きを描く人**

新しい最後の頁には、あなたの細い線と、ミオの太い線が混じっていた。

あなたが「見栄えは」と言いかけると、ミオは黒くなった掌を見せる。その掌の形が、頁の隅に一つ残った。

本を一度閉じて開く。ミオは新しい低い椅子から立ち、濡れていない靴で階段を下りた。自分の線が途中で少し曲がっているのを見つけ、芯の欠片でそこを太くした。

道の先の黒い形には、まだ名前がない。今日はそこまで行かず、灯台へ戻る階段に手すりを付けた。

あなたはその作業を、しばらく見ていた。

机の上には、予備の紙が残っている。ミオは勝手に次の紙を引き寄せられるほど大きくない。だから、あなたの指を二度叩いた。

あなたは一枚渡した。

### 体験の核と固定前提

大切な既存の本を直す手が、登場人物と一緒に続きを作る手へ変わる。祖父の作品を悪意ある牢獄にせず、読者だった主人公の温かい記憶と、絵の内側にいるミオの窓の見え方を両方残す。全経路で元の頁の印刷を消去しない。追記で成立する解法を、作品の主題を壊す抜け道として排除しない。

本は開いている間だけ人が動き、閉じると眠る。再開位置は、その人が描かれた最後の綴じ頁で決まる。白い紙だけを足してもミオの再開場所は変わらない。線はつながっていれば道になり、空白は足場にならない。新たに描いた港や住人も絵の世界へ入る。人物の気持ちは作者の断言で上書きされない。

この仕組みは絵本の中だけの前提。主人公が紙の人を肉体として外へ出せること、線を描いて現実世界を改変できることは設定しない。未知の外界でミオを罰する結末も置かない。
