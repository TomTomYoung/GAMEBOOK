# GB29 ひと晩だけの悪役

[20作の目次](README.md)

## 導入

「今日だけ、町に嫌われてくれ」

祭りの楽屋でそう頼んだのは、二十年悪役を務めてきたベロだった。声は紙を擦るようにかすれている。昼の呼び込みで張り切りすぎたらしい。

あなたは染物屋だ。今夜のために、悪役の長い黒マントを染めた。裾の裏には赤を入れた。振り向くたびに火が見えるように、勝手に仕立て直してある。

ベロはそれを肩へ掛けさせ、黒い帽子をあなたの頭へ載せ、木の王冠を渡した。

「ただし、嫌われ方は自分で決めな。去年は税金を三倍にすると言ったら、拍手が止まった」

外から勇者アサの名を呼ぶ声がする。あなたは鏡の前で一度回った。黒の下から、鮮やかな赤が翻った。

## 遊び方と記録

今夜は町の「夜冠祭」。車を通さない祭り区画で、勇者と悪役が町を舞台に追いかけ合う。あなたは悪役として木の王冠を持ち、広場から西の荷車場にある黒い鐘を目指す。鐘は地面に立ったまま鳴らせる高さにある。

あなたの手首には赤い腕章がある。勇者アサの布剣の先が腕章へ触れれば、あなたは捕まる。捕まる前に王冠を持つ悪役が黒い鐘を鳴らせば、その悪役の逃亡成功。衣装を脱いでも腕章は外さない。人に剣を振る、町の品物を壊すといった行為は競技に含まれない。

祭りの参加者は、助太刀や小芝居をしてよい。赤い腕章をつけて新たな悪役になる人へ、捕まる前に王冠を渡すこともできる。勝った悪役を翌年まで閉じ込める決まりも、必ず勇者に負ける決まりもない。

記録は「名乗り」だけ。最初は未選択。01で「威圧」「大ぼら」「変装」のいずれかを記録する。後で同じ名乗りを参照する。時間は選択によって進み、読む速度は使わない。01から始めよう。

## 本文

<a id="s01"></a>
### 01 黒マントの出番

噴水広場の入口で、あなたは木の王冠を持ち直す。三つに尖った飾りが、灯りを受けて金色に光った。通りの先には荷車場の黒い鐘が見える。まっすぐ進む道は、すでに勇者の一団で塞がれていた。

右手は干上がった水路の小橋。左手は市場の屋台。そのさらに裏には、染物を干す細い路地がある。あなたが毎日、布を運んでいる道だ。

アサは広場の中央で布剣を一回転させた。剣先より先に、靴の向きが変わる。去年、ベロを捕まえたときも、同じ足運びをしていた。

「今年の悪役は誰だ！」

誰かが叫ぶ。ベロが背中を押した。押された勢いを、そのまま登場に使ってもいい。

- 噴水の台へ上がり、低い声で町を支配すると告げる。「名乗り＝威圧」と記録する。[02へ](#s02)
- 王冠を掲げ、月も休みも盗む大悪党だと名乗る。「名乗り＝大ぼら」と記録する。[03へ](#s03)
- マントの上に荷運びの外套を羽織り、群衆へ紛れて出る。「名乗り＝変装」と記録する。[04へ](#s04)

<a id="s02"></a>
### 02 町を影にする者

「今夜から、この町の影はすべて私のものだ」

あなたは噴水の台へ片足を掛け、マントを広げた。裾の赤が灯りを受ける。最前列の人々が芝居がかって後ずさりし、奥の子どもたちがその隙間から覗いた。

「昼は？」と誰かが聞く。

「昼もだ。影を踏んだら、ひと言ずつ私を褒めてもらう」

市場の方から「いい染め仕事！」という声が飛んだ。あなたは笑いそうになるのを堪え、ゆっくり頷く。

アサが剣をあなたへ向けた。「人々の影を返せ！」

客が道を開ける。逃げ道を作ってくれたのか、勇者を通すためか。どちらにせよ、今は走れる。あなたは台から下り、王冠を腕に抱いた。

- 水路の小橋へ走る。[05へ](#s05)
- 屋台の間を抜け、市場へ入る。[06へ](#s06)

<a id="s03"></a>
### 03 月曜日泥棒

「私は月を盗んだ！　ついでに来週の月曜日も盗んだ！」

広場の拍手が跳ね上がる。あなたが王冠を逆さに振ると、用意してあった銀紙の月が落ちた。拾おうとしゃがんだ途端、マントが頭へ被さる。

「盗んだ月に、食われておる！」

頭を出すと、アサまで笑っていた。けれど布剣は下げていない。

「月曜日を返せ。うちの店の休みだ」

客席代わりの群衆から、味方と敵の声が一斉に上がる。パン職人は火曜日も盗めと叫び、洗濯屋は雨の日だけにしてくれと言う。

あなたが腕を振るたび、注文が増える。いつの間にか町でいちばん忙しい悪党になっていた。アサが近づいてくる。返事を全部している暇はない。

- 「予約は市場で受け付ける」と叫び、屋台へ走る。[06へ](#s06)
- 紙の王冠を売る露店へ逃げ込み、身代わりを探す。[07へ](#s07)

<a id="s04"></a>
### 04 荷運びは見ていた

あなたは王冠を外套の中へ抱え、空の木箱を肩へ載せた。赤い腕章は袖の上にある。荷運びの役をしているパン職人が、あなたを見るなり目を丸くする。

「悪役、来なかったの？」

あなたは口へ指を当てた。パン職人は即座に表情を戻し、わざとアサの前で木箱を積み始める。

「勇者様、足元にお気をつけて」

アサは箱を見ず、その脇に立つ人の手首を見た。あなたは箱を積み手へ渡し、別の客の後ろへ移る。

「黒い裾、見えてるよ」と小声で言われた。振り返ると、看板描きのマキが笑っている。あなたのマントの赤を見つめ、それから自分の筆箱を閉じた。

「裏の屋台なら、もっと派手な隠れ方がある」

- マキの指した、市場の屋台の間へ進む。[06へ](#s06)
- 荷運びたちの流れを抜け、水路の小橋へ向かう。[05へ](#s05)

<a id="s05"></a>
### 05 橋の上の勇者

小橋へ出ると、アサが反対側から来た。広場の脇道を回ってきたのだ。水路は干上がっているが、橋の欄干には祭りの旗が立ち、下へ降りる道はない。

アサが剣先であなたの王冠を示す。「戻れば大通り。進めば私」

あなたは後ろを見ずに、染物路地の入口を思い浮かべる。橋の手前にある細い道だ。今夜は干し布が低く渡してあり、長いマントを広げたままでは引っ掛かる。普段着なら、腰を屈めて通り抜けられる。

アサの剣が小さく上下する。足の方は動かない。客は橋の両側で待ち、あなたの次の大言を聞こうとしている。

「どうした、悪党。影を盗んでも、足は二本か」

彼女は楽しんでいる。あなたも、この台詞を返すのは嫌いではない。

- マントを翻し、橋の上でアサと渡り合う。[08へ](#s08)
- 留め金を外してマントを腕に巻き、染物路地へ飛び込む。[09へ](#s09)

<a id="s06"></a>
### 06 市場はどちらの味方か

市場へ入ると、客たちがあなたを取り囲んだ。

「名乗り」が威圧なら、屋台の主人たちは品物の前へ立ち、「我らの影は渡さぬ」と、まな板や空の盆を掲げる。中央の道が塞がり、あなたは箱の並ぶ端へ回らされる。

大ぼらなら、来週の休みを盗んでほしい人たちが、指で曜日を数えながら道を開ける。あなたが走り出すと、後ろで勝手に予約の行列ができた。

変装なら、荷運びの外套を見た屋台の主人が空の籠を一つ渡してくる。あなたが王冠を出して見せると、主人は籠を取り返し、「勤勉な悪党もいるものだ」と客へ触れ回った。

通りの向こうで、アサの名を呼ぶ声が大きくなった。角の看板を描いていたマキが、筆を拭いた。板には「悪役募集中」とある。宣伝の文句かと思ったが、彼女はあなたへ紙の仮面を見せた。

- 屋台の箱の間へ入り、追ってくるアサを迎え撃つ。[08へ](#s08)
- マキの仮面を指し、「誰がかぶるつもり？」と聞く。[10へ](#s10)

<a id="s07"></a>
### 07 王冠が十個

露店には紙の王冠が十個並んでいる。店主はあなたの木の王冠と見比べ、手で包み隠すように一番似た紙冠を差し出した。祭りの追いかけっこに使っていい品だ。

あなたが礼を言いかけると、店主は悪党に要求した。「世界征服の後も、この店の場所は変えないで」

「最前列に置こう」

「それは困る。日が当たりすぎる」

看板描きのマキが笑った。彼女は紙冠を載せるための棒を持っている。その下には、折り畳んだ黒い仮面と赤い腕章があった。

「悪い顔も、名前も考えた。あとは出番だけ」

通りの向こうからアサが来る。染物路地へ入る角は、露店のすぐ裏だ。マキが紙冠を高く掲げれば、追い手は一瞬こちらへ目を向けるだろう。

- マキに紙冠を掲げてもらい、本物を持って染物路地へ抜ける。[09へ](#s09)
- 仮面の名前を聞き、マキと悪役を組む話をする。[10へ](#s10)

<a id="s08"></a>
### 08 悪党にも見せ場がいる

あなたは足を止め、王冠を高く掲げた。アサも止まる。客たちが二人の間の道を開ける。

「この冠は渡さぬ。私が三晩、金色になるまで塗った！」

「木のまま返せば、町の塗料代が浮いたのに」

アサの剣が来る。あなたは腕章のある手を引き、代わりにマントの端を差し出した。布剣は黒い布を叩く。赤い裏が炎のように広がり、周囲がどっと沸いた。

あなたは一歩、アサは半歩。剣先を見ていると追いつかれる。相手の靴がこちらを向く前に動くと、わずかな間が空く。染物を竿へ掛けるときの、長い布との呼吸に似ている。

アサが笑った。「そのマント、よく動くね」

「染物屋の自信作だ」

- マントを畳む動きに合わせて身を返し、荷車場へ走る。[11へ](#s11)
- 最大の悪態を叫び、剣に腕章を取らせて大げさに倒れ込む。[13へ](#s13)

<a id="s09"></a>
### 09 染物屋だけが知る空

あなたはマントを腕へ巻き付けた。変装の外套を着ているなら、それも脱いで一緒に抱える。赤い腕章と木の王冠は、布の外へ出して持つ。

染物路地では、青い布が頭のすぐ上を渡っていた。あなたは腰を低くし、竿の影を三つ抜ける。肩越しにアサの赤い飾りが見える。彼女も追ってきたが、初めて入る道では足を小さく運ばなければならない。

あなたは毎日、ここで布を運んでいる。左へ半歩、石の出たところを跨ぎ、最後の白布を肩で押す。向こう側に荷車場が開いた。

客の歓声は遠い。代わりに、自分の息と抱えた布の擦れる音がする。黒い鐘はすぐ前だ。あなたは王冠を持つ手を上げ、赤い裏地を地面へ流した。

- 追ってくるアサより先に、黒い鐘を鳴らす。[12へ](#s12)

<a id="s10"></a>
### 10 二番目ではない悪役

「西風のマキ」と、看板描きは言った。「手下じゃなくて、悪役がいい」

彼女は紙の仮面を開く。左右へ長い角があり、片方には空の色、片方には夜の色が塗ってある。額の文字は小さく、近づかないと読めない。

「いつも名前を描く側でしょう。今日は呼ばれたい」

マキは腕章をつけた。次に、露店の紙冠を棒の先へ載せ、自分とあなたの間に立てる。

「あなたがこれをマントで包んで持つ。私は本物を看板の裏へ隠して、荷車場へ行く。勇者があなたを追ったら、私が鐘を鳴らす」

あなたは紙冠と木の冠を見比べる。見つかれば自分が先に捕まる役だ。けれどマキは、もう自分の名乗りを口の中で練習している。

- 木の王冠をマキへ渡し、紙冠を包んで自分が囮になる。[14へ](#s14)
- 今回は自分で鐘へ行くと伝え、本物の王冠を抱えて走り出す。[11へ](#s11)

<a id="s11"></a>
### 11 鐘まで七歩

荷車場へ駆け込むと、黒い鐘の前へアサが滑り込んだ。市場から出る脇道を、あなたより短く走ってきたらしい。

「ここまで」と彼女が言う。剣は肩の高さにある。

あなたは王冠を左手へ持ち替えた。アサの目は王冠を追わず、あなたの靴を見ている。あなたがつま先を左へ向けると、彼女の右足がわずかに動いた。

鐘の手前には、荷車に掛ける大きな空の布枠が二つ並ぶ。祭りの間は追いかけっこ用に置かれ、どちらからでも回れる。右の枠はアサに近く、左の枠はあなたに近い。帽子を投げて飛び道具を装うこともできるが、腕章を伸ばせば剣の届く距離だ。

「名乗り」が威圧なら、客は小さな声であなたの異名を囁く。大ぼらなら、盗んだ曜日を返せと囃す。変装なら、「今度は何になる」と待っている。

- 帽子を高く投げ、アサの正面を一気に駆け抜けようとする。[13へ](#s13)
- 左の枠へ動き出し、アサが回り込む間に足を返して反対側へ抜ける。[12へ](#s12)

<a id="s12"></a>
### 12 今夜は悪党の勝ち

あなたは鐘の綱を引いた。低い音が荷車場から通りへ走る。アサの布剣が届いたのは、その一拍後だった。

「先に鳴った！」と客が叫ぶ。別の客も続く。アサは剣を下ろし、鐘を見上げた。それからあなたへ向き直る。

「来年は、その足も覚えておく」

あなたは王冠を掲げた。木の三つの尖りが、鐘の黒い腹へ金色の影を落とす。

「名乗り」が威圧なら、「影の使用料は今夜だけ無料」と告げ、客は一斉に自分の影を踏む。大ぼらなら、「月曜日は返す。雨だけ貰う」と言い、洗濯屋が誰より高く拳を上げる。変装なら外套を広げ、「本日の荷運びは世界征服につき終了」と札を出すふりをする。客がようやく、染物屋の顔を見つけて笑う。

ベロがマントの裾を拾い、土を払った。かすれた声で「派手に汚したな」と言う。

あなたは赤い裏地を見せた。来年、直すところはたくさんある。今夜の鐘の音が、その全部を仕事ではないものにしていた。

**結末 E1：黒い鐘の王**

<a id="s13"></a>
### 13 見事なる捕虜

アサの剣先が赤い腕章に触れた。あなたは大きく後ろへ仰け反る。

「ぐわあ。まだ、町の影を全部畳んでいない！」

もし帽子を投げて走ったのなら、アサはその帽子を見ず、踏み出したあなたの足へ合わせて剣を伸ばしたのだった。帽子は遅れて、二人の間へ落ちた。

あなたは片膝をつき、王冠をアサへ差し出す。彼女が取ろうとすると、もう一度高く掲げて、最後の悪態を足す。客は笑いながら、今度こそ取られてしまえと手を叩いた。

「名乗り」が大ぼらなら、アサは最初に月曜日の返還を命じる。威圧なら、広場の影へ謝れと言う。変装なら、荷運びの勤務表から名前を消すぞと脅す。あなたはどれも世界の終わりのように嘆いた。

捕虜の行列は市場を一周した。あなたが足を引きずるふりをすると、アサも剣を肩へ担いで歩調を合わせる。

楽屋へ戻ると、ベロが声を出さずに笑っていた。あなたのマントは、最後まで黒より赤の方が多く見えていたらしい。

**結末 E2：町でいちばんうるさい捕虜**

<a id="s14"></a>
### 14 悪名は二人分

木の王冠はマキの看板の裏へ収まる。あなたは棒についた紙冠をマントで包み、先だけを金色に覗かせた。

「追ってみろ、勇者。王冠はここだ！」

アサが市場へ走り込む。あなたは彼女を見ながら、鐘とは反対の小橋へ向かった。追い手を遠ざけるため、ここでは逃げ切るより目立つ方がいい。

橋の上で振り向き、マントを広げた。紙冠が棒の先で揺れる。アサの目が細くなった。彼女は一歩で距離を詰め、あなたの腕章へ剣を当てる。そのまま冠を覗き、「軽い」と言った。

「世にも軽い王であった」

あなたが答えた瞬間、荷車場の鐘が鳴る。続いてマキの声がした。

「西風のマキ、この町の最後の一吹きを頂いた！」

自分で考えた台詞を、自分で言った声だった。アサは口を開け、それから顔を覆って笑う。「二人いたか」

祭りの終わり、あなたは捕虜の列にいた。マキは王冠をかぶり、その隣を堂々と歩く。客が名前を呼ぶたびに、彼女は角のある仮面を高く掲げた。

翌朝、染物屋の戸に新しい看板が掛かっていた。「悪役の衣装、ここにあり」。端には大きく、西風のマキ、と署名がある。

**結末 E3：西風と黒マント**

## 作者用設計メモ（読了後）

### 体験の核

町の人々が返してくる言葉と行動を受け、自分の悪役像を走りながら作る活劇。02〜04の登場、06の群衆の反応、08の掛合い、11の足運びが中心。個人の逃亡勝利、捕縛を大見得へ変える終幕、新しい悪役へ見せ場を渡す共演を分ける。幽霊の舞台劇であるGB26とは、路地・橋・荷車場を移動しながら勝負する身体的な遊びを変える。

### 固定前提と仕組み

祭り区画の閉鎖路上で行う公認の追いかけ芝居。木の王冠、紙冠、布剣、布枠は祭りの小道具。赤い腕章への接触が個人の捕縛、冠を持って鐘を鳴らすことが逃亡成功。新しい悪役への譲渡は捕まる前なら可能。捕虜は追跡へ戻らない。09で衣装を畳んでも腕章は外へ残す。11から12では足の向きに反応したアサを布枠で回り込ませ、鐘へ先着する。

### 人物ごとの欲望と反応

主人公は自分が作った赤い裏地を、今夜は演者として見せたい。アサは手加減した勝利ではなく、自分の読みと足で悪役を捕まえたい。04・11では手首と足を見る。08では衣装の動きを褒め、13では捕虜の芝居へ歩調を合わせる。マキは名前を書く脇仕事から、自分の名を呼ばれる演者へ出たい。10で手下を断り、14では自分の台詞と名前を使う。群衆は単に賛同せず、威圧には道を塞ぎ、大ぼらには注文を増やし、変装には仕事を渡す。

### 主な選択と回収

01の名乗りは登場と06の通り方、11の囃し言葉、12・13の最後の掛合いに反映する。05から09へは派手な対決を避け、主人公の馴染みの道で勝つ。08では戦いを続けるか、見せ場として捕まるかを選べる。11では、剣や投げた帽子ではなく足を見る相手の材料を示してから動きを選ぶ。10の王冠譲渡は14で主人公の捕縛とマキの逃亡を別々に実行し、全員勝利へ曖昧に合算しない。

### 自然な代案と核の再評価

馴染みの染物路地で早く鐘へ出ることを認める。道を突然封鎖して対決を強制しない。その経路は客の中心から離れ、自分の息と仕事の記憶を使う場面になる。祭りである以上、わざと捕まって派手な芝居にする選択も可能。勝利だけを最上位の目的にせず、選んだ悪役の演じ方を主眼にした。マキへ冠を渡すことは、冒頭の祭りのルールに含め、終幕だけの例外にしない。

### 公開記録と作用

「名乗り」は01の選択で確定するだけで、好感度・善悪点にはしない。変装の外套は04で着るが、他経路でも同名乗りで扱えるのは04から出た後だけ。09は着ている場合のみ畳み、12・13の外套関連は名乗りが変装のときだけ述べる。王冠の譲渡は10→14という独立した経路で保持し、他の終端へ混入させない。13の帽子は「投げて走ったのなら」の読者が自分の行為で判定できる一文で受ける。
