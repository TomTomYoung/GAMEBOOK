# M03『空渡り便の二度目の人生』

異世界転生をテーマにした、一続きの中編ゲームブックの第1稿です。全16章・304節・3結末。設計には[ゲームシナリオモデル v1.2b](../../SCENARIO_MODEL_V1_2B.md)を使っています。ゲーム未実装。

前の人生で、あなたは配達員だった。雨の夜に返せなかった妹への短い返事を覚えたまま、浮島の世界で赤ん坊として目を覚ます。新しい家族のもとで十八年を生き、竜と空を渡る郵便士になったあなたへ、誰も読めないはずの前の名前で手紙が届く。

生まれ直して育つ時間、幼馴染や竜との旅、もう一人の転生者との出会い、最初の配達を終えて選ぶ仕事までを描きます。

## 読み方

番号付きの節を読み、末尾のリンクをたどってください。選択肢が複数ある時は一つを選びます。「〜なら」とある行は、現在の記録が合う時だけ選べます。条件だけで行先が分かれている節では、該当する一つへ進みます。

引用枠の「〜の場合」は、該当する本文だけを読みます。太字の「記録：」が出たら、その場で値を変更してください。本文中で登場人物が帳面や書面を書くことと、読者の七つの記録を更新することは別です。

最初に次の七つを控えてください。

- **仕事＝未定**：やがて「段取り」か「聞き取り」を選びます。
- **響力＝3**：響石に残る力。0〜3。強い道聴きを使う節では1減ります。
- **告白＝まだ**：前世の記憶を**リタへ**話したか。「まだ」か「話した」。他の人への開示とは別です。
- **竜約＝未定**：サザとの飛行の合わせ方。「任せる」か「合図」を選びます。
- **航路図＝なし**：雨棚で古航路図の「写し」を受け取ったか。
- **荷箱＝無事**：最初の配達品の扱いの履歴。「無事」「濡れた」「乾かした」。配達後も履歴として残ります。
- **進路＝未定**：旅を終えた後の仕事。「島便」「遠便」「学舎」のいずれか。

響力は第8章の指定された一度だけ、宿泊による充填で3へ戻ります。章が変わっただけでは戻りません。0でも進める方法があります。幼少期や訓練では旅用の響力を使いません。

数値を隠して判定する仕組みやサイコロはありません。荷を傷めた場合も物語は続きます。選択で主に変わるのは、仕事の進め方、誰へ何を話すか、飛行や救助の役割、訪れる場面、最後に選ぶ仕事です。主人公の生い立ちや、前の世界への帰還の成否を自由に書き換える形式ではありません。

中断する時は、章・節番号と七つの記録を保存してください。再開時に初期値へ戻さず、その節の更新を二重に行わないようにします。章末の「作者用確認メモ」と、下の作者資料には先の内容が含まれます。
