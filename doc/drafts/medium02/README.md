## 物語

城町カレドの夜を守ってきた地脈灯が、弱り始めている。六日目の夜には灰獣の群れ、灰潮が来る。人々が丘への避難を進めるなか、あなたは地下にある暁炉から、町へ新しい火を分ける「星火の種」を持ち帰る仕事を引き受けた。

あなたは二十七歳の剣士、カナタ。腰に一本の剣を持ち、斥候エダ、紋術師ミレイとともに灰冠迷宮へ潜る。石の守衛、水没した鍛冶場、鏡の罠、巨大な竜骨の橋。その先では、先行した宝剣士も同じ力を求めている。

自分の間合いで剣を振り、限られた霊力を火か風へ変え、仲間と帰り道を作る。手の届く場所まで来た宝をどう扱うかは、探索と戦いのあとで決めることになる。

## 読み方

第一章01から、各節の末尾にあるリンクをたどる。章の途中から読む場合は、それまでの記録を引き継ぐ。章番号の順に全節を読み進めると、別の選択でしか起きない出来事も続けて読むことになる。

通常の選択肢は、行いたいものを一つ選ぶ。「構えが『受け』なら」などの指定は、自分の記録と一致する行をたどる。「霊力が1以上なら」とある術は、残量を満たす時だけ選べる。引用枠の条件付き段落も、記録に合う枠だけを読む。

**「記録：」の指示が出た時だけ、記録を更新する。** 霊力を1減らす指示は、現在の値から1を引く。同じ節を読み返しただけで、消費を重ねない。読む速さや中断している時間によって、物語の日付や霊力は進まない。

戦闘は、敵の動きや足場の描写を読んで行動を選ぶ形式。剣の構えと刻印は序盤に選び、その後の動作へ返る。強い術は霊力を1使い、霊力0でも剣・道具・仲間を使って進める。傷を受けた場合は、以後の握りや動きにも影響する。

中断する時は、次に読む章・節と、以下の七つの記録を残す。新しく読み始める場合だけ初期値へ戻す。

## 最初の記録

```text
構え：未定
刻印：未定
霊力：3
傷：なし
鏡片：なし
盟約：未会
炉策：未決
現在位置：第一章01
```

構えは剣の動き、刻印は使える術、霊力は残る力を表す。傷は探索中の手傷、鏡片は探索で得る物、盟約は先行者との関係、炉策は終盤で決める処置の記録。それぞれ、本文に示された値へ更新する。

本文が所持を確定する通常の装備、仲間の道具、帰り道について、別の隠し記録を自分で推測して増やす必要はない。重要な所在や使い切った物は、その場面で描写する。
