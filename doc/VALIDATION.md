## 再実行する場合

リポジトリ直下で実行します。ゲームを遊ぶだけなら不要です。

```sh
npm run check
npm test
npm ci
npx playwright install chromium firefox webkit
npm run test:browser
BROWSER=firefox npm run test:browser
BROWSER=webkit npm run test:browser
```

環境変数の書き方はbash用です。PowerShellでは `$env:BROWSER='firefox'` のように設定してから `npm run test:browser` を実行します。`BROWSER_SUITE=short` または `medium` で区分を、`BROWSER_CASE` でケース名の正規表現を指定できます。CIは3ブラウザ×短編・中編の6ジョブで実行します。
